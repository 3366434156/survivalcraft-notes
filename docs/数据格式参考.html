一句话定位

方块数据表（分号分隔 78 列）的逐列语义与值语法，AI 写 .csv/BlocksData.txt 前先查本页，不用回翻解析源码。

怎么用（AI 视角）

  1. 写方块数据文件前：先在此表找到列名与值语法 → 照"最小可用示例"抄格式；列名即 Block 子类字段名，写错=整行报错。
  2. 查"为什么这个值不生效"：看"读取方"列跳源码消费点；跨配方/衣物/实体格式见 数据格式参考2。

解析规则（BlocksManager.cs:1037-1094 实读）

  • 表头驱动，非固定列：第 1 行=Class Name;字段名;字段名;…；解析器按列名反射匹配 Block 子类的 public 非静态实例字段（BlocksManager.cs:1061-1069），列顺序无所谓，列名必须一字不差（未知列名=抛异常 BlocksManager.cs:1074-1076）。
  • 第 1 列是类型选择器：值=Block 子类简单名，按 GetType().Name 匹配；匹配失败仅告警跳整行（:1052-1058）。
  • 空单元格=保留字段默认值（:1073），不写覆盖。
  • 每行列数必须=表头 token 数（:1047-1051）；原版表头 78 个具名列+行尾 ;（split 出第 79 个空 token），数据行必须同样 79 token。CRLF 兼容（:1038 先剥 \r）。
  • # 引用语法（:1078-1085）：#=自身 BlockIndex，#类名=指定方块的 BlockIndex（用于掉落/邻块等 int 方块引用列）。
  • 值语法（HumanReadableConverter 各转换器实读）：bool=True/False（大小写不敏感）；float=不变文化小数点 .（SingleHumanReadableConverter.cs）；Vector3=x,y,z（逗号分隔，空格容忍）；枚举=枚举成员名，大小写敏感（EnumHumanReadableConverter.cs 用 Enum.Parse(type,data,false)）。
  • 载入时机：原版表随 Content.zip 由 SurvivalCraftModEntity.LoadBlocksData 载入（SurvivalCraftModEntity.cs:72-76）；模组同格式文件扩展名 .csv（ModEntity.cs:303-315），在全部方块注册后、Initialize 前执行（BlocksManager.cs:407-418）。

最小可用示例

DirtBlock（原版表第 6 行，摘录；E:\SurvivalcraftAPIProject\Survivalcraft\Content\Assets\BlocksData.txt:6）：

DirtBlock;;Terrain;;6;0,0,0;1, 1, 1;1;0.4;0.5, -0.5, -0.6;0, 40, 0;0.3;0,0.12,0;0, 0, 45;dirt;0;TRUE;TRUE;FALSE;FALSE;FALSE;FALSE;FALSE;FALSE;FALSE;FALSE;TRUE;FALSE;FALSE;15;0;0;1;#;1;0.005;0;40;0.5;1;3;FALSE;FALSE;0;0;Dirt;1;1;1;1;;1;1;;-1;FALSE;FALSE;FALSE;0;;0;FALSE;0.9;;0;25;;;;Shovel;1.5;1;;;;;2;1;

要点：第 2 列显示名留空（走 Lang）；dirt=CraftingId（配方用它）；掉落列 34 填 #（自掉落）。引用他块见 GrassBlock 第 15 行：掉落列填 #DirtBlock。

模组用法：.scmod 根放 *.csv（扩展名小写必须），首行表头可只写要覆盖的列（如 Class Name;DefaultDisplayName），其余列由字段默认值兜底——列数=表头 token 数即可，不必 78 列全写。

坑与对策

  • 列名≠列序：解析按表头名匹配字段；照抄别列的顺序不安全——FoodType 列(75)在 DefaultSicknessProbability(74) 与 DefaultRotPeriod(76) 之间，与 Block.cs 字段声明顺序不同。
  • 枚举大小写敏感：Shovel/Meat/Air 首字母必须大写（EnumHumanReadableConverter 用 ignoreCase:false）。
  • 行尾 ; 不能少：原版每行 79 token；少一个 ; 整行抛 InvalidOperationException（BlocksManager.cs:1047-1051），但解析器逐行执行——前面行已生效，报错行丢失。
  • 类名打错静默丢块：只 Log.Warning 跳行（BlocksManager.cs:1058），游戏照常进——世界少了方块先查日志。
  • # 只对 int 方块引用列：非方块引用列写 # 会按类型转换失败抛异常。
