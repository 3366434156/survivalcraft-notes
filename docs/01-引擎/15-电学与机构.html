电学与机构

域: SC引擎 · 更新: 2026-10-31 · 状态: 全读(ElectricElement 目录 51/51 逐个全文；SubsystemElectricity.cs 关键行复核；SubsystemElectricBlockBehavior.cs 164 行全文；机构/存储行为子系统 12 个深读: Piston/MovingBlocks/Door/Trapdoor/FenceGate/Dispenser/Magnet/Spikes/ItemsScanner/Furnace/MemoryBank/TruthTable；HandledBlocks 61 项核对)。逐元件端子/节流/存档见 15a-电学元件明细。

一句话定位

电路 = 单一 SubsystemElectricity 每 10 ms 游戏时间推一步的事件排队模拟；机构 = 活塞/门/发射器等 BlockBehavior 子系统被元件 Simulate 调用后改地形或移动方块。

核心机制

电路一次 tick 的传播调用链

帧驱动：SubsystemUpdate 逐个调 IUpdateable(见 02-Subsystem体系 更新体系) → SubsystemElectricity.Update(dt)(SubsystemElectricity.cs:394)：

  1. 累加器 m_remainingSimulationTime = Min(+dt, 0.1f)(:398) ⇒ 单帧最多 10 步；CircuitStepDuration = 0.01f(:237)。
  2. while(≥0.01f)(:399)：先 UpdateElectricElements()(:400)、++CircuitStep(:401)，后取本步队列 m_futureSimulateLists.Remove(CircuitStep)(:404) ⇒ 本步新建的元件同一步就会被 Simulate 一次。
  3. 逐个 SimulateElectricElement(key)(:414) → element.Simulate()(SubsystemElectricity.cs:523)；返回 true 才 QueueElectricElementConnectionsForSimulation(element, CircuitStep+1)(:525→:375-382)，把"非 Output 端口上的邻居"排到下一步 ⇒ 信号一跳 = 1 步 = 10 ms 游戏时间。

排队规则 QueueElectricElementForSimulation(:357-373)：==CircuitStep+1 进 nextStep 缓存；>+1 进 future 字典(键=步号，跨帧存活)；<=CircuitStep 静默丢弃。

连接建立链(方块变化如何变成元件与边)： SubsystemElectricBlockBehavior.OnBlockGenerated/Added/Removed/Modified(:72-90) → OnElectricElementBlock\* → 塞 m_pointsToUpdate(SubsystemElectricity.cs:255-269，value=false=生成/卸载) → 下一 step 开头 UpdateElectricElements()(:611-654)：

  • 查该点 6 面旧元件：线域标脏(:618-620)、其余进移除表(:622)；真实改动删本格持久电压(:627-629)。
  • 按接口判型(:630 IElectricWireElementBlock→标脏线；:634 IElectricElementBlock→CreateElectricElement，非 null 才登记)。
  • 固定顺序：RemoveWireDomains(:676)→逐个 RemoveElectricElement(:596)→AddWireDomains(:656，ScanWireDomain 洪泛 :668-669)→逐个 AddElectricElement(:529：双向写两边 Connections(:532/:542-587)→自身排 CircuitStep+1(:591)、邻居排 CircuitStep+2(:592)→最后一行 OnAdded()(:593))。
  • OnBlockStartMoving/StopMoving 也塞 m_pointsToUpdate(SubsystemElectricBlockBehavior.cs:88-94) ⇒ 活塞每推/停一次，途经点的电路元件全部销毁重建。

电压模型(数字要背)：无电流/电阻/短路，唯一量是 16 档 level/15f；IsSignalHigh(v)=>v>=0.5f(ElectricElement.cs:40)；多源汇入线域按 4 bit 按位或(WireDomainElectricElement.cs:20)；显示/活塞类取 Max(PistonElectricElement.cs:24)；端口配对 Output↔Output、Input↔Input 不连(SubsystemElectricity.cs:339-341)；颜色掩码 (mask&mask2)!=0(:344)。

导线不是元件：线域洪泛

WireBlock.CreateElectricElement => null(Block\WireBlock.cs:50)，每格线不建元件；引擎把连通线洪泛成一个 WireDomainElectricElement(AddWireDomains :656-674)。后果：导线任意长，传播延迟仍恒 1 步；导线颜色是 data 第 7..10 位，是唯一隔离手段。

机构执行类标准状态机(4 处逐行复制)

Door(:14-43)/TrapDoor(:14-39)/FenceGate(:14-39)/SpikedPlank(:14-39) 四个元件的 Simulate 同构：

  1. 构造置 m_needsReset=true ⇒ 上电/存档加载瞬间不触发；必须先见到低电平(!IsSignalHigh(m_voltage))才武装(:21-23)。
  2. 输入沿变化记 m_lastChangeCircuitStep(:17-19)。
  3. 距上次沿 ≥10 步(0.1s)才调行为子系统 toggle(!GetOpen(data)，写 data 由行为完成)，否则补排 CircuitStep+10-num(:24-37) ⇒ 执行类最小间隔 100ms，防信号抖动连环开关。

LightBulb(:32-41)/ChristmasTree(:22-31) 用同思路的"≥10 步才 ChangeCell 写 data"防抖。手开豁免：木活板门 83 永远可手开，铁 84 接电后禁手开(SubsystemTrapdoorBlockBehavior.cs:46)；栅栏门 166 同豁免(SubsystemFenceGateBlockBehavior.cs:46)。

旋转与语义方向协议(20 类通用)

  • RotateableElectricElement.Rotation 存 data(:5-22)，OnInteract=++Rotation+Click 音(:26-29)。
  • 元件里用 SubsystemElectricity.GetConnectorDirection(CellFaces[0].Face, Rotation, connectorFace) 把物理面换算成 Top/Bottom/Left/Right/In 语义方向，端口语义(数据/时钟/清零/音色)写在方向上 ⇒ 一个类支持 4 朝向。Counter(:44-58)、SRLatch(:30-47)、MemoryBank(:33-54)、TruthTable(:20-44)、ADC(:35-41)、DAC(:20-37)、RTC(:15-31)、SoundGenerator(:85-103) 全是这一套。
  • 例外：延迟门/或门/非门等只问"第一条非 Output 连接"，不分方向；Delayed 历史字典 ≤300 条(BaseDelayGateElectricElement.cs:33)。

传感器轮询与模拟量协议

  • 轮询自续三档：Photodiode 固定 +50 步(:15)；Thermometer 0.5s(:20)、MotionDetector 0.25s(:54) 带 period*(0.9f+0.0002f*(GetHashCode()%1000)) 抖动；RandomGenerator 无连接时 random.Float(0.25,0.75)s 随机周期(:45-48)。
  • MotionDetector 四源检测(生物/移动方块组/投掷物/掉落物，:59-92)：8m 半径、朝向点积>0.5、射线遮挡但无视编号 15/60/44/18 四种方块(:106-110)；输出下限 0.51 恰过 IsSignalHigh 阈值(:91)。
  • 模拟量端口语义：压力板质量 8 档全 ≥8/15(永远"高"，分档靠 ADC/DAC)；活塞长度=Max((int)(v*15.999)-7,0) → 0..8 格模拟量控制(PistonElectricElement.cs:27)；OneLED/多彩 LED 电压 8..15 选色、0..7 灭(OneLedElectricElement.cs:52)；7 段码 16 项 hex 字模表(SevenSegmentDisplayElectricElement.cs:33-50)；RTC 一天 4096 份拆 5 nibble 输出(RealTimeClockElectricElement.cs:9,:14-34)。
  • SoundGenerator 端口表：In/Bottom=音色(1-11,16)、Left=音高、Right=八度(默认 2)、Top=音量(默认 15)；上升沿+0.08s 间隔触发，基频 130.81Hz×2^((音高+12×八度)/12)(SoundGeneratorElectricElement.cs:91-134)。

元件状态的三条存档归宿

  1. 方块 data 位(原版主力)：开关 1 bit、电压档 4 bit、电池 4 bit、灯泡亮度 4 bit、可调延迟门 8 bit、Rotation、门开合、刺伸缩。
  2. WritePersistentVoltage(:391→VoltagesByCell)：Save 串格式 x,y,z,v;…(InvariantCulture)，num>500 break(:483-485) ⇒ 上限 501 条且取舍顺序不定；仅 Counter(:99，负值符号位偷存溢出标志)/SRLatch(:81)/RandomGenerator(:51) 3 类用。
  3. 自己的 BlockBehavior 子系统存：MemoryBank(SubsystemMemoryBankBlockBehavior.cs:5)、TruthTable(:5)、Sign、家具设计。

元件对象本身不入档、按点变动销毁重建——C# 字段不跨"方块被改动"存活。

模组自定义电路元件 4 步

元件类型不是闭集(无注册表无 switch，子系统只判接口 :634)：

  1. 方块类：class MyBlock : CubeBlock, IElectricElementBlock，实现 3 成员(IElectricElementBlock.cs:3/:5/:13)。想要贴墙+旋转就继承 MountedElectricElementBlock(但必须带模型资产)。
  2. 元件类：class MyElement : ElectricElement，至少 override Simulate(基类 :24 恒 false)和 GetOutputVoltage(:22 恒 0f)。只在值变化时 return true，自续排队会 CPU 炸。
  3. 挂接(二选一)：
  • 路 A(推荐)：方块表 csv 第 4 列 Behaviors 写 ElectricBlockBehavior——零 C# 注册，Project 模板里已有该名字(Database.xml:3488-3489)；代价是与 61 个原版电方块共用 behavior 实例。
  • 路 B：自己写 SubsystemBlockBehavior 子类，把 OnBlock\* 手工转发给 OnElectricElementBlock*(:255-269 全 public)，并作为 MemberSubsystemTemplate 挂 Project(注册方式见 02-Subsystem体系)。
  • 两条路的底线：方块编号不在 HandledBlocks(SubsystemElectricBlockBehavior.cs:8-70，61 项)又没挂行为列 ⇒ m_pointsToUpdate 永远为空，元件一次都不创建、不报错。免硬编码做法：像 SubsystemSpikesBlockBehavior.cs:17 用 GetBlockIndex<SpikedPlankBlock>()。
  1. 改值后唤醒：ChangeCell 只保证元件重建(+2 步叫醒邻居)，对话框改完电压要补 QueueElectricElementForSimulation(GetElectricElement(...), CircuitStep+1)(范式 SubsystemBatteryBlockBehavior.cs:42-49、SubsystemMemoryBankBlockBehavior.cs:61-63)。

硬边界：无法替换 SubsystemElectricity 实例——FindSubsystem 返回第一个类型兼容的(Project.cs:110-116)，插桩只能 Harmony。

坑与对策

  • Simulate 里抛异常 = 整局崩：catch 后紧接 throw;，仅 DEBUG 打一行(SubsystemElectricity.cs:415-423)。对策：自写元件内部 try 住。
  • 排队了却不跑：传 circuitStep <= CircuitStep 被静默丢弃(:357-373)。对策：一律 CircuitStep + n。
  • 元件每 10ms 都跑、CPU 炸：Simulate 无条件自续。对策：只在值变化时 return true(原版惯例)。
  • 一改方块 data，元件字段全没：UpdateElectricElements 按点销毁重建(:611-654)且删本格持久电压(:627-629)；活塞推方块启停也重建(SubsystemElectricBlockBehavior.cs:88-94)。对策：状态写 data 或自己的 behavior。
  • 与门/与非门输出恒 0：要求恰好 2 个输入连接(AndGateElectricElement.cs:20)；非门多连线只认第一条(NotGateElectricElement.cs:15-16)。
  • 两根不同色线不通、两 Output 挨着不连：设计如此(SubsystemElectricity.cs:339-344)，不是 bug。
  • 几十个轮询元件同时跑掉帧：轮询要抄相位抖动(ThermometerElectricElement.cs:20、MotionDetectorElectricElement.cs:54)。
  • 按 MC 思路找传送带/矿车：源码没有(见负事实)，别在引擎层浪费检索时间。
  • 活塞当开关用却收不回：伸出长度是模拟量，v<8/16≈0.5 时长度 0；给半档电压只伸 1 格(PistonElectricElement.cs:27)。
  • LED 接 4 档信号全程不亮：OneLED/多彩 LED 电压 8..15 才选色，0..7 灭(OneLedElectricElement.cs:52)。
  • 铁活板门/接电门"按不动"：接电后手动开合被禁(SubsystemTrapdoorBlockBehavior.cs:46、SubsystemFenceGateBlockBehavior.cs:46)；木活板门 83/栅栏门 166 豁免。
  • 改电路拓扑后延迟门延迟不对：档位缓存 50 步(DelayGateElectricElement.cs:11-13)，0.5s 后自动重算。
  • Counter 的持久电压不能挪用：符号位被偷存溢出标志(CounterElectricElement.cs:99)。
  • Hygrometer 读数不变：它不自续轮询(HygrometerElectricElement.cs:9-15)，湿度变了也不上报；要主动排它或改用其他传感器。
