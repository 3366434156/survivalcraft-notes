37-种植与作物生长（播种→轮询生长→收获→养分循环的全链）

域: SC引擎 · 更新: 2026-11-02 · 状态: 全读(SeedsBlock/RyeBlock/CottonBlock/BasePumpkinBlock+PumpkinBlock/SoilBlock/SaplingBlock/SubsystemPlantBlockBehavior/SubsystemSoilBlockBehavior/SubsystemSaplingBlockBehavior/SubsystemCactusBlockBehavior/SubsystemFertilizerBlockBehavior/SubsystemRotBlockBehavior/SubsystemBlocksScanner/SubsystemCellChangeQueue/PlantsManager)；⚡=ModLoader 钩子/可挂点 一句话定位：种植 = SeedsBlock 按种型"变身放置"成植株方块 → SubsystemBlocksScanner 以约 60s/轮全图扫描逐列调 OnPoll → 作物用 data 位记生长阶段、按"耕地状态+温度"决定推进间隔与退化概率、光照≥9 才长 → 收获全走 GetDropValues 掉落表，成熟扣耕地氮；树苗走"时间表+笔刷"，仙人掌走"堆叠概率"，是三套互相独立的生长范式。

源码引用一律仓库相对路径（Survivalcraft\...）。方块值/data 编码底座 → 04页；ChangeCell 与地形修改管线 → 27页；光照亮度来源 → 14页；掉落物实体 → 16页。

2 · 生长调度：SubsystemBlocksScanner 全图轮询（谁 tick 的答案）

  • 不是区块随机 tick，也不是逐帧 Update：SubsystemBlocksScanner（IUpdateable）把"已加载区块的所有 xz 列"排队，每帧按预算扫若干列（ shaft=一根 xz 柱，从 y=0 扫到柱顶 GetTopHeightFast，逐格查 contents → 调该方块的 pollable 行为 OnPoll(value,x,y,z,pollPass)） | SubsystemBlocksScanner.cs:36-79
  • 节奏：m_pollShaftsCount += 区块数×256×dt/ScanPeriod，ScanPeriod=60（公共字段，mod 可改）→ 全图扫一整轮 ≈60 秒（现实时间）；每帧上限 MaxShaftsToPollPerFrame=500 柱（公共字段，注释明言 mod 可调） | SubsystemBlocksScanner.cs:7,30,38-39
  • pollPass：LoopChunks 环游全部区块一圈 → m_pollPass++，随存档持久化（PollChunkCoordinates/PollPoint/PollPass 三键）→ 每根柱子每轮被调一次，pollPass 是全局轮次计数器 | SubsystemBlocksScanner.cs:88-96,103-107,117-119
  • 环境开关：作物生长只在 EnvironmentBehaviorMode.Living(=0) 生效，Static 世界不长 | SubsystemPlantBlockBehavior.cs:74-79; Survivalcraft\Game\EnvironmentBehaviorMode.cs:2-5
  • 改格不走 ChangeCell 直改：Grow* 里一律 m_subsystemCellChangeQueue.QueueCellChange——攒批、每 20s 游戏时间（或满 10000 条）批量应用，应用时校验"当前值==排队时值"（CAS，光值除外），期间被玩家改过就丢弃 | Survivalcraft\Subsystem\SubsystemCellChangeQueue.cs:26-40,44-66
  • 所以"生长一阶段"的最小时间单位 = 一整轮 ≈60s：Rye 间隔 4 轮/阶段 ≈4 分钟，改良后 2 轮；7 阶段全程约 14-28 分钟（现实时间）[由 §3 公式推得]。

3 · 生长阶段：data 位状态机 + 条件概率（GrowRye/GrowCotton/GrowPumpkin）

三作物共用骨架：光照门 → data 取 size → 野生/家种分岔 → 查耕地 data 算参数 → pollPass % 间隔 == 0 才推进 → 顺带掷退化骰 → 成熟扣氮。

data 编码：Rye size=data&7(0-7)+bit3=isWild（RyeBlock.cs:168-182）；Cotton size=data&3(0-2)+bit3=isWild（CottonBlock.cs:153-167）；Pumpkin 倒序 size=7-(data&7) + bit3=isDead（BasePumpkinBlock.cs:213-217）。

4 · 环境条件：光/温/踩/盖

  • 光：只看植株上那一格的亮度（GetCellValueFast(x,y+1) 的 ExtractLight），作物 9、仙人掌 12、树苗 GetCellLight(y+1)>=9；被不透明方块罩住=光 0=不长，但不会死（南瓜 isDead 后也不自动消失） | SubsystemPlantBlockBehavior.cs:143 等; SubsystemCactusBlockBehavior.cs:40; SubsystemSaplingBlockBehavior.cs:144
  • 温度：GetSeasonalTemperature(x,z)+SubsystemWeather.GetTemperatureAdjustmentAtHeight(y) 只用来放大间隔（寒带慢 2-3 倍），无冻死/热死判定 | SubsystemPlantBlockBehavior.cs:164,220,271
  • 水分：耕地每轮询一次 DetermineHydration（BFS 3 步：横邻 1 步、纵向 2 步，可穿泥土(2)与已湿耕地(168)，遇水(18)→湿）；湿/干结果排队，每 10s 游戏时间批量写 data bit0 | SubsystemSoilBlockBehavior.cs:29-39,64-76,88-132
  • 被踩：耕地 OnCollide——质量>20kg 且不蹲下，下落 vy<-3 或走路按 1.5×dt 概率 → 排队退化；2.5s 游戏时间后耕地变泥土(2)（蹲行安全） | SubsystemSoilBlockBehavior.cs:18-27,55-62
  • 被覆盖：耕地顶上出现"不透明且可碰撞"的方块 → OnNeighborBlockChanged 直接变泥土(2)；随后植株的 OnNeighborBlockChanged 发现下方仍适合（泥土能种）→ 不死，但下轮转野生；若下方整个没了（挖掉）→ 植株 DestroyCell | SubsystemSoilBlockBehavior.cs:41-47; SubsystemPlantBlockBehavior.cs:42-68
  • 作物本体无踩踏判定（OnCollide 未 override），踩不坏苗，只坏土。

7 · Mod 视角：自定义作物最小集

代码路线（推荐，4 件套）：

  1. 新 Block 子类（public static int Index，自动发现），家族变体全走 data 位——RyeBlock 是标准模板（size+野生两位）。
  2. 新 SubsystemPollableBlockBehavior 子类：HandledBlocks=>[你的Index]，OnPoll 里查光照/土壤 → QueueCellChange 推 data。原版 SubsystemPlantBlockBehavior.OnNeighborBlockChanged 已 sealed 不可借尸，注释明说"新植物请自建 ModPlantBlockBehavior" | SubsystemPlantBlockBehavior.cs:30-42
  3. 行为注册 = 项目模板（Database.xml）加 <SubsystemTemplate Class="Game.你的行为类">（原版四个生长行为全这样挂，Survivalcraft\Content\Assets\Database.xml:3453-3492）；behavior 与方块的关联走 HandledBlocks 或方块 Behaviors 名单（逗号分隔，按名查子系统实例） | Survivalcraft\Subsystem\SubsystemBlockBehaviors.cs:19-33
  4. 收获 = override GetDropValues（照抄 RyeBlock.cs:123-166）。

不加自建 tick 的替代做法：

  • ⚡GrowPlant 钩子接管原版 11 种作物格的生长（skipVanilla=true 后自己写）——但 HandledBlocks 是代码数组，mod 新方块进不去，此路只适合改原版 | SubsystemPlantBlockBehavior.cs:86-95
  • "种下即成品"伪种植：SeedsBlock.GetPlacementValue 直接返回成熟 data 的目标值，零 tick 零行为 | SeedsBlock.cs:36-55
  • 树苗式自管时间表：不进轮询体系，行为子系统自带 Dictionary + Update，可精确控制每株成熟时刻且随存档往返（照抄 SubsystemSaplingBlockBehavior）——代价是状态要自己持久化。

最短照抄链：单格观赏植物=GrowTallGrass（9 行，SubsystemPlantBlockBehavior.cs:122-130）；竖直蔓延=SubsystemCactusBlockBehavior.OnPoll（14 行）；完整粮食作物=GrowRye（57 行，含土壤/温度/退化/扣氮全家桶）。

9 · 快查路由

  • 种子放不上/种下就消失 → §1 步骤 4（IsSuitableForPlants 表）| 04 页
  • 作物不长 → 依次查：EnvironmentBehaviorMode 是否 Living（§2）→ 上格光照 ≥9（§4）→ 下方是否 168 且非野生（§3）→ 寒带间隔放大（§3）
  • 作物长成野生/枯死 → 退化骰 §3（氮+湿任一为 0 就有概率）
  • 想要氮 → §5 三来源（腐化链/硝石/堆肥方块）
  • 成熟不掉东西 → GetDropValues 表 §5（野生株只有种子）
