28-弹道与远程武器（扣扳机→飞行→命中→回收的全链）

域: SC引擎 · 更新: 2026-11-01 · 状态: 全读(Projectile 702行/WorldItem/SubsystemProjectiles/Attackment/ProjectileAttackment/SubsystemBow·Crossbow·Musket·Arrow·Bullet·ImpactExplosives·ThrowableBlockBehavior/Bow·Crossbow·MusketWidget/BulletBlock/MusketBlock/BlocksData.txt 弹道列)；⚡=ModLoader 钩子/可挂点 一句话定位：远程武器 = 方块 data 位状态机（拉弓档/装填态/弹种）+ OnAim 三态回调在松手瞬间换算初速 → Projectile（普通类，非实体）被 SubsystemProjectiles 持表逐帧积分（重力+阻尼，无风），每帧一段双射线（地形/Body）择近结算，停稳后按弹种契约变掉落物或消失。

源码引用一律仓库相对路径（Survivalcraft\...）。物理底座（SubsystemBodies.Raycast/爆炸压力场）→ 13页；WorldItem/Pickable 家族与拾取物物理 → 16页；发射器 Dispense 全流程 → 25页 链5 + 13页。

0 · 体系坐标：Projectile 是什么

  • Projectile : WorldItem（Survivalcraft\Game\Projectile.cs:7）——纯 C# 类，不走 Entity/组件系统；由 SubsystemProjectiles 持 List<Projectile>（Survivalcraft\Subsystem\SubsystemProjectiles.cs:38）逐帧 Update/Draw（:230-261/:200-228），存档按 Class=GetType().FullName 反序列化（Projectile.cs:138 + SubsystemProjectiles.cs:280-284，mod 子类默认构造即可随存档往返）。
  • WorldItem 基类字段：Value/Position/Velocity/CreationTime/Light/ToRemove/Creator/IsFireProof/MaxTimeExist/ExplosionMass/LogDrawError + DictionaryForOtherMods mod 数据袋（Survivalcraft\Game\WorldItem.cs:5-35）。
  • 弹种 = 物品 Value：Terrain.ExtractContents(Value) 查 Block，攻击力 AttackPower = block.GetProjectilePower(Value)（Projectile.cs:157-160）——箭 5/7/14/18、弩箭 28/36、弹丸 80（见 §3 表），数值全在 Block 类代码数组或 BlocksData.txt 列。
  • 弹道参数不在 Projectile 写死，而在 Block 数据：Gravity=10、DampingInFluid=0.001、TerrainKnockBack=0.3、DamageToPickable=1、MinVelocityToAttack=10 是 Projectile 字段默认值（Projectile.cs:34-56）；Damping 在 Initialize 时从 block.GetProjectileDamping(Value) 取（:174-184，箭 0.9/弹丸 0.95，BlocksData.txt:206/:207）。
  • 没有风、没有爆头/暴击：全链只有重力+阻尼（Projectile.cs:530-533）；伤害只按 AttackPower / 韧性 结算（Attackment.cs:82-111），无部位判定。

链 2 · 弹道模拟与命中链（Projectile.Update 每帧）

入口守卫（Projectile.cs:243-262）：UpdateTimeToRemove 超龄 MaxTimeExist ?? 40s 标 ToRemove（:264-272）；所在区块未加载（State≤InvalidContents4）→ NoChunk、停拖尾、⚡OnProjectileFlyOutOfLoadedChunks（:247-257），不在未加载区模拟。

核心 UpdateInChunk(dt)（:480-523）九步：

  1. 帧末位移预估 positionAtdt = Position + Velocity*dt（:483）。
  2. Raycast(dt) 双射线（:190-241）：线段 = 本帧位移（不扫 AABB，高速大步长会穿薄墙——弹道内建的穿墙盲区）；起点/终点各加 ProjectileTipOffset × Velocity 方向（箭 0.3，弹头前探 :194）；地形线只碰 IsCollidable_ 格（:195-215）；Body 线用 SubsystemBodies.Raycast 半径 0.2，⚡OnProjectileRaycastBody 可逐个排除 + BodiesToIgnore 白名单（:216-236）。
  3. 命中即调弹种自己的方块行为 OnHitAsProjectile（:287-298），返 true → disintegrate（粉碎：碎屑粒子+移除，箭类按弹种概率碎，§3）。
  4. 择近结算（:497-500）：Body 比 terrain 近 → HitBody，否则 HitTerrain。
  5. HitBody（:300-344）：速度 ≤ MinVelocityToAttack(10) 攻击力记 0（:301，蹭到不伤）；命中后速度 = V×(−0.05)+随机微扰（:302）；构造 ProjectileAttackment（ImpulseFactor=2、StunTimeSet=0.2、零伤不冲不晕，Survivalcraft\Game\ProjectileAttackment.cs:8-14）；⚡OnProjectileHitBody 可整体换 Attackment/改反弹速度/置 ignoreBody（置 true = 该 Body 进 BodiesToIgnore 且位移不回卷 → 穿透弹就是这一行，:313-341）；ComponentMiner.AttackBody(attackment) 进完整伤害管线（护甲/韧性/冲量/眩晕/击杀信息，Attackment.cs:213-263），射手 RangedHits++；IsIncendiary 对目标 ComponentOnFire.SetOnFire(6~8s)（:336-338）。
  6. HitTerrain（:346-445）：按命中面法线把速度反向缩放 0.3 弹回+随机扰动（:356-367）；速度>10 且随机数 > 被击方块的 GetProjectileResilience → DestroyCell 打碎目标（树叶 0.5/玻璃南瓜 0=必碎/泥土 1=打不坏，BlocksData.txt，:369-411）；速度>5 播材质撞击音（:370/:430-433）；插住判定 = 弹种 IsStickable_ ∧ 速度>10 ∧ 随机 < 被击方块的 GetProjectileStickProbability（泥土/沙/草/冰 0.9，仙人掌/南瓜 0.95——概率长在靶子上不在箭上，:371-373）；IsIncendiary 在命中格及周围 8 次射线落点火（:412-429）；被击方块的方块行为收 OnHitByProjectile（电路元件被打触发等，:391-397）；⚡OnProjectileHitTerrain 在这一切之前可 ref 改全部判定（:374-389）。
  7. 停稳判定（:507-520）：插住或速度 <1 时按 ProjectileStoppedAction 分派——TurnIntoPickable（默认，:447-478）：BlocksManager.DamageItem(Value, DamageToPickable, Owner) 结算落箭耐久（耐久 −1 的箭原值返回=完整回收，BlocksManager.cs:1011-1035；可用 TurnIntoPickableBlockValue 换成别的掉落物），插住时用 CalculateVelocityAlignMatrix 摆出"钉在墙上"的姿态再 CreatePickable；Disappear → 直接移除（火箭/弹丸）。Disappear 系弹种不是"命中即消失"，是"停稳即消失"——飞行途中照样能弹跳。
  8. UpdateMovement（:525-610）积分：Velocity.Y −= 10*dt（重力）→ 速度/角速度乘 pow(Damping,dt)（入流体换 DampingInFluid）→ Position=positionAtdt、Rotation 累积角速度（:530-535）；入水：水平速>6 且 >4×|Vy| 水面弹跳（V×0.5、Vy 反向）否则 V×0.2，出水花+水声（:536-583）；进岩浆/穿火：非 IsFireProof → 嘶声 + SubsystemExplosions.TryExplodeBlock（爆炸弹种在此殉爆）+ ToRemove（:563-574/:586-608）；拖尾每帧贴到 Position + TrailOffset 旋转（:612-626）。
  9. 噪声与爆炸：弹跳/水花调 MakeNoise（0.5s 节流，半径 6 惊动生物，:628-636）；爆炸波及 UnderExplosion 只加冲量（:638-640）。

移除时机汇总（SubsystemProjectiles.Update 每帧末统一出表，:234-258）：ToRemove（超龄 40s / 粉碎 / TurnIntoPickable 后 / 岩浆火烧 / Update 抛异常）→ 停拖尾 → OnRemove 回调 → ProjectileRemoved 事件；mod 侧 RemoveTrail 用 SubsystemProjectiles.AddTrail/RemoveTrail（:185-198）。

快查路由

  • 箭射出去没伤害：命中时速度 ≤10（MinVelocityToAttack，Projectile.cs:56/:301）——近距擦着出膛点发射/被 CanFireProjectile 前移过；或目标是 ComponentDamage 类且韧性高。
  • 穿墙/隔墙打中人：Raycast 是本帧位移的线段采样，速度×dt 跨过薄墙就漏（Projectile.cs:190-241）——高初速弹种把 dt 内位移想成离散跳跃，需要自定义子类步进采样。
  • 箭插不进方块：插住概率长在被击方块（泥土/沙/草/冰 0.9）不在箭上（Projectile.cs:371-373，BlocksData ProjectileStickProbability 列）；箭本身还要 IsStickable=TRUE。
  • 弹丸落地捡不起来：MusketBehavior 发射时设 ProjectileStoppedAction.Disappear（SubsystemMusketBlockBehavior.cs:184），消失是设计不是 bug；想回收改 TurnIntoPickable + TurnIntoPickableBlockValue。
  • 爆炸弩箭不爆：压力在 ArrowType.ExplosiveBolt 的 GetExplosionPressure（ArrowBlock.cs:249-256），起爆开关在 BlocksData Behaviors 列的 ImpactExplosivesBlockBehavior——漏一环就只是普通弩箭。
  • 想每帧改弹道：没有 per-frame 钩子——override Projectile 子类（官方入口）或用 OnProjectileHitBody/HitTerrain 在碰撞帧改速度；改 Gravity/Damping 用 Projectile 字段（改 ComponentBody 无效，弹道不走实体物理）。
