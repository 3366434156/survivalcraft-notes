粒子系统

域: SC引擎 · 更新: 2026-10-31 · 状态: 全读(28/28，另读 SubsystemParticles)

一句话定位

ParticleSystemBase 体系的注册-模拟-绘制闭环：Simulate 返回 true 即自杀，Draw 排 quad 进共享批次统一刷。

SubsystemParticles.csSurvivalcraft\Subsystem\SubsystemParticles.cs注册表 + 更新 + 绘制调度

核心机制

注册 → 模拟 → 绘制闭环

  • 注册：AddParticleSystem(ps)：要求 ps.SubsystemParticles==null，置引用、调 OnAdded、记账批次容量 (SubsystemParticles.cs:35-46)。若实例已被持有且未传 throwOnAlreadyAdded:true，静默什么都不做 (SubsystemParticles.cs:42-45)。移除 RemoveParticleSystem 对称走 OnRemoved + 反记账 (:48-59)。
  • 模拟：Update(dt) 遍历 m_particleSystems 调 Simulate(m_subsystemTime.GameTimeDelta)；返回 true 或抛异常 → 进 m_endedParticleSystems，循环结束后统一 RemoveParticleSystem (SubsystemParticles.cs:90-108)。异常也被摘除，只留一行 Log.Error——粒子系统写崩不会连环炸。
  • 绘制：drawOrder 300 (SubsystemParticles.cs:25)。流程 (SubsystemParticles.cs:110-155)：按账本对共享批次 EnsureCapacity 一次性预扩容 → 逐系统 Draw(camera) 排 quad → 取 ContentManager.Get<Shader>("Shaders/AlphaTested") 灌雾/视口 uniform（u_origin/u_viewProjectionMatrix/u_viewPosition/u_fogYMultiplier/u_fogColor/u_hazeStartDensity/u_fogBottomTopDensity/u_alphaThreshold，:133-142）→ 逐 TexturedBatch 设设备状态后 FlushWithDeviceState(shader) (:145-152) → PrimitivesRenderer.Flush(camera.ViewProjectionMatrix) (:153)。粒子自动带雾与高度衰减，无需自己算。
  • 两个总开关：ParticleSystemsDraw / ParticleSystemsSimulate（默认 true，:21-23）。关掉 Simulate 只是冻结（没人返回 true 就没人被移除），不是关闭。

发射器生命周期（重点）

Simulate 返回 true = "我演完了"。基类 ParticleSystem<T>.Simulate 恒 return false (ParticleSystem.cs:164)——不覆写就永不消失，每帧全量 Draw。正确写法抄 BlockDebrisParticleSystem：遍历数活跃粒子 return !flag;（BlockDebrisParticleSystem.cs:66-109，flag 只要有 IsActive 就置真）。构造时粒子池 new T[n] 一次性填满不增长 (ParticleSystem.cs:35-40)。

渲染细节（ParticleSystem<T>）

  • 懒建两个 TexturedBatch3D (ParticleSystem.cs:48-68)：Additive 批 = DepthRead + BlendState.Additive + PointClamp；Alpha 批 = Default + BlendState.AlphaBlend + PointClamp；逐粒子按 UseAdditiveBlending 选批 (:131)。批次键含完整状态，与 06 页"批次复用"同机制。
  • Billboard 三种基向量系按相机算 right/up (:69-77)；None 模式直接用粒子自己的 Right/Up (:90-95)；Horizontal 旋转绕 Y (:96-106)。enum 定义 ParticleBillboardingMode.cs:2-7。
  • UV：TextureSlot ÷ TextureSlotsCount 切图集，s = 1/TextureSlotsCount (:78,132,145-148)；TextureSlotsCount 是"图集 n×n 的 n"不是槽总数（碎屑 32、火 3）。
  • 颜色：整个 Particle.Color 直接进 QueueQuad 顶点色 (:149-159)，淡出靠自己改 A。
  • 批次容量自报契约：GetBatchDemands 默认把 QuadDemandTexture/MaxQuadDemand 翻成两条标准批次条目 (ParticleSystemBase.cs:59-80)；契约：纹理与容量在系统生命周期内必须恒定，否则记账增删不对称。

方块碎屑链（原版最常用）

Block.CreateDebrisParticleSystem 基类实现：new BlockDebrisParticleSystem(terrain, position, strength, DestructionDebrisScale, Color.White, GetFaceTextureSlot(4, value)) (Survivalcraft\Block\Block.cs:499-503)，颜色硬编码 White、纹理槽固定 4 号面；20+ 方块子类覆写换色/换槽。生成门控：showDebris && !noParticleSystem && CalculateDistanceFromNearestView(...) < 16f (Survivalcraft\Subsystem\SubsystemTerrain.cs:460-467)。构造里取六邻光照最大值乘进颜色、A 置 255 (BlockDebrisParticleSystem.cs:51-59)；Simulate 中 dt 钳 0-0.1（掉帧不穿墙）、重力 -9.81、撞墙反弹 (BlockDebrisParticleSystem.cs:66 起)。

生命周期三形态与消亡协议（全族归纳）

  • A 一次性发射器：构造时全量（或大部分）激活，Simulate 数活跃 return !flag——BlockDebris、Kill (KillParticleSystem.cs:64)、BurntDebris (:92)、WaterSplash (:128)、MagmaSplash (:104)、HitValue（单粒子 0.9s，HitValueParticleSystem.cs:52）。GunSmoke 附加时限：!flag && m_time >= 0.5f (GunSmokeParticleSystem.cs:89-91)。
  • B 常驻共享池：Simulate 恒 return false，注册一次全场共用，靠 AddXxx 找空位填充，找不到空位静默丢弃——RainSplash (RainSplashParticleSystem.cs:75-105)、SnowSplash (:50-72)、Explosion (ExplosionParticleSystem.cs:56-76)、PrecipitationShaft (:217)。注册点：SubsystemWeather.cs:252-253（雨雪溅花）、SubsystemExplosions.cs:339（爆炸）。
  • C 跟随型 + IsStopped：宿主每帧更新 Position/参数，宿主结束时置 IsStopped，系统等池内粒子死光再 return true——Fire (FireParticleSystem.cs:73-76)、OnFire (:73-75)、SmokeTrail (:87-90)、FireworksTrail (:61-64)、Puke (:109-112)、Shapeshift（属性名 Stopped，:69-72）、WhalePlume (:82-85)。宿主侧样板：ComponentOnFire.cs:60-83（创建→更新→IsStopped→置 null）。
  • 特例 Fuse：既不自杀也非共享池——Simulate 恒 false (FuseParticleSystem.cs:65)，由 SubsystemExplosivesBlockBehavior 持引用，引爆/移除时手动 RemoveParticleSystem (SubsystemExplosivesBlockBehavior.cs:163-164)。跟随型若宿主忘记收尾就会永久泄漏。

生成率累积器与拖尾插值

  • 通用模式 m_toGenerate：每帧 m_toGenerate += rate*dt，遇空位且 ≥1 激活一粒并 -1，帧末 MathUtils.Remainder 归零 (FireParticleSystem.cs:42,57-70)。速率可动态：GunSmoke 150→20/0.5s (GunSmokeParticleSystem.cs:47)、Shapeshift 15→35 渐升 (ShapeshiftParticleSystem.cs:33)、WhalePlume 按窗口开关 (:40-46)、Puke 由 SimplexNoise.Noise 驱动一阵一阵喷 (PukeParticleSystem.cs:53-55)。
  • 池寿命配平：SmokeTrail 生成率 = clamp(50/size, 10, 40)，粒子 Duration = Particles.Length/rate——池大小×寿命恰等于补充速度，粒子无缝循环 (SmokeTrailParticleSystem.cs:49,81)。
  • 高速拖尾防断点：FireworksTrail 在 m_lastPosition 与当前 Position 间随机 Lerp 取发射点，120/s (FireworksTrailParticleSystem.cs:28-31,49)。
  • 池内自繁殖：烟花拖尾形粒子 GenerationFrequency>0 时按 频率×|速度| 累积 GenerationAccumulator，>1 从池尾 m_nextParticle 分配 HighDamping 子粒子；池满即停 (FireworksParticleSystem.cs:205-221)。

世界交互与光照取样

  • 交互三档：①无交互（Kill/HitValue/Shapeshift/烟花本体）；②液面漂浮——落入 Water/Magma 块判 GetLevelHeight，Y 钳到 液面 + 0.02*sin(2*距心距 + 10*m_time) 波浪并缩尺寸 (WaterSplashParticleSystem.cs:115-125、MagmaSplashParticleSystem.cs:91-101)；③地形射线——Puke (PukeParticleSystem.cs:65-84)、Paint (:71-88)、BurntDebris (:62-81) 用 SubsystemTerrain.Raycast(IsCollidable_) + CellFace.CalculatePlane() 按轴向反射反弹；Paint 命中即粘附：速度清零、贴 HitPoint(0.03f)、侧面(算面≥4)关重力 (PaintParticleSystem.cs:78-91)。
  • 落叶落地：向下 Raycast 命中 → 切 Horizontal billboard、贴地 +0.03、延时 2s；首次落地触发 SubsystemDeciduousLeavesBlockBehavior.CreateFallenLeaves (LeavesParticleSystem.cs:114-128)；入水立即结束 (:111-113)。
  • 雨雪柱预落地：粒子到 YLimit 前 RaycastParticle 二次下探求精确表面高度，到点后委托 RainSplash/SnowSplash 生成溅花 (PrecipitationShaftParticleSystem.cs:161-192,292-310)。
  • 光照取样三式：①构造时六邻 GetCellLight 取 max 乘 LightingManager.LightIntensityByLightValue[x]、A=255（WaterSplash WaterSplashParticleSystem.cs:54-64，Kill/BurntDebris/Puke/GunSmoke 同式）；②Leaves 每帧采样但仅当 chunk State≥InvalidVertices1，用 Color.MultiplyColorOnlyNotSaturated 防饱和 (LeavesParticleSystem.cs:96-101)；③GunSmoke 把光照折成灰度色 (GunSmokeParticleSystem.cs:41-42)。
  • Draw 门控反馈环：Fire/OnFire/Fuse 在 Draw 里按视线点积+距离判 m_visible，Simulate 只在 m_visible 帧生成粒子（FireParticleSystem.cs:79-87+:41、OnFireParticleSystem.cs:79-86+:33、FuseParticleSystem.cs:68-76+:31）——远处火焰零生成成本；Explosion 反向：空池时 Draw 直接跳过 (ExplosionParticleSystem.cs:78-82)。

模组新增粒子系统的步骤（全代码路，无数据表入口）

  1. 新类继承 ParticleSystem<MySystem.Particle>，内嵌 Particle : Game.Particle 补 Velocity/TimeToLive 等字段（全部 public 可继承，ParticleSystemBase.cs:28、ParticleSystem.cs:5、Particle.cs:4）。
  2. 构造里 base(count) 定容量；Texture = ContentManager.Get<Texture2D>("Textures/FireParticle")（mod 放 Assets/Textures/Xxx）；TextureSlotsCount = n；初始化各粒子字段（参照 BlockDebrisParticleSystem.cs:19-22,51-59）。
  3. 覆写 Simulate(dt)：更新位置/寿命/颜色，return !alive;（BlockDebrisParticleSystem.cs:109 样式）；跟随型加 IsStopped 协议见"生命周期三形态"C 条。
  4. 任意主线程时机（覆写方块 CreateDebrisParticleSystem、SubsystemBlockBehavior 回调、Component.Update、自注册 IUpdateable）：project.FindSubsystem<SubsystemParticles>(true).AddParticleSystem(new MySystem(...))。
  5. 要挂弹道拖尾再实现 ITrailParticleSystem（Position+IsStopped，ITrailParticleSystem.cs:4-8），SubsystemProjectiles.AddTrail(projectile, offset, trail) (SubsystemProjectiles.cs:185)——仅弹射物消费此接口。

坑与对策

  • AddParticleSystem 静默失败：实例已被持有（复用同一对象）→ 不报错不显示。→ 先 ContainsParticleSystem(ps)，或传 throwOnAlreadyAdded: true 逼异常 (SubsystemParticles.cs:43-45)。
  • 粒子永不消失、帧率持续掉：没覆写 Simulate（基类恒 false）。→ 按活跃计数返回 true；跟随型按 C 条协议。
  • 把 ParticleSystemsSimulate=false 当"关粒子"：Draw 照跑且系统永被冻结。→ 用它做暂停特效；真关用 ParticleSystemsDraw。
  • 运行中改 Texture/容量：打破 GetBatchDemands 恒定契约 → 预扩容账本错乱/扩容不足。→ 生命周期内恒定；会换纹理就学雨雪柱对全部可能纹理恒报上界 (PrecipitationShaftParticleSystem.cs:92-103)。
  • 碎屑采到邻格贴图：纹理槽 16→32 换算 (slot%16*2 + rand + 32*(slot/16*2 + rand)) (BlockDebrisParticleSystem.cs:59)。→ 自带纹理的构造重载自己算 slot。
  • 远处方块破坏无碎屑：16 格距离门控 + DestructionDebrisScale=0。→ SubsystemTerrain.cs:460-467、Block.cs:503。
  • 自己排 quad 却看不见：批次 Layer/混合态与默认不同，或忘走 AlphaTested shader 灌雾。→ 照抄 SubsystemParticles.cs:133-152 的统一刷新路径。
  • 常驻池满静默丢粒子：RainSplash/SnowSplash/Explosion 的 AddXxx 找不到空位直接放弃（如 RainSplashParticleSystem.cs:34-69 无 else 分支）。→ 容量给够或自行排队。
  • 绕过水花限流：WaterSplash 单帧实例化上限 100，调用方必须先 TryBeginInstantiation() 领配额 (WaterSplashParticleSystem.cs:34-44；调用点 ComponentBody.cs:591、Pickable.cs:354、Projectile.cs:576)。→ 批量仿写时同类限流。
  • 每粒子每帧地形射线：Puke/Paint/BurntDebris 在 Simulate 内逐粒子 SubsystemTerrain.Raycast，CPU 随容量线性涨。→ 压容量/寿命，或学水花只在液面判定。
  • 跟随型忘记收尾：Fuse 不自杀靠宿主手动 Remove (SubsystemExplosivesBlockBehavior.cs:163-164)；宿主崩了/漏调 → 系统永久在场每帧空转。→ 照抄 ComponentOnFire.cs:81-83 的 IsStopped+置 null 收尾。
  • 烟花拖尾子粒子抢池：自繁殖从 m_nextParticle 顺延，初爆粒子越多拖尾越少 (FireworksParticleSystem.cs:208-209)。→ 仿写时给拖尾预留池容量。
