方块系统

域: SC引擎 · 更新: 2026-10-31 · 状态: 全读(304/304 全量实读；A27 将 266 签名级升为全文深读)，304 文件逐行明细见 04a-方块明细.md

一句话定位

方块 = "每类一个实例 + 1024 格静态注册表 + value 位打包"，Block 基类 116 个虚方法按系统分组在加载/渲染/物理/交互/挖掘各阶段被调用；形状家族各自继承中间基类并在 data 位里编码朝向/开合/染色/液位。

核心机制

方块对象模型与 value 位打包

  • 每类一个实例：m_blocks = new Block[1024](BlocksManager.cs:30)，Blocks 属性(:42)；查找字典 BlockNameToIndex/BlockTypeToIndex(:48-49)，查询入口 GetBlockIndex&lt;T&gt;()(:188-190)。
  • 一格 int = contents(低10位) | light(10-13位) | data(14位起)：Terrain.cs ContentsMask=1023(:64)、LightShift=10(:68)、DataShift=14(:72)；ExtractContents/ExtractLight/ExtractData(:311-315)。data 高位又被 GetDamage 借用存损伤(Block.cs:457-464)。
  • csv 列名 = Block 子类的 public 非静态实例字段(BlocksManager.cs:1063-1067)；Block 本体就有约 70 个 public 字段(Bean 属性面见 Block.cs:8-181)。

注册与 ID 分配(两段式)

调用链：启动 LoadingScreen.cs:533 BlocksManager.Initialize()(BlocksManager.cs:122-129) → InitializeBlocks(null)(:281-405)：

  1. 按 ModsManager.ModList 顺序遍历各模组 BlockTypes，Activator.CreateInstance(:290)；
  2. 读 public static int Index 作初值，没有则 -1(:294-303)；
  3. 同名类去重——后注册者把先注册者踢出待分配列表(:307-313)，即"同名覆盖原版方块"路线；
  4. 静态块(原版实体/IsIndexDynamic=false)先按原编号落位(:328-356)；
  5. BlockAllocateDataComparer 排序(:64-91)：同 mod 聚拢保证 BlockIndex 连续，再按类名；
  6. 进世界时 SubsystemBlocksManager.Initialize(:23-28) 重跑一遍 InitializeBlocks(this)+PostProcessBlocksLoad，CallAllocate(:32) 按存档里"类名→索引"(DynamicBlockNameToIndex)复旧编号(:360-374)；
  7. 剩余动态块从 300(=299+1，SurvivalCraftBlockCount :58) 顺排(:377-400)，到 1024 抛 Too many blocks!(:379-380)，空槽填 Air(:402-404)。

AllocateBlock(:93-120) 负责写表 + 反射回写 public static int Index(:108-119)，IsLiteral(const) 被跳过。分配顺序 → 存档只存"类名→索引"(SubsystemBlocksManager.cs:19)，所以改类名 = 老世界方块串台。注意：本目录没有 BlockLoader 类——注册统一走 BlocksManager 扫描。

形状家族渲染套路(Initialize 预烘 + 运行期查表)

标准做法：Initialize() 里把全部 data 变体的 BlockMesh/碰撞盒一次性烘焙（16/24/48 个变体循环），运行期 GenerateTerrainVertices/GetCustomCollisionBoxes 只做数组下标取用——门 16 变体(DoorBlock.cs:21-62)、楼梯 24×2(StairsBlock.cs:26-104)、活塞 48(PistonBlock.cs:12-70)、栅栏 16(FenceBlock.cs:42-192)。新写异形方块照此模式，不要在顶点阶段现算矩阵。

交叉域行为虚方法(实读补充)

  • 同族液体判定：FluidBlock.Initialize 反射找"继承 FluidBlock 的直接子类"作为同族标准，同族间不画面、放置互通(FluidBlock.cs:23-43)——WaterBlock/WaterPlantBlock/BottomSuckerBlock 一族、MagmaBlock 一族。
  • 板合并整块：SlabBlock ctor 带 fullBlockIndex，同板上下相贴放置时直接换成整块并把染色经 IPaintableBlock.Paint 转移(SlabBlock.cs:139-152)；挖整块时板不掉落(:167-183)。
  • 连接类方块靠 BlockBehavior 回写：栅栏连接(SubsystemFenceBlockBehavior.cs:22-31 调 ShouldConnectTo)、楼梯转角(SubsystemStairsBlockBehavior.cs:91/:190 调 SetCornerType)——方块类只提供谓词/位工具，拓扑计算在行为子系统里。
  • 腐烂/损坏变体：FoodBlock.GetDamageDestructionValue 返回构造传入的腐烂值(FoodBlock.cs:60)；桶类坏掉掉空桶(MilkBucketBlock.cs:53)；蛋损坏=孵化/消失(EggBlock.cs:143)。
  • AdHoc 程序化合成：不需要配方表，方块自己解 ingredients——服装染色(ClothingBlock.cs:189)、地毯(CarpetBlock.cs:103)、家具组合(家具+按钮→电按钮等, FurnitureBlock.cs:436-542)、烟花(FireworksBlock.cs:195)、LED 染色(LedBlock.cs:92)。
  • IsMovableByPiston 惯例：壁挂电器仅能从挂面推且 isEnd=true(MountedElectricElementBlock.cs:17-21)；梯子仅从墙面推(LadderBlock.cs:112-116)；门/活板门/海星不可推(DoorBlock.cs:244 等)；活塞头/家具可推。
  • 水流种植约束：IsSuitableForPlants 控制种子可放性——泥土/草/耕地 true，南瓜 false(DirtBlock.cs:5、BasePumpkinBlock.cs:248)。

坑与对策

  • static int Index 写成 const：回写跳过 IsLiteral(BlocksManager.cs:112)，字段值永远是手填的数 → 换存档必错。对策：留空走动态分配或普通 public static int Index。
  • csv 类名拼错只有一行 Warning：方块照常进世界但属性全默认(BlocksManager.cs:1057-1059)。对策：验收先搜日志 Warning。
  • csv 写 New-/Remove 列：被当陌生字段名抛异常，整份 csv 失效(:1074-1075)——csv 没有指令层。
  • #引用动态模组方块：引用的是"分配那一刻"的 BlockIndex，模组方块编号随存档变 → 掉落物跨存档可能指向别的方块。对策：dll 里用 GetBlockIndex&lt;T&gt;()。
  • 同名类静默串台：两个 mod 的方块同名，后注册者踢掉前者(:307-313)，存档按类名恢复时互相顶替。对策：类名加 mod 前缀。
  • DefaultIsUseable=FALSE 不生效：挂了 OnUse 行为的方块加载时被强制回 true(SubsystemBlockBehaviors.cs:43)。
  • Initialize() 抛异常不崩游戏：被吞成一条 Warning(:416-418)，后续 GetCreativeValues 不执行，方块分类缺失。
  • BlockIndex 是 public 字段，csv 也能写它(:1063 不过滤) → 身份错乱；数据表里永远别写这列。
  • 石斧不走 AxeBlock：StoneAxeBlock 直接继承 Block(StoneAxeBlock.cs:5)，按材质补工具时别默认"所有斧都在 AxeBlock 子类里"。
  • 双实体方块：LitFurnaceBlock 继承 FurnaceBlock 且 new static Index=65(LitFurnaceBlock.cs:3)——同一模型两个 ID；想"点亮态换方块"照抄这对，但注意两者是独立注册实体。
  • new const/new static Index 检索陷阱：KelpBlock.cs:6/SeagrassBlock.cs:6/SeaUrchinBlock.cs:6/StarfishBlock.cs:6/LitFurnaceBlock.cs:3 用 new 隐藏基类成员，反编译/搜索时按类名找，别按继承链找。
  • 异形方块顶点期现算矩阵：会每帧重复算；原版全部 Initialize 预烘变体表（见"渲染套路"节）。
