服饰与装备（穿戴·防御·叠层渲染全链）

域: SC引擎+数据 · 更新: 2026-11-01 · 状态: 全链今日实读（ComponentClothing / ClothingData / ClothingBlock / ClothingSlot / Attackment / ComponentOuterClothingModel 六文件全文 + Clothes.xml·Clothes.xsd·BlocksData.txt·CraftingRecipes.xml 节选，行号均本日现行代码） · 关联: 16-玩法物品与背包 · 22-数据资产与Database · 数据格式参考2

一句话定位

一件衣服 = 方块 203（ClothingBlock）的一个 data 编码值；属性在 Clothes.xml 的 <ClothingData>（43→38 条，见文末出入清单）；穿上身是往 ComponentClothing.m_clothes[槽位] 列表追加（可叠层），防御在 Attackment.CalculateInjuryAmount 内先于扣血结算，渲染是把每件衣服整图按染色叠画进两张合成贴图再覆盖到人体模型。

1 数据层：一件"衣服"是什么

1.1 载体结论（Database.xml vs Clothes.xml vs .clo）

载体存什么证据
Survivalcraft/Content/Assets/Clothes.xml原版全部 38 条 <ClothingData>（根 <Clothes>，49 行）今日 grep 计数 38；条目行见文件本体
Database.xml不存衣物条目（grep ClothingData = 0）。只存 MalePlayer/FemalePlayer 实体模板上的 Clothing 组件模板（Database.xml:400）与 OuterClothingModel 组件参数（女 :3306 Models/OuterClothingFemale、男 :3341 Models/OuterClothingMale）今日实读
.clo（mod 包内）mod 的 Clothes.xml 增量文件：按扩展名被抓取后 CombineClo 合并进同一 XElement 树ModEntity.cs:344-359、ModsManager.cs:938-983
BlocksData.txt:163ClothingBlock 方块级属性一行：CraftingId=clothing、Density=0.5、Durability=15、MaxStacking=1今日按表头列位解析

装载路径：原版本体伪装成"基础 mod"（SurvivalCraftModEntity）走同一条 mod 管线——LoadClo 从 ContentManager 取 Clothes（SurvivalCraftModEntity.cs:134-138），ClothingBlock.Initialize 里 ModListAllDo(LoadClo) 收树后 LoadClothingData 展开（ClothingBlock.cs:60-64）。CombineClo 合并规则：同 Index + New- 前缀属性=字段级改写；r-/Remove 属性=删条目；否则追加（ModsManager.cs:949-965）。

1.2 value 编码：一件衣服 = 203 号方块 + data 位域

Terrain.MakeBlockValue(203, 0, data)，data 位域（ClothingBlock.cs:160-166, 270-280）：

位内容读写
0-7 + 16-17衣物 Index（10bit，0-1023；XML 侧 &1023 截断）GetClothingIndex/SetClothingIndex ClothingBlock.cs:271-276
8-11损伤 0-15（Durability=15 刚好用满 4bit）GetDamage/SetDamage ClothingBlock.cs:160-166
12-15染色号 0-15（0=本色；调色板=世界 Palette 16 色、饱和度 ×0.85）GetClothingColor/SetClothingColor :278-280；SubsystemPalette.cs:92-102

染色值存在物品 value 里随存档走（不是存在 ComponentClothing）；GetColor 运行时查 SubsystemPalette.GetFabricColor（ClothingData.cs:234-237）。

1.3 ClothingData：XML 18 属性 → 实例字段

解析：ClothingBlock.LoadClothingData（ClothingBlock.cs:25-58，Class 属性可指定 ClothingData 子类，须有 (XElement) 构造器）+ 构造器逐属性读取（ClothingData.cs:11-53）。属性全表见数据格式参考2（该页 18 属性 schema 今日复核一致）。字段侧另有三个代码挂点（数据写不了）：

  • Mount / Dismount / Update：三个 Action<int, ComponentClothing>，穿戴/脱下/每帧回调（ClothingData.cs:96-106；Update 调用点 ComponentClothing.cs:323-336）；
  • DictionaryForOtherMods：mod 间联挂数据袋（ClothingData.cs:111）；
  • 四个 virtual：ApplyArmorProtection / UpdateGraduallyDamagedOverTime / OnClotheSet / GetColor 可被子类覆写（:122/:175/:224/:234）。

1.4 槽位：ClothingSlot 可扩展

  • 内置 4 槽 Head/Torso/Legs/Feet，注册进 ClothingSlot.ClothingSlots 字典（ClothingSlot.cs:27-30）；mod 经 InitializeClothingSlots 钩子加新槽（:39-45，注意不可 Clear 重建——引用相等作字典键）。
  • 每槽自带 BasicInsulation：Head=2、Torso=0.2、Legs=0.4、Feet=2（:35-38），是"该槽裸露程度"基数。
  • 部位不是"四格格子"而是每槽一个有序列表：m_clothes[slot] : List<int>，可叠层自由穿（见 §2）。

2 穿戴链：从背包拖到身上

  1. 容量问询：把物品拖上衣服槽前 UI 先问 GetSlotProcessCapacity → CanWear(value) 且 CanWearClothing 通过则回 1（ComponentClothing.cs:426-449）。
  2. 叠层规则：CanWearClothing 只看同槽最外层——新衣 Layer 必须严格大于当前最外层（ComponentClothing.cs:567-584，:583）。所以 Layer 是"同槽内穿几次"的深度序号，不是全局四层。
  3. 穿上：ProcessSlotItems（InventorySlotWidget.cs:599-601 触发）→ Mount 回调 → 同槽列表 Append → SetClothes（ComponentClothing.cs:521-529）。
  4. SetClothes 是唯一改衣入口（ComponentClothing.cs:129-159）：全量重算——各槽保温=BasicInsulation+Σ衣服 Insulation（经 OnClotheSet，ClothingData.cs:224-228）、坐骑移速因子连乘、密度修正加到 ComponentBody.Density（:148-149）、m_clothedTexturesValid=false 触发贴图重合成、末尾 ⚡SetClothes 钩子（:152-158）。
  5. 脱下：RemoveSlotItems 只弹最外层一件（list[^1]）+ Dismount 回调（ComponentClothing.cs:532-546）。
  6. 存档：每槽 ; 分隔 int 列表写进实体 Clothing 组件的 Clothes 子字典（:295-301）；出生默认衣由 PlayerData.SpawnPlayer 按皮肤硬编码注入同一结构（PlayerData.cs:573-629，MakeClothingValue :700-702）。
  7. UI：衣服页固定摆 4 个槽 widget（StableId 0-3），格子只显示 GetSlotValue=最外层（ClothingWidget.cs:33-54；ComponentClothing.cs:415）——UI 一格，身上一层叠一层。死亡掉落也是每槽只掉最外层一件（DropAllItems，ComponentClothing.cs:548-561）。

3 防御结算链：挨打时衣服怎么挡

入口：Attackment.ProcessAttackment → ProcessAttackmentToCreature → CalculateInjuryAmount（Attackment.cs:213/:137/:82）。

  1. 护甲先于扣血：CalculateInjuryAmount 内 EnableArmorProtection 时取目标的 ComponentClothing.ApplyArmorProtection(this)（Attackment.cs:90-95），返回削弱后的攻击力，随后才过韧性（ResilienceFactor，:96-101）和 ComponentHealth.Injure（:148）。
  2. 随机选槽：一次攻击只结算一个槽——10% Feet / 20% Legs / 60% Torso / 10% Head（ComponentClothing.cs:185-188）。⚡mod 可经 DecideArmorProtectionSequence 改名单、ApplyProtectionBeforeClothes/AfterClothes 前后插手（:190-205/:246-252）。
  3. 单件吸收公式（ClothingData.ApplyArmorProtection，ClothingData.cs:122-167）：

吸收 = min(剩余攻击力 × saturate(ArmorProtection / attackment.ArmorProtectionDivision), 剩余Sturdiness)（:130-135）。 剩余 Sturdiness 按损伤比例折减：(maxDurability - damage) / maxDurability × Sturdiness（:131）。ArmorProtectionDivision 是给 mod 强攻留的除数（Attackment.cs:66-71）。 多件同槽：列表序逐件吃同一攻击（ComponentClothing.cs:208-228），每件只扣自己 Sturdiness 上限。

  1. 耐久损耗：非创造（GameMode≠0）才扣——DamageItem 按吸收量折算损伤数（ClothingData.cs:138-141）；损伤超 Durability=15 → GetDamageDestructionValue=0 物品销毁（BlocksManager.cs:1011-1035、Block.cs:466），结算后从身上剔除+碎屑粒子（ComponentClothing.cs:230-239）。衣服会穿坏，原版无修补。
  2. 自然磨损：走路/游泳/跳跃时每 2s 检查一次（ComponentClothing.cs:373-376），每件按 湿身 10×Sturdiness : 干爽 20×Sturdiness 秒的间隔 75% 概率 +1 损伤（ClothingData.cs:175-218），坏时屏幕提示；创造或未开冒险生存机制则豁免（:177-179）。等级限制同门：EnableDressLimit 每 0.5s 踢掉超 PlayerLevelRequired 的衣服（ComponentClothing.cs:338-372）。
  3. 结算完按 Layer 升序重排该槽（ComponentClothing.cs:240-245）再 SetClothes 写回。

4 渲染叠层链：Layer/IsOuter/染色怎么变画面

核心：两张离屏合成贴图，不是逐件 3D 贴模型。

  1. ComponentClothing.UpdateRenderTargets（每帧尾，ComponentClothing.cs:586-709）：加载玩家皮肤纹理，建两张与皮肤同尺寸 RenderTarget（:597-610）。
  2. 内层 RT：先整图铺皮肤，再按内层槽序（Head→Torso→Feet→Legs，Load 时 Reverse(2,2) :260-262）遍历所有衣物，只画 IsOuter=False 的：每件衣服贴图作为一整张同 UV 布局 quad 乘染色色盖上去（:611-667，非外衣 quad :655-664）。外层 RT 同理只画 IsOuter=True（外层槽序 Head→Torso→Legs→Feet，:668-702）。
  3. 同槽多件按列表序（=Layer 升序）叠画 → 后画的盖先画的；Layer 本身不参与跨槽绘制排序，跨槽遮挡由固定槽序决定。
  4. 合成结果覆盖到模型：m_innerClothedTexture → ComponentHumanModel.TextureOverride，m_outerClothedTexture → ComponentOuterClothingModel.TextureOverride（:601/:608）；渲染器统一用 TextureOverride 替换模型贴图（SubsystemModelsRenderer.cs:400-401/:512-513；属性定义 ComponentModel.cs:102）。
  5. 外层是独立 .dae 模型（OuterClothingMale/Female，4 网格 Leg1/Leg2/Body/Head，ComponentOuterClothingModel.cs:44-51），每帧从人体模型拷骨骼变换（:24-27）；模型名取自 Database.xml 实体模板（CharacterSkinsManager.cs:211-223）。贴图纹理仍从 RT 来——所以外衣贴图也是"皮肤 UV 全图"。
  6. 第一/三人称：第三人称身体+外衣模型都吃合成贴图；第一人称只画手，用内层合成贴图（ComponentFirstPersonModel.cs:190；VR 手同理 ComponentVrHandsModel.cs:112）——外衣在第一人称不可见。
  7. 染色生效点就在第 2 步的 quad 乘色（GetColor→SubsystemPalette.GetFabricColor）；掉在地上/拿在手里则是 ClothingBlock.DrawBlock 用原版人体 mesh + 槽位变换 + 染色直接画（ClothingBlock.cs:292-332；拾取框 GetDrawDemand 按 IsOuter 选内/外 mesh :284-290）。
  8. 自定义玩家模型（UV 与原版皮肤不同）可关掉合成：ValuesDictionary ShowClothedTexture / DrawClothedTexture（ComponentClothing.cs:70-83/:286-287；注意当前实现是 static 字段，注释称"实例级"但实为全局开关）。

5 保温/移速：属性的消费端

  • 保温：整身 Insulation = 1/Σ(1/各槽保温)（调和平均，ComponentClothing.cs:113-127），ComponentVitalStats 消费时按湿身线性衰减到 5%（ComponentVitalStats.cs:519）；LeastInsulatedSlot 用于"哪个部位最冷"提示（ClothingSlot.cs:31-34 的文案）。
  • 移速：MovementSpeedFactor 经 ComponentLevel.GenerateSpeedFactors 汇入 ComponentFactors.SpeedFactor（ComponentLevel.cs:197-223，衣物项 :208/:364-374），ComponentLocomotion 乘进步速（ComponentLocomotion.cs:414/:453）；SteedMovementSpeedFactor 则只作用于坐骑（ComponentLocomotion.cs:419-423）。赤脚提示读 Feet 槽最外层的 MovementSpeedFactor>1（:457-475）。

8 mod 视角：自定义一件服饰

纯数据路线（.scmod 包内，零代码）：

  1. 包内放任意名 .clo 文件（按扩展名抓取，ModEntity.cs:349-357），根 <Mod>（Clothes.xsd:10 同义根），内放 <ClothingData Index="50" Slot="Torso" ArmorProtection="0.5" Sturdiness="40" Insulation="4.0" IsOuter="False" CanBeDyed="True" Layer="2" TextureName="Textures/Clothing/MyJerkin" DisplayName="[ClothingBlock:50]" Description="[ClothingBlock:50]" />。Index 取 0-1023 内未占值（原版占 0-37；同 Index 后载者直接覆盖字典项 ClothingBlock.cs:53）。
  2. 包内贴图 Assets/Textures/Clothing/MyJerkin.*——与皮肤同 UV 布局的整图（原版范本 Survivalcraft/Content/Assets/Textures/Clothing/，webp）。画多少身体区域就穿出多少。
  3. Lang 里补 ClothingBlock:50 的 DisplayName/Description 键（[...] 令牌在 ClothingData.cs:14-27 展开）。
  4. 合成：包内 .cr 加 Recipe Result="clothing:50" ...（原版同时存在 ClothingBlock:30 与 clothing:11 两种写法，CraftingRecipes.xml:943/:1041）。
  5. 改原版衣服：同 Index + New- 前缀属性做字段级覆盖；Remove="true"/r- 删条目（ModsManager.cs:949-962）。

什么时候才要代码：改防御公式→Class 指向 ClothingData 子类覆写 ApplyArmorProtection；穿戴特效/每帧逻辑→代码里给实例的 Mount/Dismount/Update 赋值；新槽位→AddClothingSlot+InitializeClothingSlots 钩子。染色/叠层/保温/耐久全部数据自带，不用写一行。

最简照抄：CottonTankTop（Index 15，上表首行）属性最少、无音效；要染色的抄 CottonShirt（13）。
