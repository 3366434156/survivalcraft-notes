输入与相机

域: SC引擎 · 更新: 2026-10-31 · 状态: 全读(Engine.Input 19/19 + Camera 族 13/13 + ComponentInput/TouchInputWidget/VrManager/PlayerInput 全文，WidgetInput/GameWidget 定区段深读；OpenXrVrBackend.cs 1690 行未深读)

一句话定位

物理设备(Keyboard/Mouse/Touch/GamePad/Multi*/VR)→语义输入(WidgetInput)→玩家动作(PlayerInput)的分层分发，Camera 类族、切换与投影机制。

  • 帧末 AfterFrame 清 Once/LastKey/LastChar 并推进连发计时；Dispatcher.Dispatch 排队的动作看到的是上一帧输入。

Multi* 分屏输入与设备位图

MultiKeyboard/MultiMouse 是 4 槽位静态类(MultiKeyboard.cs:25、MultiMouse.cs:26)，状态字段与 Keyboard/Mouse 同构(连发同 0.3s/0.04s 节奏，MultiKeyboard.cs:21-23)。ProcessXxx 全是 private 且引擎内无喂入口——桌面端 4 槽位恒空，是分屏本地多人的预留通道。唯一消费方是 WidgetInput：按 WidgetInputDevice 位标志逐槽位轮询(Keyboard 优先于 MultiKeyboard1..4，WidgetInput.cs:99-107；位→索引映射 (2&lt;&lt;i)/(64&lt;&lt;i)/(2048&lt;&lt;i))。手柄聚合是求和再归一化：GetPadStickPosition 把 4 个手柄的杆相加、模长>1 才归一(WidgetInput.cs:497-507)，扳机取 min(:509-520)。鼠标还有 IsMouseButtonUpOnce(MultiMouse.cs:47-48)与移动指数曲线 PowSign(move,1.25)(:98-99)。

语义层 WidgetInput

  • 触摸手势(UpdateInputFromTouch :939-990)：HitTest 命中才起(：942)；Moved 超过 SettingsManager.MinimumDragDistance*GlobalScale 转 Drag(:965)；超 MinimumHoldDuration 转 Hold(:974)；松开帧产生 Click=Segment2(起点,终点)(:982)。默认值：drag 10px、hold 0.25s(SettingsManager.cs:675-676)。
  • VR UI(UpdateInputFromVrControllers :992-1054)：右手柄射线与 VrQuadMatrix 平面求交得 VrCursorPosition(：995-1007)；左手柄 Trackpad 四方向→Left/Right/Up/Down(:1009-1032)；Grip/Menu→Back/Cancel(:1033-1039)；Trackpad/Trigger→Any(:1040-1045)；Trackpad 上下或右杆 ±0.5→Scroll(:1046-1054)。VR 游标在 Draw 里画白圆盘(:735-739)。
  • 软鼠标光标：UseSoftMouseCursor 时位置钳在 Widget 边界内、Draw 画 PadCursor 贴图(:706-722)；硬光标走 Mouse.SetCursorType(:721)。

手柄修饰键与组合键系统

扳机既是动作又是修饰键：IsTriggerDownOnce 只在松开帧算按下(注释原话"扳机必定是修饰键"，GamePad.cs:346)，且若该扳机刚参与过组合键(ModifierKeyOfCurrentCombo 匹配，:338-341)则本帧不触发。SetModifierKeyOfCurrentCombo(:391)记录组合键用的修饰键；AfterFrame 在所有修饰键松开时重置标记(GamePad.cs:465)。WidgetInput 侧同名透传：IsPadTriggerDown/IsTriggerDownOnce/SetModifierKeyOfCurrentCombo/IsAnyModifierKeyHolding(WidgetInput.cs:522-610)。

Camera 类族与模式

基类 Camera(Game\Camera.cs:5-57，58 行)：抽象 ViewPosition/ViewDirection/ViewUp/ViewRight/ViewMatrix/InvertedViewMatrix/ProjectionMatrix/ScreenProjectionMatrix/InvertedProjectionMatrix/ViewProjectionMatrix/ViewportSize/ViewportMatrix/ViewFrustum(:10-34) + UsesMovementControls/IsEntityControlEnabled(:36-38) + WorldToScreen/ScreenToWorld(:42-46，直接用 Viewport.Project/Unproject) + Activate(previousCamera)(:48) + Update(dt)(:50) + PrepareForDrawing(:51-56，VR 重载带 Eye)。

BasePerspectiveCamera 全属性惰性缓存、PrepareForDrawing 统一置 null 失效(BasePerspectiveCamera.cs:197-207)。关键实现：

  • SetupPerspectiveCamera(pos,dir,up)(:211-216)是所有派生相机的唯一姿态写入口。
  • ViewMatrix 非 VR=CreateLookAt；VR=LookAt×EyeToHead 逆(:42-56)。
  • ProjectionMatrix(:68-86)与 ScreenProjectionMatrix(:88-110)把投影再乘 ViewWidget 的 UI 变换(半个视口缩放+GlobalTransform+反归一)——屏幕坐标直接可用。
  • CalculateBaseProjectionMatrix(:222-241)：FOV=80°×SettingsManager.ViewAngle(:73)，near 0.1/far 2048；末尾挂模组钩子 ModsManager.HookAction("RecalculateCameraProjection", …)(:233-239，改 FOV/近远平面在此改，无需 RegisterHook 的 HookAction 机制)。
  • ViewportSize/ViewportMatrix 处理 ScalingRenderTarget 与 VR swapchain(:137-180)；ViewFrustum 缓存 BoundingFrustum(:182-195)。

坑与对策

  • 键位注册了但不生效/界面没有：没重写 GetKeyboardMappings()，或两个 Loader 返回同名键(ValuesDictionary.Add 抛，后半模组键位全丢)→ 映射名加模组前缀。
  • IsKeyOrMouseDownOnce 永远 false：值类型不是 Key/MouseButton 直接 return false；Key.Null(=禁用)也 false。
  • UpdateInput 不跑：没 RegisterHook("UpdateInput", this)；异常只报第一次后静默。
  • 写 ValuesDictionaryForMods 抛 NRE：m_playerInput = default 绕过 struct 初始化器(PlayerInput.cs:6/:72)→ 每帧判空。
  • 死亡/睡觉时输入被抹：闸门整体换白名单结构体(ComponentInput.cs:93-105)→ 自定义数据每帧重写；Camera* 与 5 个环境开关保留。
  • 自建相机读 Move/Look 失灵：UsesMovementControls=true 时 Move/Look/Jump 被清零(ComponentInput.cs:107-114)→ 像 OrbitCamera 一样读 PlayerInput.CameraLook/CameraMove/CameraCrouchMove。
  • 组合键误触/不触发：修饰键按住时普通按钮被闸门拦；扳机 Once 在松开帧且参与过组合键的帧被抑制(GamePad.cs:338-346)。
  • 多手柄杆值串味：GetPadStickPosition 把 4 槽求和再归一(WidgetInput.cs:497-507)→ 单手柄场景确认只有一个 GamePadN 位。
  • GamePad 传参越界直接抛：index 出 0..3、deadZone∉[0,1) 都 throw(GamePad.cs:294-295/:298-300/:317)。
  • Touch.IsTouched 当"正被触摸"：永真锁存(Touch.cs:122)→ 用 TouchLocations 或 IsControlledByTouch。
  • 点击事件重复触发：TouchLocation 一次点击存活 2-3 帧(ReleaseQueued 机制，Touch.cs:87-104)→ 按 Id 去重。
  • **Multi* 槽位永远没数据**：ProcessXxx 私有、引擎无喂入口(MultiKeyboard.cs:100-132)→ 反射喂数或自己桥接到静态类。
  • VR 矩阵全零：后端 null 时 VrManager.HmdMatrix 返回 default(Matrix)(VrManager.cs:46-48)→ 先判 VrManager.IsFrameActive(:41)。
  • VR 模式不渲染：EndFrame 只在 RenderToEyes 被调过才提交，否则提交空层防残影(VrManager.cs:233-244)→ 每帧必须走 RenderToEyes。
  • 注册相机切不过去：没在 ManageCameras 里 AddCamera，或 GetCameraList 值写成负数被禁用；注册名必须是类型全名 Game.XxxCamera；重排后序号会压缩(GameWidget.cs:85-93)，别存注册值当持久索引。
  • 改 FOV 找错地方：投影在 CalculateBaseProjectionMatrix(BasePerspectiveCamera.cs:222-241)，模组钩子 RecalculateCameraProjection 直接改 ref result。
