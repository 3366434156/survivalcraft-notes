学习路线（给人：三条路 + 概念词典）

更新: 2026-11-01 · 这是给人类读者的入口页；AI agent 请直接看 AGENTS.md。 全库 24 个主题页结构统一（一句话定位 → 目录地图 → 核心机制 → 坑与对策 → 原版范例 → 快查路由），页内行号即源码出处（源码仓库 https://gitee.com/SC-SPM/SurvivalcraftApi ），不克隆源码也能完整阅读。

先选你的路

路线一：我就想做个 mod（最快 2 小时闭环）

  1. 10 分钟——读 AGENTS.md 的"引擎 30 秒心智模型"8 条：双层结构/帧链/子系统/组件袋/方块编码/存档双轨/数据优先/电力步进。这 8 条能避免 80% 的方向性错误。
  2. 30 分钟——抄一个端到端示例，跑通"打包→装载→验证"全流程（这是 mod 开发的真正门槛，和写什么无关）：
  • 纯数据改数值 → Mod示例-数据驱动
  • 加一个会发光的方块 → Mod示例-代码方块
  • 加一个自定义电力元件 → Mod示例-电力元件
  • 加一只自然生成的生物 → Mod示例-自定义生物
  • 加一个自己的界面 → Mod示例-自定义界面
  • 加自定义粒子特效+音效 → Mod示例-自定义特效
  1. 做自己的东西——"我想做 X"查 Mod开发配方（23 域任务 → 照抄哪段原版代码），打开对应源码核对行号，照抄改造。
  2. 出问题——按症状查 Mod排错手册/2（250 条），先查 AGENTS.md 的高频坑 Top10 再深挖。

路线二：我想读懂引擎（按序读，主干 5 页 + 自选分支）

主干按依赖顺序，读这 5 页就能建立完整骨架：

序页为什么在这
101-程序入口与主循环一帧从哪开始、到哪结束——后面的页都挂在帧链上
202-Subsystem体系世界=40+ 子系统互相 tick，这是游戏层的组织方式
303-实体与组件体系一切活动物（玩家/生物/掉落物）= 组件袋
404-方块系统世界由 int 编码的方块组成，contents+data 位是全库最重要的编码
511-存档持久化双轨制落盘规则——不读它，写任何有状态的 mod 都会踩坑

之后按兴趣选分支，互不依赖可跳读：

  • 画面向：06-渲染管线 → 07-粒子 → 14-光照天空与天气
  • 玩法向：15-电学与机构 → 16-玩法物品与背包 → 05-世界与地形生成
  • 交互向：09-UI与Widget → 17-Screen → 18-Dialog → 10-输入与相机
  • 平台向：12-ModAPI与加载链 → 20-内容与资源管理 → 21-Engine核心运行时 → 23-内嵌浏览器
  • 资产向：22-数据资产与Database → 08-音频 → 19-媒体动画与VR → 13-物理与碰撞

读法建议：每页先读"核心机制"再看"坑与对策"；要查某个文件去各主题页链接的逐文件明细（01-引擎\明细\ 20 张，一行一文件）；想核行号就克隆源码仓库直接跳。

路线三：我有问题要查（查询式）

  • 报错/不生效/崩溃 → Mod排错手册/2 按症状找条目，每条带根因和锚点。
  • "这件事在引擎里怎么走完整一遍"（找挂点/断点） → 24-机制全链：挖方块/放置/实体一帧/生物一生/电路一步/加载保存六条链，每步带出处和 mod 挂点。
  • 查某类钩子/数据格式 → Mod钩子总表（236 钩子）/ 数据格式参考/2。
  • 查某文件在哪 → 对应主题页的"目录地图"节，或逐文件明细。
  • 查到库里没有的 → 欢迎按 AGENTS.md §7 回写贡献。
