Mod 开发配方（任务 → 照抄原版代码）

独立库 · 更新: 2026-10-31 · 状态: 23 域全量收录；后续新批次随批补最典型范例 本表只含 Survivalcraft 原版实现；mod 侧用法案例不在本库收录范围。

这本配方怎么用

写 mod 时遇到"我想做 X"，三步：

  1. 在下表找到你要做的事，右边就是引擎里最值得照抄的原版实现（文件 + 实读行号）；
  2. 打开那个文件核对（源码仓库：https://gitee.com/SC-SPM/SurvivalcraftApi ），看它为什么这样写；
  3. 照抄改造成自己的代码——范例选的都是"最简/最全/唯一"的实现，抄它少踩坑。

例：想给方块加"按状态发光"→ 查"发光方块"行 → 抄 CampfireBlock.cs:146-152（min(8+data/2,15)，字段>0 是闸门）。 想理解某段代码的完整上下文（调用链/存档/坑），去对应主题页（导航"引擎主线"）；AI agent 从 AGENTS.md 进。
