Mod 开发配方（任务 → 照抄原版代码）

独立库 · 更新: 2026-11-01 · 状态: 最高频 30 条精选；全量任务索引（235 条·15 大类）见 Mod开发配方2.md。 本表只含 Survivalcraft 原版实现；mod 侧用法案例不在本库收录范围。

这本配方怎么用

写 mod 时遇到"我想做 X"，三步：

  1. 在精选表或 Mod开发配方2.md 对应大类里找到你要做的事，右边就是引擎里最值得照抄的原版实现（文件+实读行号）；
  2. 打开那个文件核对（源码仓库：https://gitee.com/SC-SPM/SurvivalcraftApi ），看它为什么这样写；
  3. 照抄改造成自己的代码——范例选的都是"最简/最全/唯一"的实现，抄它少踩坑。

配方2 按 15 个任务大类组织（新增类×4 / 修改覆盖 / 拦截钩子 / 绘制渲染 / 音效 / UI 与屏幕 / 输入相机 / 存档数据 / 媒体动画 / 内容资源 / 物理 / 平台工具），类内按域分组；每条附〔NN〕页锚，深入上下文去 01-引擎\NN-主题.md。

例：想给方块加"按状态发光"→ 查精选"发光方块"行 → 抄 CampfireBlock.cs:146-152（min(8+data/2,15)，字段>0 是闸门）。 想理解某段代码的完整上下文（调用链/存档/坑），去对应主题页（导航"引擎主线"）；AI agent 从 AGENTS.md 进。
