## 核心机制

### 注册 → 模拟 → 绘制闭环

- **注册**：`AddParticleSystem(ps)`：要求 ps.SubsystemParticles==null，置引用、调 OnAdded、记账批次容量 (SubsystemParticles.cs:35-46)。若实例已被持有且未传 throwOnAlreadyAdded:true，**静默什么都不做** (SubsystemParticles.cs:42-45)。移除 `RemoveParticleSystem` 对称走 OnRemoved + 反记账 (:48-59)。
- **模拟**：`Update(dt)` 遍历 m_particleSystems 调 `Simulate(m_subsystemTime.GameTimeDelta)`；返回 true 或抛异常 → 进 m_endedParticleSystems，循环结束后统一 RemoveParticleSystem (SubsystemParticles.cs:90-108)。**异常也被摘除，只留一行 Log.Error**——粒子系统写崩不会连环炸。
- **绘制**：drawOrder 300（SubsystemParticles.cs:25）。流程 (SubsystemParticles.cs:110-155)：按账本对共享批次 `EnsureCapacity` 一次性预扩容 → 逐系统 `Draw(camera)` 排 quad → 取 `ContentManager.Get<Shader>("Shaders/AlphaTested")` 灌雾/视口 uniform（u_origin/u_viewProjectionMatrix/u_viewPosition/u_fogYMultiplier/u_fogColor/u_hazeStartDensity/u_fogBottomTopDensity/u_alphaThreshold，:133-142）→ 逐 TexturedBatch 设设备状态后 `FlushWithDeviceState(shader)` (:145-152) → `PrimitivesRenderer.Flush(camera.ViewProjectionMatrix)` (:153)。**粒子自动带雾与高度衰减，无需自己算。**
- 两个总开关：ParticleSystemsDraw / ParticleSystemsSimulate（默认 true，:21-23）。关掉 Simulate 只是冻结（没人返回 true 就没人被移除），不是关闭。

### 发射器生命周期（重点）

`Simulate` 返回 true = "我演完了"。基类 `ParticleSystem<T>.Simulate` 恒 `return false` (ParticleSystem.cs:164)——不覆写就**永不消失**，每帧全量 Draw。正确写法抄 BlockDebrisParticleSystem：遍历数活跃粒子 `return !flag;`（BlockDebrisParticleSystem.cs:66-109，flag 只要有 IsActive 就置真）。构造时粒子池 `new T[n]` 一次性填满不增长 (ParticleSystem.cs:35-40)。

### 渲染细节（ParticleSystem<T>）

- 懒建两个 TexturedBatch3D (ParticleSystem.cs:48-68)：Additive 批 = DepthRead + BlendState.Additive + PointClamp；Alpha 批 = Default + BlendState.AlphaBlend + PointClamp；逐粒子按 UseAdditiveBlending 选批 (:131)。批次键含完整状态，与 06 页"批次复用"同机制。
- Billboard 三种基向量系按相机算 right/up (:69-77)；None 模式直接用粒子自己的 Right/Up (:90-95)；Horizontal 旋转绕 Y (:96-106)。enum 定义 ParticleBillboardingMode.cs:2-7。
- UV：TextureSlot ÷ TextureSlotsCount 切图集，`s = 1/TextureSlotsCount` (:78,132,145-148)；TextureSlotsCount 是"图集 n×n 的 n"不是槽总数（碎屑 32、火 3）。
- 颜色：整个 Particle.Color 直接进 QueueQuad 顶点色 (:149-159)，淡出靠自己改 A。
- 批次容量自报契约：`GetBatchDemands` 默认把 QuadDemandTexture/MaxQuadDemand 翻成两条标准批次条目；纹理与容量在系统生命周期内必须恒定，否则记账增删不对称 (ParticleSystemBase.cs:59-80,43-50)。

### 方块碎屑链（原版最常用）

`Block.CreateDebrisParticleSystem` 基类实现：`new BlockDebrisParticleSystem(terrain, position, strength, DestructionDebrisScale, Color.White, GetFaceTextureSlot(4, value))` (E:\SurvivalcraftAPIProject\Survivalcraft\Block\Block.cs:499-503)，颜色硬编码 White、纹理槽固定 4 号面；20+ 方块子类覆写换色/换槽（百科 22-effects）。生成门控：`showDebris && !noParticleSystem && CalculateDistanceFromNearestView(...) < 16f` (SubsystemTerrain.cs:460-467)。构造里取六邻光照最大值乘进颜色、A 置 255 (BlockDebrisParticleSystem.cs:51-59)；Simulate 中 dt 钳 0-0.1（掉帧不穿墙）、重力 -9.81、撞墙反弹 (BlockDebrisParticleSystem.cs:66 起)。

### 模组新增粒子系统的步骤（全代码路，无数据表入口）

1. 新类继承 `ParticleSystem<MySystem.Particle>`，内嵌 `Particle : Game.Particle` 补 Velocity/TimeToLive 等字段（全部 public 可继承，ParticleSystemBase.cs:28、ParticleSystem.cs:5、Particle.cs:4）。
2. 构造里 `base(count)` 定容量；`Texture = ContentManager.Get<Texture2D>("Textures/FireParticle")`（mod 放 Assets/Textures/Xxx）；`TextureSlotsCount = n`；初始化各粒子字段（参照 BlockDebrisParticleSystem.cs:19-22,51-59）。
3. 覆写 `Simulate(dt)`：更新位置/寿命/颜色，`return !alive;`（BlockDebrisParticleSystem.cs:109 样式）。
4. 任意主线程时机（覆写方块 `CreateDebrisParticleSystem`、SubsystemBlockBehavior 回调、Component.Update、自注册 IUpdateable）：`project.FindSubsystem<SubsystemParticles>(true).AddParticleSystem(new MySystem(...))`。
5. 要挂弹道拖尾再实现 `ITrailParticleSystem`（Position+IsStopped，ITrailParticleSystem.cs:4-8），`SubsystemProjectiles.AddTrail(projectile, offset, trail)` (SubsystemProjectiles.cs:185)——仅弹射物消费此接口。

## 坑与对策

- **AddParticleSystem 静默失败**：实例已被持有（复用同一对象）→ 不报错不显示。→ 先 `ContainsParticleSystem(ps)`，或传 `throwOnAlreadyAdded: true` 逼异常 (SubsystemParticles.cs:43-45)。
- **粒子永不消失、帧率持续掉**：没覆写 Simulate（基类恒 false）。→ 按活跃计数返回 true。
- **把 ParticleSystemsSimulate=false 当"关粒子"**：Draw 照跑且系统永被冻结。→ 用它做暂停特效；真关用 ParticleSystemsDraw。
- **运行中改 Texture/容量**：打破 GetBatchDemands 恒定契约 → 预扩容账本错乱/扩容不足。→ 生命周期内恒定；要换纹理就 override GetBatchDemands 把所有可能纹理恒报上界。
- **碎屑采到邻格贴图**：纹理槽 16→32 换算 (`slot%16*2 + rand + 32*(slot/16*2 + rand)`) (BlockDebrisParticleSystem.cs:59)。→ 自带纹理的构造重载自己算 slot。
- **远处方块破坏无碎屑**：16 格距离门控 + DestructionDebrisScale=0。→ SubsystemTerrain.cs:460-467、Block.cs:503。
- **自己排 quad 却看不见**：批次 Layer/混合态与默认不同，或忘走 AlphaTested shader 灌雾。→ 照抄 SubsystemParticles.cs:133-152 的统一刷新路径。
