# 渲染管线与着色器

> 域: SC引擎 · 更新: 2026-10-31 · 状态: 抽样(读22/69)

## 一句话定位

一帧从 ViewWidget 到 GL 的完整路径：IDrawable 排序 → 批次按 Layer 排序 → Shader(语义头+uniform) 编译绑定。

## 核心机制

### 一帧主链

ViewWidget.Update/Draw → `SubsystemDrawing.Draw(camera)` (E:\SurvivalcraftAPIProject\Survivalcraft\Widget\ViewWidget.cs:134) → 收集所有 IDrawable 的 `DrawOrders` 塞进 SortedMultiCollection<int,IDrawable> 后按 drawOrder 升序调 `Draw(camera, drawOrder)` (SubsystemDrawing.cs:39-56)。挂进绘制的两种身份：Subsystem 实现 IDrawable，实体组件实现 IDrawable（SubsystemDrawing.cs:83,113）。

实际 drawOrder 数值表（`m_drawOrders` 静态字段）：

| 绘制者 | drawOrders | 含义 |
|---|---|---|
| SubsystemSky | [-100, 5, 105] (SubsystemSky.cs:139) | -100 水下/雾参数计算，5 天空，105 水面 |
| SubsystemTerrain | [0, 100] (SubsystemTerrain.cs:40) | 0 = PrepareForDrawing+DrawOpaque+DrawAlphaTested，100 = DrawTransparent (SubsystemTerrain.cs:472-484) |
| SubsystemWeather | [50] (SubsystemWeather.cs:50) | 雨雪 |
| SubsystemParticles | [300] (SubsystemParticles.cs:25) | 全部粒子（另见 07 页） |
| SubsystemModelsRenderer | [-10000, 1, 99, 201] (SubsystemModelsRenderer.cs:87) | -10000 阴影，1 AlphaThreshold 模型，99/201 水前/水后半透明 (SubsystemModelsRenderer.cs:95-194) |

相机矩阵：`Camera` 抽象出 ViewPosition/ViewMatrix/ProjectionMatrix/ViewProjectionMatrix/ViewFrustum (Camera.cs:10-28)；透视投影 near=0.1 far=2048 (BasePerspectiveCamera.cs:228)。区块级视锥剔除在 TerrainRenderer.PrepareForDrawing (TerrainRenderer.cs:83,101-105)。

### 着色器加载：两条路（mod 自定义都走这两条）

资源注册：mod zip 里 `Assets/` 前缀文件在 ModEntity.CombineContent 被剥前缀注册进 ContentManager（ModEntity.cs:290-292），即 `Assets/Shaders/MyFx.vsh` → 键 `Shaders/MyFx.vsh`。原版 8 对着色器同机制（E:\SurvivalcraftAPIProject\Survivalcraft\Content\Assets\Shaders\）。

- **成对象路（ContentManager.Get<Shader>）**：`ContentManager.Get<Shader>("Shaders/AlphaTested")` 不带后缀 → ShaderReader 按 DefaultSuffix ["vsh","psh"] 取两个文本 → `new Shader(vsh, psh, macros)`；文件名以 "AlphaTested" 开头自动附 ALPHATESTED 宏 (ShaderReader.cs:5-15)。Get 的键拼接 = name+"."+suffix (ContentManager.cs:79,89-121)。使用者：SubsystemMovingBlocks.cs:437、ComponentDiggingCracks.cs:101、SubsystemParticles.cs:133。
- **取源码路（ShaderCodeManager.GetFast）**：`GetFast("Shaders/Opaque.vsh")` 按 '.' 拆成 (路径,后缀) → `ModsManager.GetInPakOrStorageFile<string>` (ShaderCodeManager.cs:6-13) 返回原文，调用方自己 new Shader 并选宏。使用者：TerrainRenderer.cs:66-78、SubsystemModelsRenderer.cs:230-252、ComponentFirstPersonModel.cs:43-44。
- **mod 自定义**：包里放 `Assets/Shaders/Xxx.vsh`+`.psh`，代码里 `new Shader(ModsManager.GetInPakOrStorageFile<string>("Shaders/Xxx","vsh"), ...("Shaders/Xxx","psh"), 宏)`，现成范例 ComponentBlockHighlight.cs:89-96（用 Shaders/Highlight）。GetFast/Get 均可被 mod 同名资源覆盖（ContentManager.AddOrUpdate，后载 mod 赢）。
- **#include**：ShaderCodeManager.GetIncludeText 递归展开 `#include "..."` 并剥行注释但保留 `// <.../>` 元数据行 (ShaderCodeManager.cs:49-73)；引擎另一套 ShaderCache.ResolveIncludes 用 `#include <名>` + basePath (ShaderCache.cs:119-158)。

### 编译与语义头契约

`Shader.Construct → CompileShaders` (Shader.cs:69-78,263-364)：

1. `ParseShaderMetadata` 扫两种注释元数据 (Shader.cs:135-180)：`// <Semantic Name='COLOR' Attribute='a_color' />`（语义→属性名）与 `// <Sampler Name='u_samplerState' Texture='u_texture' />`（纹理→采样器名）。实测样例 E:\SurvivalcraftAPIProject\Survivalcraft\Content\Assets\Shaders\AlphaTested.vsh:50-52、AlphaTested.psh:39。
2. `PrependShaderMacros` (Shader.cs:214-253)：前置 `#version`、`#define GLSL`、顶点着色器注入 `uniform float u_glymul;` 和 `#define OPENGL_POSITION_FIX`（z 未缩时是 `y *= u_glymul; z = 2z - w`，UseReducedZRange 时只剩 y 翻转），然后用户宏，最后 `#line 1`；源码里的原 #version 行被注释掉。
3. 链接后逐 ActiveAttribute 查 Semantic 映射，查不到抛 "Attribute ... has no semantic defined" (Shader.cs:310-314)；逐 ActiveUniform 建 ShaderParameter；Texture2D/Texture2DArray uniform 必须有对应 Sampler 元数据，否则抛 (Shader.cs:338-346)。
4. 顶点属性槽与 VertexDeclaration 的 Semantic 匹配在 GetVertexAttribData (Shader.cs:107-133)，缺语义元素抛 "VertexElement not found for shader attribute"。

**未用 uniform 被裁**：GL 链接器裁掉无活跃引用的 uniform，`GetParameter(name)` 对裁掉的直接抛 "Parameter ... not found"；`GetParameter(name, true)` 返回 Null 型参数，所有 SetValue 遇 `Type==Null` 直接 return（Shader.cs:47-50、ShaderParameter.cs:45-47）——引擎自身参数一律 allowNull 取。

### Parameter 绑定与上传

- ShaderParameter 构造按类型开缓存数组 (ShaderParameter.cs:20-42)；各 `SetValue` 重载严格校验 (Type, Count)，不匹配抛 "Shader parameter type mismatch."（如 float 版 ShaderParameter.cs:44-56；Matrix 版 :306-349；Texture2D :452-465；SamplerState :481-493）。float[] 长度 1/2/3/4/16 分别对应 Float/Vector2/3/4/Matrix (ShaderParameter.cs:58-114)。
- 值没变不置 IsChanged，变了才标记；`GLWrapper.ApplyShaderAndBuffers` (GLWrapper.cs:815-870)：先 `shader.PrepareForDrawing()`（设 u_glymul=±1，Shader.cs:102-105）→ UseProgram → 只上传 IsChanged 的 uniform（GLWrapper.cs:862 起的 switch）→ 按 Semantic 绑顶点属性。
- TransformedShader 持 ShaderTransforms，`UpdateMatrices` 算 worldView/worldViewProjection (ShaderTransforms.cs:46-74)；UnlitShader.PrepareForDrawingOverride 上传 u_worldViewProjectionMatrix (UnlitShader.cs:86-90)。
- 变体宏：ShaderMacro 即 #define（ALPHATESTED、USE_TEXTURE、USE_VERTEXCOLOR、USE_ADDITIVECOLOR、USE_ALPHATHRESHOLD，见 UnlitShader.PrepareShaderMacros UnlitShader.cs:98-118）。ShaderCache.SelectShader 按 (源码名 ^ ShaderDefines hash) 缓编译对象，程序可落 GL 二进制缓存 (ShaderCache.cs:166-189,343-380)。

### 批次与层排序（重点坑）

- BaseBatch 身份 = Layer + DepthStencilState + RasterizerState + BlendState (BaseBatch.cs:3-13)。TexturedBatch 复用键再加 纹理+UseAlphaTest+SamplerState，命中则 MoveFirst（MRU）(BasePrimitivesRenderer.cs:44-68)。
- Flush 时若新批次 Layer 小于现有最大 Layer 则置 m_sortNeeded，用 **`List<T>.Sort` 只按 Layer 排** (BasePrimitivesRenderer.cs:37,123-131) —— **不稳定排序，同 Layer 的多个批次相对顺序不保证**，同层异纹理的绘制次序不可依赖；要确定次序就分 Layer。
- 单批索引超 196605 分段提交 DrawUserIndexed (BaseTexturedBatch.cs:79-95)；`EnsureCapacity`/`EnsureQuadCapacity` 支持一次性预扩容 (BaseTexturedBatch.cs:24-39)。
- 两套静态 UnlitShader 常驻：m_shader 与 m_shaderAlphaTest (BaseTexturedBatch.cs:3-5)；粒子/模型等自管 Shader 时走 `FlushWithDeviceState(shader)` 直传。

### 混合语义（重点坑）

E:\SurvivalcraftAPIProject\Engine\Engine.Graphics\BlendState.cs:17-41：

| 预设 | ColorSrc/Dst | 语义 |
|---|---|---|
| Opaque | One/Zero | 不混合 |
| AlphaBlend | **One / InverseSourceAlpha** | **预乘 alpha**：纹理 RGB 必须已乘 A，否则半透明像素发白/过亮 |
| Additive | SourceAlpha / One | 加法 |
| NonPremultiplied | SourceAlpha / InverseSourceAlpha | 直通 alpha（常规 PNG 语义） |

预乘靠纹理加载参数：`Texture2D.Load(stream, premultiplyAlpha)` (Texture2D.cs:344-347) 与 `Color.PremultiplyAlpha` (E:\SurvivalcraftAPIProject\Engine\Engine\Color.cs:180-182)。引擎默认批次 (USE_TEXTURE Unlit) 不替你预乘。

## 坑与对策

- **自定义 uniform 被裁**：着色器里声明了但没实际使用 → GetParameter 抛 not found。→ 用 `GetParameter(name, true)` 拿 Null 参数，或确保 uniform 被读写。
- **SetValue 类型不匹配运行时抛**：如给 Vector2 传 Matrix。→ 对着 ShaderParameterType 写强类型 SetValue；数组长度必须 1/2/3/4/16。
- **AlphaBlend 下贴图没预乘**：边缘白边/整体偏亮。→ 加载时 `Texture2D.Load(s, true)` 或改用 NonPremultiplied 批次。
- **同 Layer 批次顺序抖动**：List.Sort 不稳定。→ 需要 Z 序的内容拆不同 Layer，或同 Layer 用深度缓冲而非绘制序。
- **Attribute/Sampler 忘写语义头**：编译链接成功但 Construct 抛 "has no semantic/sampler defined"。→ 每个顶点属性一行 `<Semantic/>`，每个 sampler 纹理一行 `<Sampler/>`（照抄 AlphaTested.vsh:50-52）。
- **顶点着色器漏 OPENGL_POSITION_FIX/u_glymul**：画面上下颠倒或深度异常。→ 顶点源码保留 `#ifdef GLSL` 段并应用 OPENGL_POSITION_FIX 宏（引擎会注入该宏定义）。
- **mod 覆盖原版着色器全局生效**：Assets/Shaders/Opaque.vsh 同名覆盖后所有区块都换。→ 只覆写自己新增的名字（如 Fx01_SwordRain.vsh）。
- **ContentManager.Get<Shader> 前提是 ShaderReader 注册的 vsh+psh 都在**：缺一个抛 "Not Found Res [Shaders/X.vsh]"。→ 两文件同名成对打包，扩展名小写。
