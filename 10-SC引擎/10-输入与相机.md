## 核心机制

### 引擎层四静态类

| 类 | 关键成员 | 锚点 |
|---|---|---|
| `Keyboard` | `IsKeyDown/IsKeyDownOnce/IsKeyDownRepeat`、`LastKey/LastChar`、事件 `KeyDown/KeyUp/CharacterEntered`、`ShowKeyboard`、`Clear()` | Keyboard.cs:69/71/73、:47/:49、:63-67、:78、:130 |
| `Mouse` | `MousePosition(Point2?)`、`MouseMovement`、`MouseWheelMovement`(一格=120)、`IsMouseButtonDown/Once`、事件 `MouseMove/MouseDown/MouseUp` | Mouse.cs:66/:54/:59、:331/:333、:70-74 |
| `Touch` | `TouchLocations`(Id/Position/State/ReleaseQueued)、事件 `TouchPressed/Released/Moved`、`IsTouched` | Touch.cs:26、:28-32、:34 |
| `GamePad` | `IsConnected(0..3 越界抛)`、`GetStickPosition(deadZone∈[0,1))`、`IsButtonDownOnce`、扳机在**松开帧**算 Once | GamePad.cs |

- 失焦窗口(`!Window.IsActive`)与软键盘打开期间，键盘三处理函数直接返回 false 不触发事件。
- 桌面端 `ShowKeyboard` 是空操作（内部只有 cancel）；文本输入走 `TextBoxWidget`/`WidgetInput.EnterText`。
- 同帧按下抬起会被"续命"一帧（Mouse 延迟松开数组），轮询不会漏点击；鼠标事件只在 `IsMouseVisible` 时触发，但按下状态照常更新。
- `Touch.IsTouched` 是**只置 true 永不复位**的锁存标记（Touch.cs:122），不能当"正被触摸"用。
- 帧末 `AfterFrame` 清 `IsKeyDownOnce`/`LastKey`/`LastChar`；`Dispatcher.Dispatch` 排队的动作看到的是**上一帧**输入。

### 语义层 WidgetInput

每帧 `Update()` 先 `ClearInput()` 再按 `Devices` 位标志填值（`WidgetInput.cs:680-703`）。语义成员（`WidgetInput.cs:58-94`）：`Any/Ok/Cancel/Back/Left/Right/Up/Down/Press(Vector2?)/Tap(Vector2?)/Click(Segment2?)/SpecialClick/Drag/DragMode/Hold/HoldTime/Scroll/ScrollX`。注意：键盘侧没有 `Ok`；`Left/Right/Up/Down` 用连发节奏；`Click` 是按下→松开的**线段**不是布尔。

- `Widget.Input` 沿父链找最近挂 `WidgetsHierarchyInput` 的祖先，找不到给 `EmptyInput`（Devices=None，读啥都是空）。
- 按映射名读：`IsKeyOrMouseDown(name)` / `IsKeyOrMouseDownOnce(name)`（`WidgetInput.cs:363-395`）→ `SettingsManager.GetKeyboardMapping(name)`（SettingsManager.cs:943，throwIfNotFound 默认 true）→ 按 `MouseButton`/`Key` 分派。

### 键位绑定表与注册链

原版默认键位：`SettingsManager.InitializeKeyboardMappingSettings`（SettingsManager.cs:752-780）——`MoveLeft=A MoveRight=D MoveFront=W MoveBack=S MoveUp=Space MoveDown=Shift Jump=Space Dig/Hit=鼠标左键 Interact/Aim=鼠标右键 ToggleCrouch=Shift ToggleMount=R ToggleFly=F PickBlockType=中键 ToggleInventory=E ToggleClothing=C TakeScreenshot=P SwitchCameraMode=V TimeOfDay=T Lightning=L Precipitation=K Fog=J Drop=Q EditItem=G KeyboardHelp=H`。手柄默认在 `:782`。

模组注册（**唯一正道**）：重写 `ModLoader.GetKeyboardMappings()` / `GetGamepadMappings()`，yield `KeyValuePair<string,object>`（值=`Key`/`MouseButton`，手柄可加 `GamePadButton`/`GamePadTrigger`/组合键 ValuesDictionary）。**不需要 RegisterHook**——`ModSettingsManager.LoadModSettings` 用 `Loaders.SelectMany(item => item.GetKeyboardMappings())` 直接轮询（ModSettingsManager.cs:119）。链路：注册→`ModKeyboardMapSettings[包名]`→`CombinedKeyboardMappingSettings`（TryAdd 先到先得，重名被原版遮蔽）→改键界面→`ModSettings.xml` 落盘。手柄组合键只在 `IsGamepadDownOnce` 里解析；兼容组 `InitKeyCompatibleGroups` 是**真钩子**，必须 `RegisterHook`（KeyCompatibleGroupsManager.cs）。

### 每帧消费：ComponentInput → PlayerInput

顺序（`ComponentInput.cs:72-76`）：`m_playerInput = default` → MouseAndKeyboard → Gamepad → VrControllers → Widgets。`UpdateInput` 钩子插在键鼠阶段末尾（`ComponentInput.cs:234-240`，`ModLoader.UpdateInput(ComponentInput, WidgetInput)`，需 RegisterHook）。

`PlayerInput`（PlayerInput.cs:5-72）：`Look`(Vector2,已乘灵敏度夹±15)、`Move`(Vector3,>1 归一化)、`Jump`、`Dig/Hit/Aim/Interact`(Ray3?，前两者按住、后两者点按)、`ToggleInventory` 等 bool 开关、`SelectInventorySlot`(数字键硬编码不走映射)、`ValuesDictionaryForMods`。三道闸门（`ComponentInput.cs:89-117`）：窗口失焦/未就绪→整结构体清零；血量0/睡觉/相机禁控→只保留 8 个环境字段；相机无移动权限→移动字段清零。**`ValuesDictionaryForMods` 因 `default` 每帧变 null，用前判空重建；别当持久状态**。

### Camera 类族与模式

基类 `Camera`（Game\Camera.cs:5-56，70 行）：抽象 `ViewPosition/ViewDirection/ViewMatrix/ProjectionMatrix/ViewFrustum/UsesMovementControls/IsEntityControlEnabled` + `WorldToScreen/ScreenToWorld` + `Activate(previousCamera)` + `Update(dt)` + `PrepareForDrawing`。透视公共实现在 `BasePerspectiveCamera.cs`（投影/屏幕矩阵缓存 :68-121）。

## 坑与对策

- **键位注册了但不生效/界面没有**：没重写 `GetKeyboardMappings()`，或两个 Loader 返回同名键（ValuesDictionary.Add 抛，后半模组键位全丢）→ 映射名加模组前缀。
- **`IsKeyOrMouseDownOnce` 永远 false**：值类型不是 Key/MouseButton 直接 return false；`Key.Null`（=禁用）也 false。
- **UpdateInput 不跑**：没 `RegisterHook("UpdateInput", this)`；异常只报第一次后静默。
- **写 ValuesDictionaryForMods 抛 NRE**：`m_playerInput = default` 把字段清 null（PlayerInput.cs:72 初始化器对 default 不生效）→ 每帧判空。
- **死亡/睡觉时输入被抹**：闸门整体换结构体（ComponentInput.cs:93-106）→ 自定义数据每帧重写。
- **组合键误触/不触发**：修饰键按住时普通按钮被闸门拦（手柄 LB/RB/扳机既是动作又是修饰键）；扳机 Once 在松开帧。
- **长按方向连发太快/没有**：键盘 0.3s 起 0.04s 一次、手柄 0.2s 起（AfterFrame 推进）。
- **注册相机切不过去**：没在 `ManageCameras` 里 `AddCamera`，或 `GetCameraList` 值写成负数被禁用；注册名必须是类型全名 `Game.XxxCamera`。
