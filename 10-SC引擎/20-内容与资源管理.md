## 核心机制

### 1. ContentManager 三表与 Get 装载链

- 三表：`Resources`(键=带后缀资产路径→`ContentInfo`)、`ReaderList`(键=读取器 `Type` 字符串=目标 CLR 类型全名→读取器)、`Caches`(键=name[.suffix]→已解析对象 List)(ContentManager.cs:51-54)。
- `Get<T>(name)` 流程(ContentManager.cs:76-129)：`Subtexture` 特判直转 `TextureAtlasManager.GetSubtexture`(:80-82) → 查 Caches → 按 `reader.DefaultSuffix` 逐后缀拼 `name.suffix` 查 Resources(:92-109，**先到先得**) → `reader.Get(contents)` 解析 → 结果入 Caches。找不到抛 `Not Found Res [key][type.FullName]`(:118，键**区分大小写**)。
- `ContentInfo.Duplicate()` **不是复制**：同一 MemoryStream 仅复位 Position 返回(ContentManager.cs:35-43)。多线程并发解析同一图片靠 `ContentInfo.InUse` 锁+睡眠等待+回缓存取，先例 ImageReader.cs:12-22。
- 初始化：LoadingScreen 第 1 个加载动作 `ContentManager.Initialize()`(LoadingScreen.cs:163)——挂 `Storage.LoadContentStreamCallback`/`GltfLoader.LoadExternalStreamCallback=GetStream`(ContentManager.cs:60-62，引擎层按路径回查包内流)；`Display.DeviceReset` 时重建 Texture2D/Model/BitmapFont 缓存(:172-184)。
- 释放无自动逐出：`Dispose(name)` 才清缓存并 Dispose 对象(:141-156)；一次性大资产(BlocksData/Database/Clothes/CraftingRecipes)用后即弃，见 SurvivalCraftModEntity.cs:74-137。
- mod 扩展点：`AddContentReader`(ContentManager.cs:201，按 Type 键 TryAdd，先到先得)。

### 2. 双源资产流：游戏本体也是"根 mod"

- `SurvivalCraftModEntity` 构造(SurvivalCraftModEntity.cs:13-70)：注册 19 个原版读取器(:14-40) → 打开 `app:/Content.zip`（存在则外置，否则内嵌程序集资源 `Game.Content.zip`，:50-58）→ `InitResources()`。
- `ModEntity.InitResources`(ModEntity.cs:191-277)：读中央目录进 ModFiles + icon.webp/modinfo.json/modsettings.json；SafeMode 时非本体包直接清空(:228-232)；包名查重/禁用判定(:238-269)。
- `CombineContent`(ModEntity.cs:279-298)：把 zip 内**所有 `Assets/` 前缀文件**剥掉前缀，流拷入 MemoryStream，`ContentManager.Add` 注册(键=无前缀路径)。LoadingScreen 步骤：依赖检查(:208-241)→全部 ModList 逐个 CombineContent(LoadingScreen.cs:242-247)→ContentLoaded(方块等)。
- 后载覆盖先载：`ContentManager.Add` 是 `Resources.AddOrUpdate`(ContentManager.cs:134)——**同名资产后注册的 mod 赢**(06 页着色器覆盖同机制)。
- mod 侧读取：`GetAssetsFile`(ModEntity.cs:162)=`GetFile("Assets/"+名)`；或注册后 `ContentManager.Get<T>`/`ModsManager.GetInPakOrStorageFile<T>`(ModsManager.cs:216-217，纯 Get 别名)。

### 3. IContentReader 家族：序列化契约

- 契约 3 成员：`Type`(目标类型全名=ReaderList 键)、`DefaultSuffix`(无显式后缀时的探测顺序)、`Get(ContentInfo[])`(1~N 个内容→对象)。全 19 实例见 20a 明细。
- 多文件组合读取：`ShaderReader` 固定取 vsh+psh 两个内容，文件名以 `AlphaTested` 开头自动附宏(ShaderReader.cs:9)；`BitmapFontReader` 要求恰好 2 条(.lst 字形+纹理，顺序无关，BitmapFontReader.cs:14-28)；`VectorFontReader` 单 ttc/ttf/otf，ttc 多面按 OS/2 fsSelection 映射四样式，同样式先到先得(VectorFontReader.cs:44-59)。
- 后缀即格式分支：`Texture2DReader` DefaultSuffix 序=astc→astcsrgb→webp→png→jpg→jpeg；`.astc/.astcsrgb` 走 `CompressedTexture2D.Load`(后者 linear=false=正确 sRGB)，其余先 `Get<Image>` 再上 Texture2D；特例 `Fonts/Pericles` 固定 3 级 mipmap(Texture2DReader.cs:11-19)。`DaeModelReader` 以 gltf/glb/dae 三后缀共用(gltf 走 `GltfLoader.Load` 且传包内目录作外部流根，DaeModelReader.cs:15-19)。
- `.dll` 资产：AssemblyReader 反序列化即 `Assembly.Load`(AssemblyReader.cs:8)。
- 读取器抛异常即 Get 失败；`Get(name, suffix, throwOnNotFound:false)` 可静默返回 null(ContentManager.cs:69-70)。

### 4. 外部内容导入管线(类型识别→准备→决策树导入)

- 类型扩展名总表 `GetEntryTypeExtensions`(ExternalContentManager.cs:39-62)：.scworld/.scbtex(+webp/png/astc)/.scskin/.scfpack/.scmod(Mod 与 NetMod 同扩展，声明序 Mod 在前)/字体 5 后缀；`ExtensionToType`(:29-37)按枚举序匹配。
- 提供者注册 `Initialize`(:16-27)：非 Android=Disk(`app:` 根)、Android=AndroidSdCard(安卓 files 目录)、再加 ChineseCommunity 与 Dropbox；`Providers[0]` 即 DefaultProvider(:12)。
- 准备 `PrepareExternalContent`(ExternalContentManager.Analyze.cs:47-102)：整包进内存(TryGetBuffer 零拷贝, :54-58)→mod 类(CommunityFileTypes.IsModLike)用 `ScmodArchiveReader.ReadModInfo` 取名+按包名/文件名找已装实体(:72-84)，**Mod 一律 RequiresRestart=true**(:86)；其余按类型查同名冲突(:91-101)。冲突检测枚举管理器 List 时统一 `Dispatcher.Dispatch(waitUntilCompleted:true)` 封送主线程(防 Clear()+Add 竞态, :133-154、:221-251)。
- 导入决策树 `ImportPreparedExternalContent`(ExternalContentManager.Import.cs:15-62)：mod 且有旧包→`ModUpdateImporter.ImportModUpdate`；内置物(材质/皮肤 `$`/空名族)禁覆盖(:41，EnsureExternalContentCanBeOverwritten :205-215)；文件型覆盖走 `ImportExternalContentWithRollback`→`TransactionalFileReplacement.OverwriteWithRollback`(先备份后导入失败还原, :95-119)；World 永远普通导入(目录 World/World1 自动编号，天然副本)。
- mod 更新落地(ModUpdateImporter.cs:42-69)：包名不匹配拒绝(:29-32)→写 `mod-update-<guid>.tmp`→事务替换→触发 `ModsManager.RescanModsAsync()` 对账(:61)；**密文落盘、引擎加载期自解密**(ScmodArchiveReader.cs:41-43 注释)。
- scmod 归档原语(ScmodArchiveReader.cs)：`OpenArchive`(:57-92)=整读→长度≥加密头才走 `ModsManager.GetDecipherStream`(HeadingCode 前缀倒序/HeadingCode2 交织, :176-198)→扫 `PK\x03\x04` 头截掉杂质前缀(64KB 上限, :200-214)→非 zip 抛类型化 `InvalidScmodArchiveException`(:19-36)。`TryReadRootEntry`(:99-133)只收根条目+4MB 解压上限+逐块复核(防压缩炸弹)。

### 5. IExternalContentProvider 来源家族

- 接口(IExternalContentProvider.cs:2-30)：`List/Download/Upload/Link` + `Login/Logout` + 能力位(SupportsLinks/SupportsListing/RequiresLogin/IsLocalProvider)+`ScreenNameForListing`(列举可改跳专用屏)。
- Disk(:DiskExternalContentProvider.cs)：根=`app:`；List=递归目录树按扩展名定类型(:102-128)；Link/Login=NotSupported；BROWSER 上传落 `Uploads/` 子目录(:27-31)。
- AndroidSdCard(AndroidSdCardExternalContentProvider.cs)：根=`RunPath.AndroidFilePath/files`(:140-146)；上传重名自动加序号到 999(:118-134)；externalPath 与 internalPath 双向映射(:136-138)。
- ChineseCommunity(ChineseCommunityExternalContentProvider.cs)：登录态挂 `AuthSessionManager`(per-URL 会话)；`SupportsListing=true` 但载体是专用屏 `CommunityMyPublished`(:29)；Upload=又拍云直传+登记链(凭证 30s 超时, :97-136)；List/Download/Link 保留未实现(:79-86)。
- Dropbox(DropboxExternalContentProvider.cs)：OAuth2 token 流=浏览器+URI 回调 `Program.HandleUri`(:257-287)，桌面兜底窗口激活后贴 code 换 token(:212-255)；token 存 `SettingsManager.DropboxAccessToken`(:46)；List/Download/Upload/Link 直调 REST(:86-195)。
- SchubExternalContentProvider：**尸体类** [Obsolete]，旧 `/com/files/*`+`/com/api/login` 接口已死，由 ChineseCommunity+AuthSessionManager 取代(SchubExternalContentProvider.cs:9-13)。

### 6. 材料族格式契约

- **皮肤**(.scskin=裸图片文件)：内置名 `$` 前缀(CharacterSkinsManager.cs:27)；清单=8 个 `$Male1-4/$Female1-4`(+$Empty 可选)+目录内 .scskin(:138-156)；校验=≤65536² 且 2 的幂(:225-235)；加载回退链=用户文件→按名找内置 `Textures/Creatures/Human*`→`HumanMale1` 兜底(:79-107)。玩家模型取 `MalePlayer/FemalePlayer` 数据库模板 `HumanModel.ModelName`，加载时把 AnimationConfig 的 boneAliases 注入 Model(修旧骨骼名硬编码崩溃, :195-205)。
- **方块纹理包**(.scbtex)：**内置=空字符串名**(BlocksTexturesManager.cs:24,128-134)；文件本体可以是 astc(取 GetParameters 宽高)或普通图片；文件名把 `.scbtex` 视为容器后缀、真扩展名看剩余部分(:58)；校验同皮肤 pow2+65536(:149-158)；`DefaultBlocksTexture=Textures/Blocks`(:21)。
- **家具包**(.scfpack)：zip 但**必须恰好 1 条目 `FurnitureDesigns.xml`**(FurniturePacksManager.cs:110-115)；导入重名自动 ` (1)`..` (9)` 后拒(:43-51)；`CreateFurniturePack` 由 ValuesDictionary→XML→zip(:64-78)；内容=SubsystemFurnitureBlockBehavior 的 FurnitureDesigns。
- **字体**：目录 doc/Fonts；后缀 ttf/otf/ttc/woff/woff2(FontManager.cs:219)；导入校验=SharpAstro 解析 0 面即拒+全面轮廓可渲染(CFF2 变量字体拒)+Latin 必备 62 字符探测(FontManager.cs:912-961)；同名覆盖导入要失效 `user:<文件名>` 探测缓存(:968-970)；链构建顺序=内置 Pericles 头→槽位→mod hook→用户字体→系统发现(RebuildChainsCore :633-660；Windows 系统发现=注册表 HKLM+HKCU Fonts 键枚举, FontLocator.Windows.cs:57-90)。
- 试用模式闸门：`MarketplaceManager.IsTrialMode`(纯静态布尔, MarketplaceManager.cs:7)挡住导入世界/家具包/发布(WorldsManager.cs:35、FurniturePacksManager.cs:35、CommunityContentManager.cs:226)。

## 坑与对策

- **`Duplicate()` 被当复制**：多线程同时解析同一 ContentInfo 会互相改 Position → 照抄 ImageReader 的 InUse 自旋+缓存回取模式(ImageReader.cs:12-22)，或保证单线程。
- **资产键区分大小写且必须带后缀**：`Not Found Res [X][T]` → 键=注册时的 AbsolutePath 原样；不带后缀的 Get 按 DefaultSuffix 顺序探测，读者表见 20a。
- **mod 资产意外覆盖**：AddOrUpdate 后载赢 → 包内 Assets/ 路径别与原版/其他 mod 同名，覆盖要靠 `Assets/` 同名故意做补丁时先确认加载序。
- **Caches 不自动释放**：`Get` 过的大资产常驻 → 一次性数据照抄 `Get` 后立刻 `ContentManager.Dispose("名字")`(SurvivalCraftModEntity.cs:74-76)。
- **后台线程枚举内容列表崩溃**：Update*List/ModListAll 是主线程 Clear()+Add → 封送 `Dispatcher.Dispatch(...,waitUntilCompleted:true)`(ExternalContentManager.Analyze.cs:138-154 先例)。
- **SettingsManager 挂临时静态属性会被写盘**：反射无差别收集 → 临时状态别做成它的 public static 可写属性。
- **scmod 带弱加密/杂质前缀**：直接 ZipArchive.Open 报英文错 → 必须走 ScmodArchiveReader.OpenArchive(内存解密+截前缀)。
- **覆盖导入丢档**：先备份后写 → 用 TransactionalFileReplacement.OverwriteWithRollback(ExternalContentManager.Import.cs:107)。
- **皮肤/材质图非 2 次幂或超 65536²**：导入期抛 → 预校验照抄 ValidateCharacterSkin/ValidateBlocksTexture。
