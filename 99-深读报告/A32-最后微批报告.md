**关键发现**：
- 三平台统一 Discover() 契约：主路线系统 API + 候选打表兜底，产出 SystemFontFace 列表；`SystemFontsScanAttempted` 是 RebuildChainsCore 系统槽位回退的前置门——W/A/L 恒 true，Browser 须至少发起过一次手势扫描（防回退静默清掉用户持久化选择，Browser.cs:70-75）。
- Android：AFontMatcher（API 29+）4 次 match，locale 用游戏内语言优先（CultureInfo 恒 en-US 不随游戏语言，否则 NotoSansCJK ttc 落 JP 面"置"显示日文字形，:86-90）；bold 请求落 <600 字重面即丢弃交 Stroked1 兜底（:125-127）；CFF2 变量面（Android 16 起 AOSP CJK）轮廓探针拒收，body 全拒时从候选表补 OEM glyf 面（:37-50）。
- Browser：仅 Chromium 103+，queryLocalFonts 元数据→34 组候选 family 精确双打（英文名+本地化名）→按 postscriptName 拉 blob **内存持有不落盘**（唯一落盘=用户手动导入字体）；同内容字节去重共享 ttc；面序=postscriptName→样式位→首面三段降级；Firefox/Safari 无 API 恒不扫描。
- Linux：fontconfig（libfontconfig.so.1）三步匹配序（FcConfigSubstitute+FcDefaultSubstitute+FcFontMatch，跳过 substitute 则 generic 族名无区分度，:100-110）；face index 高 16 位是 FreeType named instance 编码须掩掉（:141-144）；目录扫描兜底递归带 symlink 终靶去重防环（StackOverflow 不可捕获且崩在持锁段，:213-247）。
- 三平台的 CFF2-only 变量字体都在发现期拒收（ProbeFaceOutlines/HasRenderableOutlines），否则坏面进链导致整链退位图。
