## 二、模块架构结论（一句话定性）

这不是"内嵌 WebView"，而是**把整个 SC 引擎编译成 WASM 跑在浏览器里的平台后端**：JS 侧 main.js 是事实上的"平台窗口系统"（输入采集/全屏/文件选择器/字体/下载），C# 侧 Engine.Browser 是它的消费端；两侧用三条通道通信——JSImport/JSExport 低频互操作、共享内存双缓冲高频输入、共享内存+Atomics 旗标传输 Content.zip。

分层：
1. **平台壳**（Survivalcraft.Browser）：csproj 组合根（emcc 旗标 FULL_ES3/pthreads/OffscreenCanvas/WASMFS、AOT、PatchJs 补丁、GenerateContentInfo 尺寸常量）+ Native C 桩（libEGL pbuffer 桩、wasmfsHelper OPFS 挂载/软链）+ 唯一 .cs ContentFileBridge。
2. **互操作层**（Engine.Browser，12 .cs）：BrowserInterop/Emscripten/OAL 族 + 输入共享内存协议 6 文件 + TrampolineFuncs。
3. **程序集形态**：Engine.props 把 `..\Engine\**\*.cs` 全量并入（Engine.props:4-5 AssemblyName=Engine），Engine.Browser.csproj 只补链 EGL.cs、剔除 Serialization 的 Archive/Serializer——**引擎核心与浏览器胶水编进同一个 Engine.dll**，核心 Window.cs 才能直接 `#if BROWSER` 调 InputBridge；main.js 也从 Engine.dll 取 `Engine.Browser.BrowserInterop`。EntitySystem.Browser 同构产出 EntitySystem.dll。浏览器构建移除 Jint/HarmonyX。

## 三、关键机制实测数据

- **共享内存布局**（C#/JS 两侧镜像核对一致）：Header 8B（ActiveIndex+Padding），单 Buffer 4220B（状态区 124B：canvas 宽高/DPR/鼠标 XY/4 手柄×4 摇杆+2 扳机 + UsedBytes 4B + EventData 4096B）。JS STRUCT 常量 main.js:92-105 与 C# InputBuffer.cs:4-26 逐字段吻合。
- **事件流**：高位 128=12B 大事件（Mouse/Touch/Wheel），否则 4B 小事件（Key/Gamepad/Focus/Fullscreen）。JS 打包进单个 int32 写入(main.js:121-139)，>4096B 静默丢弃。
- **输入泵**：JS rAF pollInputLoop 写状态+异或边沿(main.js:161-221)；C# Window.BeforeFrameAll→InputBridge.BeforeFrame 原子翻转+消费(Window.cs:906, InputBridge.cs:20-36)。渲染帧泵=emscripten rAF loop 挂 [UnmanagedCallersOnly] BrowserRenderFrameHandler(Window.cs:830/:711-715)。
- **Content.zip 桥**：JS fetch 分块写 wasmMemory(ptr+8)，Atomics 置首字节旗标(main.js:34-56)；C# 分配 FileSize+8、忙等 100ms 轮询、UnmanagedMemoryStream→ZipArchive.Open(SurvivalCraftModEntity.cs:42-48, ContentFileBridge.cs:8-18)。FileSize 为构建期常量（GenerateContentInfo.csx→ContentFileInfo.g.cs，csproj BeforeBuild 任务）。
- **文件系统**：MountOPFS("/__root__")(Storage.cs:59→wasmfsHelper.c:7-10)+任意顶级目录自动软链 /X→/__root__/X(Storage.cs:820-845, EEXIST 容忍)——业务文件树根全落 OPFS。
- **互操作性能红线**：main.js:66 原注释"调用这个特别慢……能少用就少用"→高频走共享内存。
- **合成 Esc**：指针锁丢失与浏览器后退都注入 KeyDown(20)/KeyUp(20)(main.js:569-575/:603-609)。
- **构建补丁**：PatchJs.csx 打 4 处——注释 emscripten `_egl*` JS 实现、canvas 转移兜底、WASMFS createPath 直拼、worker 加 resize_canvas 命令。
- **GL 蹦床**：GLWrapper.cs:204 在 GL.GetApi 前调 ApplyWorkaroundFixingInvocations，TrampolineFuncs.cs 靠 [DynamicDependency] 锚(:8-11)保住 280 个 GL 委托签名供 WASM AOT 生成蹦床，文件本体零逻辑。
- **音频**：Mixer.cs:3-7 用 using 别名把 Engine.Browser.AL 族顶替 Silk.NET.OpenAL，上层零改动；OAL 库名 "openal32" 由 emscripten 解析到 -lopenal。
