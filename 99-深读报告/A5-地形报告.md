## 二、最重要的机制发现

1. **五代生成器同一接口、同一 26 步骨架**，逐代只换"公式+参数化+步骤容器"。TCG23 是分水岭：首次引入 `ChunkGenerationStep1-4` 列表+钩子+构造尾 Sort(TCG23:255-258/:353-365)，TCG24 继承此结构。TCG21 连步骤列表都没有(直接函数调用 :629-661)。
2. **笔刷池种子跨版本不同**：TCG21/22/23 `CreateBrushes` 用 `new Random(17)`(TCG21:2171/TCG22:1934/TCG23:2031)，TCG24 用 `new Random(24)`(TCG24:1984)。同一世界种子在 2.3/2.4 生成器下矿物形状不同；模组若在钩子里清空笔刷池，两种种子都受影响。
3. **矿脉宿主是整值比较**：`PaintFastSelective(chunk,x,y,z,onlyInValue)` 要求格子 value 与 onlyInValue 完全相等(TerrainBrush.cs:214-236)——宿主"煤=Granite(3)/铁硫钻锗=Basalt(67)/硝石=Sandstone(4)"指 value 3/67/4，任何带 data/light 的同 contents 格画不上。
4. **矿脉跨区块无缝靠"邻域重算+坐标种子"**：每区块对 3×3 邻域逐块 `new Random(m_seed + i + 119*j)`(TCG21:999)+burn-in(先抽 0-10 次废 :1000-1003)——随机序列只由邻区坐标决定，两边各自画出对方境内属于自己的部分，接缝天然对齐。
5. **洞穴是"蠕虫+方向熵"模型**(TCG21:1152-1266)：起点=地表下 1 格、方向=两点高度差叉积、5 类转向事件(50% 扰动/6% 换向/5% 抬平升级刷型/3% 竖井向下/Y<30 2% 向上)、33% 换刷型(幂 7 分布偏小型)、6% 分支(条件 >20 步+Y<58+≤12 条)、三重终止(超长/半径 34/冒出地表 Height+1)。
6. **存档门槛+光位藏游程压缩**(TS23)：`SaveChunk` 仅 `State>InvalidContents4 && ModificationCounter>0`(TS23:593-599)；压缩先 256B shaft(`温<<4|湿`)、再 y→x→z RLE(游程藏进 light 位，≤271 上限，>271 抛异常)、Deflate Fastest(:652-724)。Region 文件=256 目录项×8B+1024B 余量/条目+256MB 上限+tmp 原子换名(:358-443)。
7. **2.4 唯一存档后端是 TS23**：`SubsystemTerrain.Initialize:523` 无条件 `new TerrainSerializer23(dirName)`；TS14/129/22 只在 VersionConverter10To14/21To22/22To23 中出现。加载异常除 IOException 外被吞并按"有档空块"处理(:626-630)。
8. **TCG21 有双分支参数时代**：构造按 `OriginalSerializationVersion` 分"空串(未定)/<2.1/≥2.1"三套参数(TCG21:515/:543/:571)；<2.1 分支的噪声偏移来自 `OldRandom(100+seed)`(.NET 老 Random 复刻 :106-252)，≥2.1 用自家 Java 式 LCG(:6-104)。
9. **TCG23 独有**：倒木/立树拆两步(:1085/:1228)、GenerateCairns 石冢(:1917, 步 1200)、`MaxBedrockHeight=4` 字段(:252, 基岩 2+Noise*4 层 :1292)、`FindCoarseSpawnPosition` 钩子(:394-401)、树画完 `chunk.AddBrushPaint`(:1274)——但 `ApplyBrushPaints`(TerrainChunk.cs:243) 全项目无调用方，闲置。
10. **TCG22 出生点按难度评分**：ScoreSpawnPosition 按 StartingPositionMode Easy/Medium/Hard 分档扣分(TCG22:499 起)；TCG21 只有固定扣分(:772-805)。

## 三、材料分层事实(TCG21 GenerateTerrain :916-924)

- 密度<0 且 y≤OceanLevel → Water(18)
- 密度≥0: 深于 num37 → Basalt(67)；否则 Granite(3)；沙漠/海岸带(温>8∧湿<8∧山<0.95，或岸距<12)顶层带→Sandstone(4)
- GenerateSurface(TCG21:941-989) 再改写: Sandstone→温5-6 Gravel(6)/其余 Sand(7)；Granite 表层→Limestone(66)(y<66 或 y=84+温/4 或 y=103+温/4 且湿=9 且温%6=1) 或 Clay(72)(上方是水∧湿>8∧湿偶∧温%3=0) 或 Grass(2)；厚度 0-7 层随"高山+高 Y"趋 0
- GrassAndPlants(TCG21:1467-1494) 把表层 Grass 值 2(Dirt) 改成 8(GrassBlock) 并种植物——注意"surface 材料写 2"实际是 Dirt，草是 pass4 才换的
- 基岩: 2+4·Noise(0.1) 层(TCG21:1458)，y=255 强制空气
