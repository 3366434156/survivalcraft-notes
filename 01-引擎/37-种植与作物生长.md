# 37-种植与作物生长（播种→轮询生长→收获→养分循环的全链）

> 域: SC引擎 · 更新: 2026-11-02 · 状态: 全读(SeedsBlock/RyeBlock/CottonBlock/BasePumpkinBlock+PumpkinBlock/SoilBlock/SaplingBlock/SubsystemPlantBlockBehavior/SubsystemSoilBlockBehavior/SubsystemSaplingBlockBehavior/SubsystemCactusBlockBehavior/SubsystemFertilizerBlockBehavior/SubsystemRotBlockBehavior/SubsystemBlocksScanner/SubsystemCellChangeQueue/PlantsManager)；⚡=ModLoader 钩子/可挂点
> 一句话定位：**种植 = SeedsBlock 按种型"变身放置"成植株方块 → SubsystemBlocksScanner 以约 60s/轮全图扫描逐列调 OnPoll → 作物用 data 位记生长阶段、按"耕地状态+温度"决定推进间隔与退化概率、光照≥9 才长 → 收获全走 GetDropValues 掉落表，成熟扣耕地氮；树苗走"时间表+笔刷"，仙人掌走"堆叠概率"，是三套互相独立的生长范式**。

源码引用一律仓库相对路径（`Survivalcraft\...`）。方块值/data 编码底座 → [04页](04-方块系统.md)；ChangeCell 与地形修改管线 → [27页](27-地形修改与MovingBlocks.md)；光照亮度来源 → [14页](14-光照天空与天气.md)；掉落物实体 → [16页](16-玩法物品与背包.md)。

## 2 · 生长调度：SubsystemBlocksScanner 全图轮询（谁 tick 的答案）

- **不是区块随机 tick，也不是逐帧 Update**：`SubsystemBlocksScanner`（IUpdateable）把"已加载区块的所有 xz 列"排队，每帧按预算扫若干列（ shaft=一根 xz 柱，从 y=0 扫到柱顶 `GetTopHeightFast`，逐格查 contents → 调该方块的 pollable 行为 `OnPoll(value,x,y,z,pollPass)`） | SubsystemBlocksScanner.cs:36-79
- **节奏**：`m_pollShaftsCount += 区块数×256×dt/ScanPeriod`，`ScanPeriod=60`（公共字段，mod 可改）→ **全图扫一整轮 ≈60 秒（现实时间）**；每帧上限 `MaxShaftsToPollPerFrame=500` 柱（公共字段，注释明言 mod 可调） | SubsystemBlocksScanner.cs:7,30,38-39
- **pollPass**：`LoopChunks` 环游全部区块一圈 → `m_pollPass++`，**随存档持久化**（PollChunkCoordinates/PollPoint/PollPass 三键）→ 每根柱子每轮被调一次，pollPass 是全局轮次计数器 | SubsystemBlocksScanner.cs:88-96,103-107,117-119
- **环境开关**：作物生长只在 `EnvironmentBehaviorMode.Living`(=0) 生效，Static 世界不长 | SubsystemPlantBlockBehavior.cs:74-79; Survivalcraft\Game\EnvironmentBehaviorMode.cs:2-5
- **改格不走 ChangeCell 直改**：Grow* 里一律 `m_subsystemCellChangeQueue.QueueCellChange`——攒批、每 20s 游戏时间（或满 10000 条）批量应用，应用时校验"当前值==排队时值"（CAS，光值除外），期间被玩家改过就丢弃 | Survivalcraft\Subsystem\SubsystemCellChangeQueue.cs:26-40,44-66
- **所以"生长一阶段"的最小时间单位 = 一整轮 ≈60s**：Rye 间隔 4 轮/阶段 ≈4 分钟，改良后 2 轮；7 阶段全程约 14-28 分钟（现实时间）[由 §3 公式推得]。

## 3 · 生长阶段：data 位状态机 + 条件概率（GrowRye/GrowCotton/GrowPumpkin）

三作物共用骨架：光照门 → data 取 size → 野生/家种分岔 → 查耕地 data 算参数 → `pollPass % 间隔 == 0` 才推进 → 顺带掷退化骰 → 成熟扣氮。

**data 编码**：Rye `size=data&7`(0-7)+`bit3=isWild`（RyeBlock.cs:168-182）；Cotton `size=data&3`(0-2)+`bit3=isWild`（CottonBlock.cs:153-167）；Pumpkin **倒序** `size=7-(data&7)` + `bit3=isDead`（BasePumpkinBlock.cs:213-217）。

|---|---|---|---|---|
| 光照门（上格 ExtractLight） | **≥9**，否则 return | ≥9 | ≥9 | SubsystemPlantBlockBehavior.cs:143,201,257 |
| 成熟上限 | size==7 停 | size==2 停 | size==7 / isDead 停 | :148,206,262-264 |
| 野生株 | 无条件每轮 +1 到 7（不查土不查温） | 同左 | （无野生位，只有 isDead） | :151-157,209-213 |
| 下方非 168 耕地 | **转野生**（继续长但收获报废） | 同左 | 长得慢（按无土参数） | :194-197,250-252,266-270 |
| 基础间隔（轮）/ 基础退化率 | 4 / 0.8 | 8 / 0.8 | 4 / 0.15(死) | :165-166,221-222,272-273 |

- 草/花只比一档 data：`IsSmall` 且上格光≥9 → 翻 small 位（`GrowTallGrass/GrowFlower`，9 行范式） | SubsystemPlantBlockBehavior.cs:122-140
- **腐化钩子**：Grow 入口先走 ⚡`ModsManager.HookAction("GrowPlant")`，mod 返 `skip=true` 可整体接管原版作物生长（仅对上面 11 种 HandledBlocks 生效，**mod 新方块不在此列，见 §7**） | SubsystemPlantBlockBehavior.cs:86-95; Survivalcraft\ModsManager\ModLoader.cs:1761-1767

## 4 · 环境条件：光/温/踩/盖

- **光**：只看**植株上那一格**的亮度（`GetCellValueFast(x,y+1)` 的 ExtractLight），作物 9、仙人掌 12、树苗 `GetCellLight(y+1)>=9`；被不透明方块罩住=光 0=不长，但**不会死**（南瓜 isDead 后也不自动消失） | SubsystemPlantBlockBehavior.cs:143 等; SubsystemCactusBlockBehavior.cs:40; SubsystemSaplingBlockBehavior.cs:144
- **温度**：`GetSeasonalTemperature(x,z)+SubsystemWeather.GetTemperatureAdjustmentAtHeight(y)` 只用来**放大间隔**（寒带慢 2-3 倍），无冻死/热死判定 | SubsystemPlantBlockBehavior.cs:164,220,271
- **水分**：耕地每轮询一次 `DetermineHydration`（BFS 3 步：横邻 1 步、纵向 2 步，可穿泥土(2)与已湿耕地(168)，遇水(18)→湿）；湿/干结果排队，每 10s 游戏时间批量写 data bit0 | SubsystemSoilBlockBehavior.cs:29-39,64-76,88-132
- **被踩**：耕地 OnCollide——质量>20kg 且不蹲下，下落 vy<-3 或走路按 `1.5×dt` 概率 → 排队退化；2.5s 游戏时间后**耕地变泥土(2)**（蹲行安全） | SubsystemSoilBlockBehavior.cs:18-27,55-62
- **被覆盖**：耕地顶上出现"不透明且可碰撞"的方块 → OnNeighborBlockChanged 直接**变泥土(2)**；随后植株的 OnNeighborBlockChanged 发现下方仍适合（泥土能种）→ 不死，但下轮转野生；若下方整个没了（挖掉）→ 植株 DestroyCell | SubsystemSoilBlockBehavior.cs:41-47; SubsystemPlantBlockBehavior.cs:42-68
- 作物本体**无踩踏判定**（OnCollide 未 override），踩不坏苗，只坏土。

## 5 · 收获链与养分循环

- **掉落表全在 `GetDropValues(oldValue,newValue,toolLevel,…)`，与工具等级无关（toolLevel 三者皆不读），徒手=工具**；打掉即为收获，无"右键采集"。

| 作物 | 未成熟 | 成熟收获 | 出处 |
|---|---|---|---|
| Rye 野生 | 无掉落 | size>2 时 33% 掉 1 粒野黑麦种(173:4) | RyeBlock.cs:134-137 |
| Rye 家种 | 无 | size5→1 种(173:4)；size6→1-2 种；**size7→1-3 粮(173:5) + 50% 经验块(248)** | RyeBlock.cs:139-165 |
| Cotton | 无 | **size2→1-2 种(173:6)**；非野生再加 1-2 棉絮(205) + 50% 经验块(248)；野生只掉种 | CottonBlock.cs:22-45 |
| Pumpkin | size≥1 掉同型瓜（**强制 isDead=true**——摘下的瓜再放不会继续长） | size7 完整瓜=PumpkinBlock 自身再 +50% 经验块(248) | BasePumpkinBlock.cs:160-172; PumpkinBlock.cs:7-19 |

- **重种循环**：成熟只掉种子/粮，耕地氮被扣 → **氮是稀缺资源**，全游戏只有三个来源：①腐化链 `食物→(GetRotPeriod 轮询/物品扫描每 60s 伤害+1)→腐烂食物→再腐→GetDamageDestructionValue=堆肥值168(氮1)`（创造/冒险模式不腐） | Survivalcraft\Block\FoodBlock.cs:6,60; SubsystemRotBlockBehavior.cs:38-53,52-77
- ②硝石块(102)右键耕地顶面 → **3×3 全部氮拉满 3**，消耗 1 个 | SubsystemFertilizerBlockBehavior.cs:14-47
- ③腐肉等含 `m_compostValue` 的方块放置即成氮1耕地（RottenMeatBlock 等构造第 4 参） | Survivalcraft\Block\RottenMeatBlock.cs:7
- 氮 0 的耕地顶面贴图变贫瘠（37 vs 53），一眼可辨 | SoilBlock.cs:20-29
- **最经济循环**：氮3+湿耕地 = Rye 间隔 2 轮/阶段、退化率 0，约 14 分钟 7 穗 1-3 粮。

## 6 · 三种生长范式对比

| | A 作物（data 阶段机） | B 树苗→树（时间表+笔刷） | C 仙人掌（堆叠概率） |
|---|---|---|---|
| 调度 | SubsystemBlocksScanner 轮询（≈60s/轮，无状态） | 自持 `Dictionary<Point3,SaplingData>` 存**成熟时刻**，Update 每帧最多处理 10 株 | 同 A（OnPoll） |
| 状态存哪 | 方块 data 位（随地形存档，零额外数据） | 行为子系统自己的存档键 `Saplings`（`点;TreeType;MatureTime` 字符串） | 无（原地概率生成） |
| 推进条件 | 光≥9 + `pollPass%间隔` + 土壤/温度调参 | 游戏时间到 `MatureTime`（生存 480-600s/创造 8-12s）+ 4 角区块 Valid + 光≥9 | 上格空且光≥12 + 下方沙/仙人掌 |
| 随机性 | 间隔取模+退化骰 | 成功率=`2×PlantsManager.CalculateTreeProbability(温,湿,y)`（旁边 3×3 有水：温=(温+10)/2、湿抬到 12）；失败→枯灌木(28) | 每轮 25% |
| 成长形态 | 同格换 data（0→7 阶贴图渐大） | 删除树苗格 → `PlantsManager.GetTreeBrushes(type)` 16 变体随机抽一支，试 20 次空间校验（只容忍树叶重叠）后 `brush.Paint` 一次性"印"出整树 | 向上 `QueueCellChange` 新增一格（下两格不能都是仙人掌 → **自长最高 2 节**：沙上 y1、y2 可长，y3 被"下两格皆仙人掌"条件挡住） |
| 结构性产出 | 无（单格作物） | 多格树干+树叶+树枝 | 铅直柱 |
| 照抄价值 | 新粮食/经济作物 | 果树/巨型植物 | 竖直蔓延方块（如水晶） |

出处：A=§3；B=SubsystemSaplingBlockBehavior.cs:48-57,82-96,120-189,191-215 + PlantsManager.cs:11-274,423-499；C=SubsystemCactusBlockBehavior.cs:34-48。世界生成端的野生作物/树种分布同走 `PlantsManager.GenerateRandomPlantValue`（湿度/温度驱动，PlantsManager.cs:282-329）。水下植物（WaterPlantBlock 族）只有"附着校验"无生长轮询（SubsystemWaterPlantBlockBehavior.cs:5-23）。

## 7 · Mod 视角：自定义作物最小集

**代码路线（推荐，4 件套）**：
1. 新 `Block` 子类（`public static int Index`，自动发现），家族变体全走 data 位——RyeBlock 是标准模板（size+野生两位）。
2. 新 `SubsystemPollableBlockBehavior` 子类：`HandledBlocks=>[你的Index]`，`OnPoll` 里查光照/土壤 → `QueueCellChange` 推 data。原版 `SubsystemPlantBlockBehavior.OnNeighborBlockChanged` 已 **sealed** 不可借尸，注释明说"新植物请自建 ModPlantBlockBehavior" | SubsystemPlantBlockBehavior.cs:30-42
3. 行为注册 = 项目模板（Database.xml）加 `<SubsystemTemplate Class="Game.你的行为类">`（原版四个生长行为全这样挂，Survivalcraft\Content\Assets\Database.xml:3453-3492）；behavior 与方块的关联走 `HandledBlocks` 或方块 `Behaviors` 名单（逗号分隔，按名查子系统实例） | Survivalcraft\Subsystem\SubsystemBlockBehaviors.cs:19-33
4. 收获 = override `GetDropValues`（照抄 RyeBlock.cs:123-166）。

**不加自建 tick 的替代做法**：
- ⚡`GrowPlant` 钩子接管**原版 11 种作物格**的生长（skipVanilla=true 后自己写）——但 HandledBlocks 是代码数组，mod 新方块进不去，此路只适合改原版 | SubsystemPlantBlockBehavior.cs:86-95
- "种下即成品"伪种植：SeedsBlock.GetPlacementValue 直接返回成熟 data 的目标值，零 tick 零行为 | SeedsBlock.cs:36-55
- 树苗式自管时间表：不进轮询体系，行为子系统自带 `Dictionary` + `Update`，可精确控制每株成熟时刻且随存档往返（照抄 SubsystemSaplingBlockBehavior）——代价是状态要自己持久化。

**最短照抄链**：单格观赏植物=GrowTallGrass（9 行，SubsystemPlantBlockBehavior.cs:122-130）；竖直蔓延=SubsystemCactusBlockBehavior.OnPoll（14 行）；完整粮食作物=GrowRye（57 行，含土壤/温度/退化/扣氮全家桶）。

## 9 · 快查路由

- 种子放不上/种下就消失 → §1 步骤 4（IsSuitableForPlants 表）| 04 页
- 作物不长 → 依次查：EnvironmentBehaviorMode 是否 Living（§2）→ 上格光照 ≥9（§4）→ 下方是否 168 且非野生（§3）→ 寒带间隔放大（§3）
- 作物长成野生/枯死 → 退化骰 §3（氮+湿任一为 0 就有概率）
- 想要氮 → §5 三来源（腐化链/硝石/堆肥方块）
- 成熟不掉东西 → GetDropValues 表 §5（野生株只有种子）
- 树苗不发芽 → §6 B 列：区块 Valid/光/成功率（有水翻倍概率）
- 自定义作物 → §7 四件套；接管原版 → GrowPlant 钩子
- 调生长速度 → SubsystemBlocksScanner.ScanPeriod/MaxShaftsToPollPerFrame 或 Grow* 内间隔参数
