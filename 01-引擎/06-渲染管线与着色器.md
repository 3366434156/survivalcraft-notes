## 一句话定位

一帧从 ViewWidget 到 GL 的完整路径：IDrawable 排序 → 批次按 Layer 排序 → Display 提交链 → GLWrapper 状态缓存 → Shader(语义头+uniform) 编译绑定。

## 核心机制

### 一帧主链

ViewWidget.Update/Draw → `SubsystemDrawing.Draw(camera)` (E:\SurvivalcraftAPIProject\Survivalcraft\Widget\ViewWidget.cs:134) → 收集所有 IDrawable 的 `DrawOrders` 塞进 SortedMultiCollection<int,IDrawable> 后按 drawOrder 升序调 `Draw(camera, drawOrder)` (SubsystemDrawing.cs:39-56)。挂进绘制的两种身份：Subsystem 实现 IDrawable，实体组件实现 IDrawable（SubsystemDrawing.cs:83,113）。

实际 drawOrder 数值表（`m_drawOrders` 静态字段）：

| 绘制者 | drawOrders | 含义 |
|---|---|---|
| SubsystemSky | [-100, 5, 105] (SubsystemSky.cs:139) | -100 水下/雾参数计算，5 天空，105 水面 |
| SubsystemTerrain | [0, 100] (SubsystemTerrain.cs:40) | 0 = PrepareForDrawing+DrawOpaque+DrawAlphaTested，100 = DrawTransparent (SubsystemTerrain.cs:472-484) |
| SubsystemWeather | [50] (SubsystemWeather.cs:50) | 雨雪 |
| SubsystemParticles | [300] (SubsystemParticles.cs:25) | 全部粒子（另见 07 页） |

相机矩阵：`Camera` 抽象出 ViewPosition/ViewMatrix/ProjectionMatrix/ViewProjectionMatrix/ViewFrustum (Camera.cs:10-28)；透视投影 near=0.1 far=2048 (BasePerspectiveCamera.cs:228)。区块级视锥剔除在 TerrainRenderer.PrepareForDrawing (TerrainRenderer.cs:83,101-105)。

### Display 提交链与状态机（设备级，全部实读）

所有几何最终走 Display 四个静态入口：`DrawUser` (Display.cs:91-117)、`DrawUserIndexed` (:119-161)、`Draw` (:163-172)、`DrawIndexed` (:174-195)，每个都是同一条 7 步链：

ApplyRenderTarget → ApplyViewportScissor → ApplyShaderAndBuffers → ApplyRasterizerState → ApplyDepthStencilState → ApplyBlendState → GL.DrawArrays/DrawElements (Display.cs:100-112)。

- **RenderTarget**：Display.RenderTarget 非 null 时绑该 FBO，否则绑 m_mainFramebuffer(=0) (GLWrapper.cs:794-805)；RenderTarget setter 顺带重置 Viewport/Scissor 到目标尺寸 (Display.cs:51-65)。**无独立 SwapChain 类**：后缓冲交换在 Window.cs:728-734（ANGLE 走 Egl.SwapBuffers，否则 m_view.SwapBuffers）。
- **背面/坐标约定（重点坑）**：绑后备缓冲（RenderTarget==null 且 m_mainFramebuffer==0）时 Viewport 的 Y 翻转 (GLWrapper.cs:685)、Scissor 的 Y 翻转 (:704-706)；CullClockwise/CullCounterClockwise 的 FrontFace 随是否 RT 反向 (:719,724)。即 UI(后备缓冲) 与 RT 内渲染的绕向语义相反。
- **状态缓存**：GLWrapper 对全部 GL 状态做脏检查缓存（InitializeCache GLWrapper.cs:366-407），Enable/Disable、BlendFunc、BindTexture、BindBuffer、UseProgram、BindFramebuffer 都只在变化时调 GL；原始 GL 调用（如 BlitFramebuffer）必须手动置 `GLWrapper.m_framebuffer = -1` 失效缓存 (RenderTarget2D.cs:98-100)。
- **状态对象锁**：RasterizerState/DepthStencilState/BlendState/SamplerState 均继承 LockOnFirstUse（LockOnFirstUse.cs:2-10），首次绑到 Display 后 IsLocked，再改抛 "Object was attached to a device"；Display.RasterizerState 等 setter 也会加锁 (Display.cs:22-47)。预设都是 static readonly 锁定实例：RasterizerState 6 个（RasterizerState.cs:11-25，默认 CullCounterClockwise+Scissor 关）、DepthStencilState 4 个（DepthStencilState.cs:9-15，Default=读写/LessEqual）、SamplerState 6 个（SamplerState.cs:17-47）。
- **纹理槽分配**：ApplyShaderAndBuffers 按 uniform 枚举顺序自动分配纹理单元，Texture2D/Texture2DArray/SamplerCube 计入 `num`，超 GL_MAX_COMBINED_TEXTURE_IMAGE_UNITS 抛 "Too many simultaneous textures."（GLWrapper.cs:910-1051，:911-912）；**纹理与采样器在参数表里必须成对相邻**（tex 在 num2、sampler 在 num2+1，:918-920），配不齐抛 "Associated SamplerState is not set" (:1054)。采样器参数按纹理句柄缓存（m_textureSamplerStates，:928-963），换贴图采样器时要换新纹理或清缓存才生效。
- **Clear**：GLWrapper.Clear (GLWrapper.cs:1057-1082) 清深度时强制 DepthMask(true) 并把 m_depthStencilState 置 null（下次 Apply 重发），清时强制关 Scissor。
- **设备丢失/重置**：GLWrapper.HandleContextLost (GLWrapper.cs:1084-1097) → Display.HandleDeviceLost/Reset 遍历 GraphicsResource.m_resources 调各资源 HandleDeviceLost/HandleDeviceReset (Display.cs:343-355)；GraphicsResource 终结器把 Dispose 抛回主线程 Dispatcher（GraphicsResource.cs:11-13）。UseReducedZRange 置位会对所有 Shader 重编译（Display.cs:67-77）。
- **上下文创建**：WINDOWS 原生 WGL(GL.GetApi(Window.m_view)) 或 ANGLE/EGL 兼容模式（游戏目录 UsingAngle 标记文件锁定，libEGL+libGLESv2 绝对路径预加载，GLWrapper.cs:76-114,210-255）；EGL 配置固定 RGBA8+D24S8+ES3 (InitializeEgl GLWrapper.cs:163-207)；iOS 直连 OpenGLES.framework 防桌面 libGL 劫持符号 (:257-275)；另有 WINDOWS 无头 PBuffer 上下文 InitializeHeadless（Display.cs:219-225、GLWrapper.cs:286-363）。

### 着色器加载：两条路（mod 自定义都走这两条）

资源注册：mod zip 里 `Assets/` 前缀文件在 ModEntity.CombineContent 被剥前缀注册进 ContentManager（ModEntity.cs:290-292），即 `Assets/Shaders/MyFx.vsh` → 键 `Shaders/MyFx.vsh`。原版 8 对着色器同机制（E:\SurvivalcraftAPIProject\Survivalcraft\Content\Assets\Shaders\）。

- **成对象路（ContentManager.Get<Shader>）**：`ContentManager.Get<Shader>("Shaders/AlphaTested")` 不带后缀 → ShaderReader 按 DefaultSuffix ["vsh","psh"] 取两个文本 → `new Shader(vsh, psh, macros)`；文件名以 "AlphaTested" 开头自动附 ALPHATESTED 宏 (ShaderReader.cs:5-15)。Get 的键拼接 = name+"."+suffix (ContentManager.cs:79,89-121)。使用者：SubsystemMovingBlocks.cs:437、ComponentDiggingCracks.cs:101、SubsystemParticles.cs:133。
- **取源码路（ShaderCodeManager.GetFast）**：`GetFast("Shaders/Opaque.vsh")` 按 '.' 拆成 (路径,后缀) → `ModsManager.GetInPakOrStorageFile<string>` (ShaderCodeManager.cs:6-13) 返回原文，调用方自己 new Shader 并选宏。使用者：TerrainRenderer.cs:66-78、SubsystemModelsRenderer.cs:230-252、ComponentFirstPersonModel.cs:43-44。
- **mod 自定义**：包里放 `Assets/Shaders/Xxx.vsh`+`.psh`，代码里 `new Shader(ModsManager.GetInPakOrStorageFile<string>("Shaders/Xxx","vsh"), ...("Shaders/Xxx","psh"), 宏)`，现成范例 ComponentBlockHighlight.cs:89-96（用 Shaders/Highlight）。GetFast/Get 均可被 mod 同名资源覆盖（ContentManager.AddOrUpdate，后载 mod 赢）。
- **#include**：ShaderCodeManager.GetIncludeText 递归展开 `#include "..."` 并剥行注释但保留 `// <.../>` 元数据行 (ShaderCodeManager.cs:49-73)；引擎另一套 ShaderCache.ResolveIncludes 用 `#include <名>` + basePath (ShaderCache.cs:119-158)。
- **第三条路（引擎内嵌资源）**：LitShader 无参构造反射读程序集内嵌 `Engine.Resources.Lit.vsh/.psh`（LitShader.cs:270-280，物理文件 E:\SurvivalcraftAPIProject\Engine\Resources\Lit.vsh）。

### 编译与语义头契约

`Shader.Construct → CompileShaders` (Shader.cs:69-78,263-364)：

1. `ParseShaderMetadata` 扫两种注释元数据 (Shader.cs:135-180)：`// <Semantic Name='COLOR' Attribute='a_color' />`（语义→属性名）与 `// <Sampler Name='u_samplerState' Texture='u_texture' />`（纹理→采样器名）。实测样例 E:\SurvivalcraftAPIProject\Survivalcraft\Content\Assets\Shaders\AlphaTested.vsh:50-52、AlphaTested.psh:39。
2. `PrependShaderMacros` (Shader.cs:214-253)：前置 `#version`、`#define GLSL`、顶点着色器注入 `uniform float u_glymul;` 和 `#define OPENGL_POSITION_FIX`（z 未缩时是 `y *= u_glymul; z = 2z - w`，UseReducedZRange 时只剩 y 翻转），然后用户宏，最后 `#line 1`；源码里的原 #version 行被注释掉。
3. 链接后逐 ActiveAttribute 查 Semantic 映射，查不到抛 "Attribute ... has no semantic defined" (Shader.cs:310-314)；逐 ActiveUniform 建 ShaderParameter；Texture2D/Texture2DArray uniform 必须有对应 Sampler 元数据，否则抛 (Shader.cs:338-346)。
4. 顶点属性槽与 VertexDeclaration 的 Semantic 匹配在 GetVertexAttribData (Shader.cs:107-133)，缺语义元素抛 "VertexElement not found for shader attribute"。

**未用 uniform 被裁**：GL 链接器裁掉无活跃引用的 uniform，`GetParameter(name)` 对裁掉的直接抛 "Parameter ... not found"；`GetParameter(name, true)` 返回 Null 型参数，所有 SetValue 遇 `Type==Null` 直接 return（Shader.cs:47-50、ShaderParameter.cs:45-47）——引擎自身参数一律 allowNull 取。

**宏体系两套并存**：ShaderMacro（名字校验 [_a-zA-Z] 开头，值禁换行，ShaderMacro.cs:13-30）走 Shader.PrependShaderMacros；ShaderDefines（glTF PBR 宏构造器，对应官方 renderer.js）自带**稳定字符串 hash**（string.GetHashCode 每次进程不同不能持久化，ShaderDefines.cs:19-27），支持增量 UpdateHash/Clone 拷 hash (:32-51)、SetAlphaMode 改值时整体重算 (:184-208)、GetDefinesCode 自带 `#version {ShaderCache.GlslVersion} es` (:213-220)、CreateFromVertexDeclaration/CreateFromModelMeshPart 从顶点布局自动生成 HAS_*/USE_SKINNING/USE_INSTANCING/NOT_TRIANGLE 宏 (:334-411)、ToShaderMacros 转回旧体系 (:271-284)。

### Parameter 绑定与上传

- ShaderParameter 构造按类型开缓存数组 (ShaderParameter.cs:20-42)；各 `SetValue` 重载严格校验 (Type, Count)，不匹配抛 "Shader parameter type mismatch."（如 float 版 ShaderParameter.cs:44-56；Matrix 版 :306-349；Texture2D :452-465；SamplerState :481-493）。float[] 长度 1/2/3/4/16 分别对应 Float/Vector2/3/4/Matrix (ShaderParameter.cs:58-114)。
- 值没变不置 IsChanged，变了才标记；`GLWrapper.ApplyShaderAndBuffers` (GLWrapper.cs:807-1055)：先 `shader.PrepareForDrawing()`（设 u_glymul=±1，Shader.cs:102-105）→ BindBuffer → UseProgram → 顶点属性指针仅在 (shader, offset, arrayBuffer, declaration) 四元组变化时重发（:827-852）→ 只上传 IsChanged 的 uniform（:861-908）→ 纹理/采样器处理（见上节）。
- TransformedShader 持 ShaderTransforms，`UpdateMatrices` 算 worldView/worldViewProjection (ShaderTransforms.cs:46-74)；LitShader.PrepareForDrawingOverride 按 instances 数上传矩阵、仅灯光≥1 传 world、仅雾传 worldView（LitShader.cs:282-291）；UnlitShader.PrepareForDrawingOverride 上传 u_worldViewProjectionMatrix (UnlitShader.cs:86-90)。
- 变体宏：ShaderMacro 即 #define。LitShader 宏组合 = USE_LIGHTING/ONE_LIGHT/TWO_LIGHTS/THREE_LIGHTS/USE_EMISSIONCOLOR/USE_VERTEXCOLOR/USE_TEXTURE/USE_FOG/USE_ALPHATHRESHOLD/USE_INSTANCING/MAX_INSTANCES_COUNT（LitShader.cs:293-333）；UnlitShader 宏见 UnlitShader.cs:98-118。ShaderCache.SelectShader 按 (源码名 ^ ShaderDefines hash) 缓编译对象，程序可落 GL 二进制缓存 (ShaderCache.cs:166-189,343-380)。

### 批次与层排序（重点坑）

- BaseBatch 身份 = Layer + DepthStencilState + RasterizerState + BlendState (BaseBatch.cs:3-13)。TexturedBatch 复用键再加 纹理+UseAlphaTest+SamplerState，命中则 MoveFirst（MRU）(BasePrimitivesRenderer.cs:44-68)。FontBatch/VectorFontBatch 同构（PrimitivesRenderer2D.cs:96-130）。
- Flush 时若新批次 Layer 小于现有最大 Layer 则置 m_sortNeeded，用 **`List<T>.Sort` 只按 Layer 排** (BasePrimitivesRenderer.cs:37,123-131) —— **不稳定排序，同 Layer 的多个批次相对顺序不保证**，同层异纹理的绘制次序不可依赖；要确定次序就分 Layer。
- 提交分段：TexturedBatch/FontBatch 单次索引超 **196605**（=65535×3，对应 16 位索引上限）分段 DrawUserIndexed (BaseTexturedBatch.cs:79-95、BaseFontBatch.cs:41-91)；FlatBatch 三角同样 196605、线 131070 (BaseFlatBatch.cs:41-85)。`EnsureCapacity`/`EnsureQuadCapacity` 支持一次性预扩容 (BaseTexturedBatch.cs:24-39)。
- 2D/3D 默认状态不同：2D 全家（FlatBatch2D/TexturedBatch2D/FontBatch2D/VectorFontBatch2D）默认 DepthStencilState.None；3D 全家默认 DepthStencilState.Default；Rasterizer 一律 CullNoneScissor、Blend 一律 AlphaBlend、采样一律 LinearClamp（FlatBatch2D.cs:3-7、PrimitivesRenderer3D.cs:9-69、FontBatch3D.cs:5-11）。
- 2D 视口矩阵：`PrimitivesRenderer2D.ViewportMatrix()` 把像素坐标映射到 NDC（y 向下，PrimitivesRenderer2D.cs:9-31）；TexturedBatch2D.Flush()/FlatBatch2D.Flush() 无参版本自动用它。
- 每类批各有一个 static UnlitShader 常驻：BaseTexturedBatch m_shader/m_shaderAlphaTest、BaseFlatBatch m_shader、BaseFontBatch m_shader（均 useVertexColor=true）；自管 Shader 时走 `FlushWithDeviceState(shader)` 直传。
- 批合并：QueueBatch/QueueBatchTriangles/QueueBatchLines 把另一批顶点/索引搬进来并可顺带 Transform（FlatBatch2D.cs:9-105、TexturedBatch2D.cs:10-24）。
- 几何工具：FlatBatch3D.QueueSphere/QueueSphereWithLines/QueueCircle/QueueCurvedCylinder/QueueBoundingBox/QueueBoundingFrustum/QueueCube（FlatBatch3D.cs:12-523）；FlatBatch2D.QueueEllipse/QueueDisc/QueueRectangle（FlatBatch2D.cs:141-232）。

### 顶点格式与索引缓冲

- 顶点元素三元组 = (Offset, Format, Semantic 字符串)；Semantic 尾部数字自动拆成 SemanticName+SemanticIndex（"TEXCOORD0"→TEXCOORD+0，VertexElement.cs:19-37）。VertexDeclaration 构造时 Offset=-1 自动顺排并算 VertexStride；**全局元素数组缓存 m_allElements**（VertexDeclaration.cs:13-37）——Equals 比较的是 m_elements 引用 (VertexDeclaration.cs:43)，所以同布局声明天然相等、GLWrapper 用引用比较判断要不要重发属性指针。
- 内置顶点结构只有两个：VertexPositionColor（16B：Vector3+NormalizedByte4 色，VertexPositionColor.cs:3-6）、VertexPositionColorTexture（20B：+Vector2 TEXCOORD，VertexPositionColorTexture.cs:3-7）。地形/模型的自定义布局在各自工程里按同法 new VertexDeclaration。格式枚举含 NormalizedByte4/NormalizedShort2 等 GPU 压缩格式（VertexElementFormat.cs，翻译到 GL 的 normalize 标志在 GLWrapper.cs:1107-1153）。
- 索引格式自动选型：`IndexBuffer.FormatForVertexCount(vertexCount)` ≤65535 用 16 位（带宽减半），否则 32 位；`IndexBuffer.ForceThirtyTwoBits=true` 一键回退旧行为（IndexBuffer.cs:31-40）。SetData 支持 int→ushort 收窄（逐个溢出检查，IndexBuffer.cs:61-81）与 ushort→int 加宽 (:82-93)；越界校验按"实际写入宽度"算，int[] 写 16 位缓冲不会误报 (:168-179)。Model.Initialize 同样做 4 字节小端索引流收窄（Model.cs:383-400）。
- 纯 Color 枚举到 GL 的映射在 ExtensionMethods.cs:11-31（Position/Color/Normal/Tangent/TEXCOORD0-7/Instance/BLENDINDICES/BLENDWEIGHTS），自定义语义名必须在这个表或 Semantic 头里能对上。

### 纹理装载链

- 构造：`new Texture2D(w,h,mipLevels,colorFormat)` 按 ColorFormat 选 GL 内部格式（Texture2D.cs:80-138）；AllocateTexture 预分配各 mip 的 TexImage2D(null) (:267-288)，SetData 系列再填内容。mipLevels 超链长会被钳到 log2 链长（InitializeTexture2D :454-480）。
- **ColorFormat 家族**：未压缩 Rgba8888/Rgba8888Srgb/Rgb565/Rgba5551/R8 + HDR R32f/RG32f/RGBA32f/Rgba16f + 压缩 LinearLDR/SrgbLDR（ColorFormat.cs）。R8 用遗留 GL_LUMINANCE（shader 里 r=g=b=value，Texture2D.cs:104-110）。sRGB 判定 IsSrgb、浮点判定 IsHDR (:28-37)。
- 装载入口：`Texture2D.Load(stream, premultiplyAlpha, mips)`（:344-350，预乘见混合语义节）、`LoadSrgb`（:371-397，BaseColor/Emissive 用）、`LoadHDR(Span<float>|Span<Half>)`（:407-447）、`Image<Rgba32>` 重载（:333-342，mip 用 GL GenerateMipmap 而非 CPU 生成）。`LoadForYsf` 是给引用不规范工程的中转 (:449-452)。
- **Silk.NET 指针坑（已修，自定义代码别踩）**：泛型 `TexImage2D(in T)` 传的是"变量地址"不是"指针值"，nint 会变成从栈上读像素 → 小图垃圾像素、大图 AV；必须走 void* 重载（Texture2D.cs:181-189、CompressedTexture2D.cs:108-114、CubemapTexture.cs:137-144 三处注释实证）。
- ASTC：CompressedTexture2D 仅支持 ASTC，设备无 KHR_texture_compression_astc_ldr 直接 NotSupported（CompressedTexture2D.cs:15-18）；.astc 文件头 16 字节魔数 0x13ABA15C+块宽高+尺寸自解析（:168-200）；**ASTC 不能 GenerateMipmap**，要 mip 必须离线生成逐层 SetData（:194-198 注释）；基类 SetData 全部封死为 Invalid（:62-90）。
- FBO：RenderTarget2D = Texture2D + framebuffer(+depth renderbuffer)，AllocateRenderTarget 挂 ColorAttachment0+Depth，CheckFramebufferStatus 不完整抛异常（RenderTarget2D.cs:133-185）；回读 GetData→ReadPixels (:52-78)；BlitFromBackbuffer/BlitFromRenderTarget 支持格式转换（RGBA8→RGBA16F），Raw GL 调用后必须失效 GLWrapper.m_framebuffer 缓存（:88-123）。CubemapTexture 六面×mip 分配（CubemapTexture.cs:88-108），CubemapRenderTarget.BindFace(face,mip) 逐面渲染（CubemapRenderTarget.cs:101-124）。
- 模型纹理链：Model.GetTexture(index) 惰性解码（DDS/KTX2/XNB 容器直接拒载，Model.cs:141-183），mip 级数=log2(max(w,h))+1 (:169)；sRGB 开关 `Model.LoadTexturesInSrgb`（static，:13）决定 BaseColor/Emissive 走 Srgb8Alpha8；glTF 无纹理模型默认 LinearWrap、dae 默认 PointClamp（GetDefaultSamplerState :209-223）；无纹理回退 DefaultWhiteTexture 让 BaseColorFactor 生效 (:113-136)。

## 坑与对策

- **自定义 uniform 被裁**：着色器里声明了但没实际使用 → GetParameter 抛 not found。→ 用 `GetParameter(name, true)` 拿 Null 参数，或确保 uniform 被读写。
- **SetValue 类型不匹配运行时抛**：如给 Vector2 传 Matrix。→ 对着 ShaderParameterType 写强类型 SetValue；数组长度必须 1/2/3/4/16。
- **AlphaBlend 下贴图没预乘**：边缘白边/整体偏亮。→ 加载时 `Texture2D.Load(s, true)` 或改用 NonPremultiplied 批次。
- **同 Layer 批次顺序抖动**：List.Sort 不稳定。→ 需要 Z 序的内容拆不同 Layer，或同 Layer 用深度缓冲而非绘制序。
- **Attribute/Sampler 忘写语义头**：编译链接成功但 Construct 抛 "has no semantic/sampler defined"。→ 每个顶点属性一行 `<Semantic/>`，每个 sampler 纹理一行 `<Sampler/>`（照抄 AlphaTested.vsh:50-52）。
- **顶点着色器漏 OPENGL_POSITION_FIX/u_glymul**：画面上下颠倒或深度异常。→ 顶点源码保留 `#ifdef GLSL` 段并应用 OPENGL_POSITION_FIX 宏（引擎会注入该宏定义）。
- **mod 覆盖原版着色器全局生效**：Assets/Shaders/Opaque.vsh 同名覆盖后所有区块都换。→ 只覆写自己新增的名字（如 Fx01_SwordRain.vsh）。
- **ContentManager.Get<Shader> 前提是 ShaderReader 注册的 vsh+psh 都在**：缺一个抛 "Not Found Res [Shaders/X.vsh]"。→ 两文件同名成对打包，扩展名小写。
- **状态对象改了抛 "Object was attached to a device"**：LockOnFirstUse 锁死后不可变。→ 自建新 RasterizerState/SamplerState 等，用前一次赋值到位；别改 CullNoneScissor 等预设。
- **改了纹理的采样器不生效**：采样器参数按纹理句柄缓存（GLWrapper.m_textureSamplerStates）。→ 同一纹理句柄换采样器要换纹理实例；或每次用不同 SamplerState 配新纹理。
- **纹理超过 GL_MAX_COMBINED_TEXTURE_IMAGE_UNITS 抛 "Too many simultaneous textures"**：一个 Shader 的纹理 uniform 数有硬上限。→ 合并纹理图集或减 uniform。
- **RT 内绘制三角形消失/被剔除而后备缓冲正常**：FrontFace 在 RT 与后备缓冲相反（GLWrapper.cs:719,724）。→ 自定义顶点数据绕向按目标缓冲验证；用 CullNone 最稳。
- **原始 BlitFramebuffer 后画面错乱**：Raw GL 调用绕过 GLWrapper 缓存。→ 照 RenderTarget2D.BlitFromBackbuffer 把 `GLWrapper.m_framebuffer = -1` 置脏再绑回（RenderTarget2D.cs:98-100）。
- **ASTC 纹理调 SetData 直接抛 Invalid**：压缩纹理只能走 `SetData(mipLevel, imageSize, source)` 系。→ 读 .astc 头自解析后用专用重载；mip 必须离线做好。
