## 核心机制

### 入口链(Windows)

`Program.Main`(`Program.cs:78`) → 参数解析+单实例互斥锁(`Program.cs:82-157`, 第二实例弹框退出) → `EntryPoint()`(`Program.cs:166` → `:196`)：设语言、`Storage/VersionsManager` 初始化、挂 `Window.Frame += FrameHandler`(`:217`)、加 `GameLogSink`(`:223`) → `Window.Run(1600, 900, Resizable, title)`(`:231`)。`Window.Run`(`Window.cs:420`) 里 `m_view.Run()` 是**阻塞调用**(`Window.cs:547`, 注释原文"会阻塞")，窗口每帧回调 `RenderFrameHandler`(`:836` 注册)。Android 无 Main：`MainActivity` → `Window.Activity`(`Window.cs:54`)，帧链相同。

### 帧回调三段式

`Program.FrameHandler`(`Program.cs:242-253`)按 `Time.FrameIndex` 分派：`<0` 只清屏白；`==0` 调 `Initialize()`(`:255-276`：Settings→ExternalContent→Music→`ScreensManager.Initialize`→`APIUpdateManager.Initialize`，`ScreensManager.Initialize`(`ScreensManager.cs:197-203`)只注册 `"Loading"` 一屏并 `SwitchScreen("Loading")`)；`>0` 每帧调 `Run()`(`:278`)。

### 一帧完整顺序(输入→更新→绘制)

`Window.RenderFrameHandler`(`Window.cs:718-735`)，单线程，无渲染线程：

1. `BeforeFrameAll()`(`:902-914`)：`Time.BeforeFrame`(`Time.cs:77-103`，算 `FrameDuration`、跑 `QueueTime/FrameIndexDelayedExecution` 队列，边扫边执行，到期回调重排当帧再跑) → `Dispatcher.BeforeFrame`(`Dispatcher.cs:70`，排空跨线程队列，异常记日志不中断) → **输入采样**(`InputBridge/Display/Keyboard/Mouse/Touch/GamePad/Mixer` 的 `BeforeFrame`，`Window.cs:906-913`)。
2. `Frame?.Invoke()`(`:722`) → `Program.Run()`(`Program.cs:278-364`)：Uri 处理 → `PerformanceManager/Motd/MusicManager.Update` → **`ScreensManager.Update()`**(`:298`) → `DialogsManager/JsInterface`。`ScreensManager.Update`(`ScreensManager.cs:210-215`)=切换动画推进+`Widget.UpdateWidgetsHierarchy(RootWidget)`——UI 树的 `Update` 在这里，含 `GameScreen.Update`(`GameScreen.cs:34-56`)：每 300 真实秒自动存档(`:36-41`)、调 `GameManager.UpdateProject()`(`:48`) → `GameManager.UpdateProject`(`GameManager.cs:185-193`)=`SyncDispatcher` 每帧消费队头 1 条(`:186-189`)+`m_subsystemUpdate.Update()`(tick，见 02-Subsystem体系)。
3. 绘制(同在 `Run` 内，更新之后)：`ScreensManager.Draw()`(`Program.cs:328`；被 `LoadingScreen.m_isContentLoaded` 挡住，`Program.cs:327`，所以首屏加载日志先攒后刷) → `PerformanceManager.Draw` → `ScreenCaptureManager.Run`。`ScreensManager.Draw`(`ScreensManager.cs:217-227`)→`LayoutAndDrawWidgets`(`:447-484`，850 基准 UI 缩放)。
4. `AfterFrameAll()`(`Window.cs:916-924`)：`Time.AfterFrame`(`Time.cs:105-115`)——算 `CpuFrameDuration`、`FrameIndex++`、`FrameDurationLimit>0` 时 `Task.Delay().Wait()` 限帧(`:109-114`，模组自由旋钮，全仓无赋值点) → `SwapBuffers`(`Window.cs:728-734`)。

### 屏幕切换机制(ScreensManager)

- 注册表 `m_screens`(名字→Screen)，`AddScreen`(`ScreensManager.cs:47`)；原版各屏在 LoadingScreen 第 18 步 `InitScreens` 时才 new 出来。
- `SwitchScreen(string, params)`(`:49`)→`SwitchScreen(Screen)`(`:51-88`)：先派 `OnSwitchScreen` 钩子(**钩子里可改 `ref screen`**，即换目标屏/拦截) → 同屏直接 return(`:59-61`) → 建 `AnimationData`(旧屏淡出+新屏淡入，`Speed=4f`) → 旧屏 `IsUpdateEnabled=false`、清输入(`:71-74`) → `HistoryStack` 进/出栈(`:76-81`，目标=栈顶时是"返回"弹出) → `CurrentScreen=screen`。
- **Leave/Enter 不在切换瞬间**：动画 `Factor≥0.5` 时才执行(`UpdateAnimation`，`:273-335`)——旧屏 `Leave()`+`OnScreenLeaved` 钩子+从 RootWidget 移除(`:294-303`)，新屏 `Children.Insert(0,…)`+`Enter(parameters)`+`OnScreenEntered` 钩子+恢复更新(`:305-317`)。切换后头半帧两屏都不在更新中。
- `GoBack`(`:90`)=切到历史栈顶。`RebuildAllScreens`(`:100-159`)整表重建(切语言/字体)，`RestartGameToScreen`(`:166-172`)写 `SettingsManager.RestartReturnScreen` 后 `Window.Restart()`(`Window.cs:627-631`)重启进程，`LoadingScreen` 完成时 `ConsumeRestartReturnScreen`(`:183-195`)直达——**mod 改设置后"重启生效"走这条链**。

### 进世界与退世界

`PlayScreen.Play`(先 `BeforeGameLoading` 钩子可拦) → `GameLoadingScreen` 状态机(`GameLoadingScreen.cs:21-83`)：`WaitingForFadeIn` → `Upgrading`(`Task.Run` 修复/升级世界，`:36-63`) → `Loading`(同步 `GameManager.LoadProject`(`:69`)+`SwitchScreen("Game")`(`:70`))。`GameScreen` 构造时挂：窗口失焦→`SaveProject(true,false)`(`GameScreen.cs:13`)、窗口关闭→`DisposeProject`(`:14`)；`Leave` 时 `SaveProject(true,true)`(`:28`)。`Program.Run` 顶层 catch(`Program.cs:308-322`)：任何更新异常→回 MainMenu+弹日志对话框+`DisposeProject`。

### 时间与速度(基准时间倍率)

两套时钟：墙钟 `Engine.Time`(静态，界面也走)与游戏时间 `SubsystemTime`(只在 tick 里推进，唯一推进点 `SubsystemUpdate.Update:46`)。tick 的 `dt = Min(Time.FrameDuration, MaxGameTimeDelta) × m_gameTimeFactor`(`SubsystemTime.cs:62-67`)：`MaxGameTimeDelta` 默认 `1/LowFPSToTimeDeceleration`(默认 10→0.1 秒上限，低帧率=时间变慢而非补帧)；`GameTimeFactor` setter 钳 0~256(`:55-58`)，睡眠/菜单直接写私有字段绕过钳制(`:113`、`:135-137`)。模组改速度的正道是 `ChangeGameTimeDelta(SubsystemTime, ref float dt)` 钩子(叠加式)。墙钟侧 `Time.PeriodicEvent/SingleEvent/Queue*DelayedExecution`(`Time.cs:56-75`)是"每 N 秒/跨过某刻/延时一帧"的标准件。

## 坑与对策

- **切换屏后立刻读 `CurrentScreen` 的 Enter 结果**：`Enter` 要等动画过半(`ScreensManager.cs:305-307`)才跑，同帧读不到。需要初始化数据走钩子 `OnScreenEntered` 或在 `Enter` 自己完成。
- **Dispatcher 未初始化**：`Window.Run` 之前的静态代码调 `Dispatcher.Dispatch` 抛 `InvalidOperationException`(`Dispatcher.cs:39-41`)。mod 代码入口只可能是 `__ModInitialize` 之后。
- **模组自建 Screen 忘了 `AddScreen`**：`SwitchScreen("名字")` 按 `m_screens` 查，查不到抛 `ArgumentNullException`(`ScreensManager.cs:62-64`)。
- **限帧睡眠阻塞**：`FrameDurationLimit` 的睡眠是 `Task.Delay().Wait()`(`Time.cs:117-118`)，在游戏线程上同步睡，别在 tick 里动态调大。
- **`Input.Back/Cancel` 在 LoadingScreen 是退出确认**(`LoadingScreen.cs:690-693`)，加载中误触弹确认框不中断加载。
