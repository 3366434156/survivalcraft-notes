## 一句话定位

液体就是一个 `FluidBlock` 方块 + data 里的 4bit 液位/1bit 顶面标志；**流动模拟不在方块类里而在行为子系统**（每流体一个 `SubsystemFluidBlockBehavior` 子类，定时跑 `SpreadFluid` 两遍扩散），实体侧一切（浮力/阻力/溺水/视效）都消费 `ComponentBody.ImmersionFactor` 这一个由液面高度算出来的数。

## 1 数据与渲染基础：FluidBlock

### 1.1 data 编码与几何（Survivalcraft/Block/FluidBlock.cs）

| 项 | 值 | 出处 |
|---|---|---|
| 液位 level | data bit0-3（`GetLevel/SetLevel`） | FluidBlock.cs:196-198 |
| 顶面标志 isTop | data bit4（`GetIsTop/SetIsTop`） | FluidBlock.cs:200-207 |
| 每级液面高度 | `0.875 × (1 - level/MaxLevel)`，级 0=满（源头） | FluidBlock.cs:17 |
| 碰撞盒 | 每级一个 y∈[0,高度] 的盒（`GetCustomCollisionBoxes`） | FluidBlock.cs:8-19/:45-46 |
| 放置 | `GetPlacementValue` 恒放 **data 0 = 满液位源头** | FluidBlock.cs:140-148 |
| 顶面标志维护 | `UpdateIsTop`：上方无同族流体 → isTop=1，加块/改块/上方邻居变化时刷新 | FluidBlock.cs:31-58 |

- **IsTop 的作用**：只有柱顶那格画平滑液面并参与波动，柱内格不画面（见下）。
- `IsHeatBlocker=true`（:194）、`IsCollapseDestructibleBlock=false`（:209）——液体不导热、不可被塌方破坏。

### 1.2 同族判定：反射建表（免写比较器）

`FluidBlock.Initialize` 沿继承链上溯，找**直接继承 FluidBlock 的那一层类**作为"族标准"，再扫全部已注册方块，类型相同或是其子类的都标 `m_theSameFluidsByIndex[i]=true`（FluidBlock.cs:23-43，判定入口 `IsTheSameFluid` :48）。因此：

- `WaterBlock` 是水族标准（WaterBlock.cs:5），`WaterPlantBlock : WaterBlock`（WaterPlantBlock.cs:5）自动入族——同族间不画面、液位互通；
- mod 直接继承 `WaterBlock/MagmaBlock` 即加入原族；直接继承 `FluidBlock` 即自建一族。

族表构建时机：`BlocksManager.PostProcessBlocksLoad` → `ResetBlocks()`（按 `is FluidBlock` 填 `BlocksManager.FluidBlocks[]`，BlocksManager.cs:135-145）→ 逐方块 `Initialize()`（BlocksManager.cs:407-418）。

### 1.3 顶面平滑与纹理

- 顶面 8 邻采样定 4 角高度：同族顶格取本级高度、同族非顶格取 1、空气取 0.01 哨兵、他物取 0（`CalculateNeighborHeight` FluidBlock.cs:179-192）；4 角取邻域最大值，遇 0.01 哨兵强制落 0 形成缺口（`CalculateFluidVertexHeight` :126-138）。
- 侧纹理槽 = `DefaultTextureSlot+16`，顶/底 = `DefaultTextureSlot`（:150-155）；顶面按坡度符号偏移贴图坐标（:84-86）。
- 同族流体之间不生成面（`ShouldGenerateFace` :157-177）。

## 2 流动模拟链：SpreadFluid 全解

### 2.1 谁在更新、多久一次

| 流体 | 行为子系统 | 扩散周期（游戏时间） | 无限源规则 | 出处 |
|---|---|---|---|---|
| 水 18 | `SubsystemWaterBlockBehavior`（IUpdateable） | **0.25s** | generateSources=**true** | SubsystemWaterBlockBehavior.cs:9/:13/:16-18 |
| 岩浆 92 | `SubsystemMagmaBlockBehavior`（IUpdateable） | **2.0s**（8 倍慢） | generateSources=**false** | SubsystemMagmaBlockBehavior.cs:14/:18/:21-23 |

两个子系统各自只跑自己的 `m_fluidBlock`（基类构造传入，SubsystemFluidBlockBehavior.cs:26-29）；`HandledBlocks` 写死 `[18]`/`[92]`，原版实现**不能**直接复用于 mod 方块。

### 2.2 触发与队列

- 任何邻居方块变化 → 该格入 `m_toUpdate`（OnNeighborBlockChanged，SubsystemFluidBlockBehavior.cs:53-58）；加块/改块时顺带刷 isTop（:45-51）。
- `SpreadFluid()` 每次跑 **2 遍**（外层 `for i<2` :150），每遍先处理完 `m_toUpdate` 再统一写 `m_toSet`、`ProcessModifiedCells`、清队列（:237-263）——批处理避免同帧连锁抖动。

### 2.3 单格决策四分支（对队列中每个同族流体格，:159-235）

先收集：四周同族最小液位 `num`（初值 MaxLevel+1）与相邻 level-0 源头数 `num2`（:166-176）。设本级液位 `level`：

1. **沉降/干涸**（:177-189）：`level≠0 && level≤num && 上方无同族`（没有任何更满的邻居喂我）→ 本格液位抬到 `num+1`；**`num+1>MaxLevel` 时写 0 = 空气（干涸消失）**（:185 的三目写的就是字面量 0）。孤立流水一格一格衰减直至蒸发。
2. **无限源**（:190-194）：`generateSources && level≠0 && num2≥2`（两侧贴着源头）→ 本格升为 level 0 源头（MC 式无限水；岩浆关此规则）。
3. **喂下层**（:195-199）：下方是同族且其 level>1 → 下方压成 level 1（满柱）。
4. **横向扩散**（:200-234）：下方非同族（空/挡板）→ 先 `OnFluidInteract` 尝试占据下方（带 level 1，:200-206）；若 `level<MaxLevel`，对四方向做 `LevelAtNearestFall` DFS 找"最近的落点"（:208-213，:354-387：遇挡板断路、遇更满同族断路、下方可流即落点），最近方向 `FlowTo(level+1)`，垂直两方向 `FlowTo(MaxLevel)`（:214-233）——**朝最近落差方向衰减少、侧向衰减快**，形成"优先找坑填"的形态。

### 2.4 写回与占位

- `FlowTo`（:336-352）：目标超过 MaxLevel 直接放弃；同族且更新液位更低 → 改液位；异族 → `OnFluidInteract`。
- `OnFluidInteract` 基类（:267-282）：目标格 `!IsFluidBlocker_` 才允许 `DestroyCell`+写流体。`IsFluidBlocker` 默认 true（Block.cs:73），仅空气/水/岩浆/火/雪/植物类为 FALSE（BlocksData.txt 表头第 27 列 `IsFluidBlocker`）——**流体只能流进这些格**。
- 写回时目标若已被**异族流体**占据 → `DestroyCell` 后覆盖（:245-257），即水/岩浆相遇时后写者赢，但两族各自的 `OnFluidInteract` 重写（见 §3）会在覆盖前拦下变成石头/玄武岩。

### 2.5 流速场（实体消费）

`CalculateFlowSpeed`（:96-138）：取所在液柱顶格，比较四方同族液位差得方向向量（更满一侧指过来，:111-119），叠加缓存的位置 Simplex 噪声游移 ±0.05（:123-132，缓存上限 1000 条满了就整表清），×2 返回——这是 `ComponentBody` 水阻力的目标速度（见 §5）。`GetSurfaceHeight`（:66-94）自下而上找液柱顶返回 `y+液面高度`，是沉浸度、水下视效共用的液面查询。

## 4 桶链（装/倒）

方块索引：空桶 90（EmptyBucketBlock.cs:6）、水桶 91（WaterBucketBlock.cs:6）、岩浆桶 93（MagmaBucketBlock.cs:6）；水桶 `PriorityUse=1500`（WaterBucketBlock.cs:33）。全部逻辑在 `SubsystemBucketBlockBehavior.OnUse`（SubsystemBucketBlockBehavior.cs:33-205）：

1. **装**（空桶在手持，:37-93）：Raycast(Gathering) 命中方块 → 目标是 WaterBlock/MagmaBlock **且 `GetLevel(data)==0`（只舀源头，流水舀不到）**（:46-53）→ 背包换入对应满桶 + `DestroyCell` 销毁源格（:63-71/:82-90）；槽内叠数>1 走"扣 1 个空桶、找空位放满桶"分支，放不下回滚并提示。
2. **倒**（水桶/岩浆桶在手持，:131-165）：Raycast(Interaction) → `componentMiner.Place(落点, MakeBlockValue(18/92))`（data 0 = 源头，:133/:142/:157）→ 成功后空桶回收；Place 失败回滚并提示（:145-154）。
3. 同文件顺带处理：挤奶（ComponentUdder，:94-129）、油漆桶 128/脱漆剂 129 对 IPaintableBlock（:166-203）。
4. 桶本身是普通方块（IsFluidBlocker=FALSE 只是数据列），mesh 在 `WaterBucketBlock.Initialize` 用 `Models/FullBucket` 的 Bucket+Contents 两部件拼装、Contents 部件染水色（WaterBucketBlock.cs:10-35）。

mod 自建流体想配桶：原版子系统 `HandledBlocks` 写死自家桶，需仿 :33-165 自写一个（对流体格判 `IsTheSameFluid`+level==0 即可泛化）。

## 5 实体在流体里

### 5.1 沉浸度量（ComponentBody.UpdateImmersionData，ComponentBody.cs:611-628）

每帧物理末尾：以 `Position.Y+0.01` 所在格查 `GetSurfaceHeight` → `ImmersionDepth = 液面高 − Position.Y`（:619），**`ImmersionFactor = saturate((Depth / StanceBoxSize.Y)^0.7)`**（:620），`ImmersionFluidBlock = FluidBlocks[所在格内容]`（:621）。无液面则三项清零（:623-627）。`FluidCollidable=false` 可整体豁免（:117）。

### 5.2 浮力与水阻力（ComponentBody.Update 内）

- 浮力（:498-504）：重力 `Vy -= 10dt` 后，`Vy += 10 × (1/Density) × ImmersionFactor×(1+0.03sin) × dt`——**Density 是实体自身密度**（ComponentBody.cs:129，模板值），Density≤1 才能上浮。
- 水阻力（:513-549）：速度向流速场 lerp——水平 `WaterDrag.X × ImmersionFactor`、垂直 `WaterDrag.Y`（:530-534）；目标速度 = `CalculateFlowSpeed`（顺流漂移）；`FrictionFactor≠1` 时按噪声随机在 1 与 FrictionFactor 间切换制造湍流（:524-529）；无支撑且在流场中时附加旋摆/转向（WaterTurnSpeed/WaterSwayAngle，:535-549）。落水冲击因此被泄力——`CalculateFallDamage` 只看触地速度突变（ComponentHealth.cs:52-62），深水着陆不触发。
- 模型动画参数：`IsInWater = ImmersionFactor>0`、`ImmersionFactor` 直传动画控制器（ComponentCreatureModel.cs:377-379）。

### 5.3 游泳（ComponentLocomotion）

- 涉水减速：`ImmersionFactor>0.2` 步速 ×0.66（ComponentLocomotion.cs:407-409）。
- 竖直分量：行走 order 的 Y 按 ImmersionFactor 折算上浮 `Vy += 10×Acc×orderY×Immersion×dt`（:455）；未站地且 Immersion>0 记 `m_swimming`（:442-445）。
- 跳跃：站立**或 `ImmersionFactor>0.5`** 都允许跳（:504-505）——水中按跳即上浮。
- `SwimOrder`（鱼/船用）：`ImmersionFactor>0.5` 且 `SwimSpeed>0` 才生效，速度 lerp 向 `SwimSpeed×order`，全速冲刺 ×2 加速 ×4（:486-494）；order.Y 近平（|Y|≤0.07）关重力、全程关水阻力（:499-500）。
- 游泳代价：`ImmersionFactor>0.33` 且未站地（或 ImmersionDepth 超过眼高）→ 走路饥饿消耗 ×2（ComponentVitalStats.cs:268-280）。

### 5.4 溺水与呼吸（ComponentHealth.Update）

| 呼吸模式 | 规则 | 出处 |
|---|---|---|
| Air（人/陆生） | **眼位所在格是 FluidBlock（或 y>259）**→ `Air -= dt/AirCapacity`，否则回满 | ComponentHealth.cs:275-281 |
| Water（鱼类） | `ImmersionFactor>0.25` 或冻在冰里回满 Air，否则耗 | :283-287 |

- 溺水伤害：每 1.0s 游戏时间，`Air==0` → `Injure(1/AirLackResilience)`（:325-330）。**氧气按眼位格判定，不看身体 immersed 比例**——贴着 1 格深的水底爬不会呛水。
- 岩浆伤害 + 红屏脉冲：:289-302；鱼搁浅（CanStrand 且 Immersion<0.25 且已落地）：每秒掉血（:347-353）。

### 5.5 火、弹道、掉落物

- 水灭火：`ImmersionFactor>0.5` 且在水 → 熄灭 + SizzleLong（ComponentOnFire.cs:74-78）；岩浆点火见 §3。
- 弹道：`IsInFluid = 所在格 is FluidBlock`（SubsystemProjectiles.cs:72/:332-339），飞行阻力换 `DampingInFluid=0.001`（Projectile.cs:36/:530）；入水弹跳/水花与岩浆殉爆已在 [28 页](28-弹道与远程武器.md) 详载。火枪在 `ImmersionFactor>0.4` 时哑火（SubsystemMusketBlockBehavior.cs:154）。
- 挖流体本身：`OnItemHarvested` 不掉落、格子保留满液位（§3 表末行）。

## 6 视听

- **液面渲染**：§1.3 的 8 邻平滑；水色随温湿度（WaterBlock.cs:15），岩浆纯贴图色。
- **水下视野**（SubsystemSky pass -100，SubsystemSky.cs:286-327）：相机格查 `GetSurfaceHeight`，`ViewUnderWaterDepth=液面+0.1−camY`（水 :296）/ `ViewUnderMagmaDepth=液面+1−camY`（岩浆 :299）。水下：雾起始 0，雾色 = 温湿度查 Water 色表 × 0.66 × 深度衰减 × 天光（:302-317），天空不可见；岩浆中：雾色恒 (255,80,0)、haze 密度 10（:318-327）。⚡`ViewFogColor(ViewUnderWaterDepth, ViewUnderMagmaDepth, ref color)` 钩子（:376-382）。
- **屏幕覆盖**：进出水面瞬间播 `Textures/SplashOverlay` 全屏水波（0.66s 衰减，ComponentScreenOverlays.cs:58-92），入水方向带动视野偏移（:89）。
- **入水瞬间**：水深>0.3 → `Audio/WaterFallIn` + WaterSplashParticleSystem（有配额限流）；岩浆→`Audio/SizzleLong` + MagmaSplashParticleSystem，一次沉浸只放一次（ComponentBody.cs:584-608）。
- **环境循环音**：`Audio/Water`、`Audio/Magma` 全局循环轨，音量由水/岩浆行为子系统按"最近听者到流体距离"每 1s 上报（§2.1 表），SubsystemAmbientSounds 统一 lerp 淡入淡出（SubsystemAmbientSounds.cs:38-79）；岩浆 audible 时随机播 Sizzles（:60-63）——"贡献聚合"模式详见 [08 页](08-音频系统.md)。
- **脚步**：ImmersionDepth>0.2 且在水中 → 脚步材质切 "Water"（Audio/Footsteps/Water，SubsystemSoundMaterials.cs:66-73）。

## 7 mod 视角：自定义液体最小集

| 步骤 | 必写 | 照抄 |
|---|---|---|
| 1 方块类 | 继承 `FluidBlock`（自建族）或 `WaterBlock`（入水族）；至少重写 `GenerateTerrainVertices` 调 `GenerateFluidTerrainVertices` | 岩浆链最短：MagmaBlock.cs:19-31（Color.White 直接过，不调色）；要透明水感抄 WaterBlock.cs:12-29 |
| 2 行为子系统 | `SubsystemXxxBlockBehavior : SubsystemFluidBlockBehavior, IUpdateable`：构造 `base(BlocksManager.FluidBlocks[自Index], generateSources)` + 重写 `HandledBlocks` + `Update` 里 `PeriodicGameTimeEvent(周期,0)` 调 `SpreadFluid()` | SubsystemWaterBlockBehavior.cs 全文 60 行；**不能复用原版子系统**（HandledBlocks 写死） |
| 3 数据参数 | BlocksData.txt 行：`Density`（与实体浮力无关，实体看 ComponentBody.Density）、`FrictionFactor`（水阻力湍流倍率）、`IsFluidBlocker=FALSE`（必须，否则别的流体/自己都流不进） | WaterBlock/MagmaBlock 行 |
| 4 交互反应（可选） | 重写 `OnFluidInteract` | 水→花岗岩 / 岩浆→玄武岩两段（§3 表） |
| 5 环境音（可选） | Update 里 `CalculateDistanceToFluid` + 上报 `SubsystemAmbientSounds` 新增属性 | SubsystemWaterBlockBehavior.cs:19-30（新增音轨要改 SubsystemAmbientSounds，原版只有 Fire/Water/Magma 三条） |
| 6 桶（可选） | 桶方块（mesh 照抄 WaterBucketBlock）+ 自写 OnUse 抽/倒 | SubsystemBucketBlockBehavior.cs:33-165，把"Is WaterBlock"换成 `IsTheSameFluid` |
| 7 注册 | mod 常规 AddBlock；族表与 FluidBlocks[] 在 `PostProcessBlocksLoad` 自动建，无需手工注册 | BlocksManager.cs:407-418 |

最简照抄判定：**岩浆链更短**（渲染无调色、无环境音也可跑、MaxLevel=4 流得慢好调试）；但要"能溺水/灭火/有水声"的观感就得抄水侧的消费端（那些不在方块类里，见 §5）。
