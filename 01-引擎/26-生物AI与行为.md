# 26-生物AI与行为（感知→决策→移动→攻击全链）

> 域: SC引擎 · 更新: 2026-11-01 · 状态: 全读(29/29 行为文件 + 调度/寻路/驾驶/攻击链 9 文件 + Database.xml 模板节选)+⚡挂点
> 一句话定位：**生物没有中央大脑——每个行为组件自带状态机持续"报价"ImportanceLevel，调度器每帧选最高者独占（赢家通吃），赢家写 Pathfinding 目标→Pilot 驾驶→Locomotion 出力；攻击走 模型动画命中帧→Miner.Hit→Attackment**。
> 源码引用一律仓库相对路径：行为族在 `Survivalcraft\Component\Behavior\`，其余组件在 `Survivalcraft\Component\`，游戏层在 `Survivalcraft\Game\`，子系统在 `Survivalcraft\Subsystem\`；模板数据 `Survivalcraft\Content\Assets\Database.xml`。

## 调度器：收集、竞争、节流

| 问题 | 答案（今日实读） |
|---|---|
| 收集者是谁 | `ComponentBehaviorSelector`（**组件**不是子系统）。`Load` 里 `Entity.FindComponents<ComponentBehavior>()` 全量收进 `m_behaviors`（ComponentBehaviorSelector.cs:39-44）。AICreature 模板自带该组件（Database.xml:182 `BehaviorSelector`），故所有生物模板自动有 |
| 怎么选 | 每帧 `Update`(:14-37)：`Health>0 且未嵌冰` 才参选(:16-17)，**线性扫一遍取 ImportanceLevel 最大者**置 `IsActive=true`，其余全清 false——无排序缓存、无优先级队列，每帧 O(n) 重算（importance 是动态的） |
| tick 频率 | 调度器每帧跑；**每个 behavior 也各自是 IUpdateable，每帧都被 SubsystemUpdate 调 Update**——"每生物每帧跑 N+1 个 Update"。省性能两招：①行为内部状态机节流（下表"节流"列）；②非选中行为只算 importance 不写路径，部分行为干脆 `if (IsActive)` 才跑状态机（SwimAround:30-35、FlyAround:32-37、RandomPeck:39-44、LayEgg:46-51） |
| IsActive 契约 | 虚属性，setter 可带副作用：FlyAwayBehavior 置 true 时清 `m_nextUpdateTime` 立即响应（ComponentFlyAwayBehavior.cs:46-53）。非选中≈让位：行为自己把 importance 归 0（如 Chase 放弃 :349-350） |
| 决策下传 | 赢家写 `ComponentPathfinding.SetDestination`（8 参：destination/speed/range/maxPathfindingPositions/useRandomMovements/ignoreHeightDifference/raycastDestination/doNotAvoidBody，ComponentPathfinding.cs:63-81）→ Pilot 避障驾驶 → order 并进 `ComponentLocomotion`（WalkOrder/TurnOrder/JumpOrder/LookOrder 每帧消费后清空 :301-313）。链路详见 [03页](03-实体与组件体系.md) |
| 跳跃 | `ComponentAutoJump`（LandAnimal 底座挂，ComponentAutoJump.cs:112-114 写 `Locomotion.JumpOrder`）；追击者踩着目标身体也跳（Chase :240-244） |

**importance 梯度**（同 03 页，今日复核）：FishOutOfWater 1000(:49) > CetaceanBreathe 400(:46) > 逃跑族 300(低血)/100(:84,:102) > Steed 275(:70) > Summon 270(:57) > AvoidFire 250(:79)/Herd 250(:139-142) > DumpRider 220(:57) > StubbornSteed 210(:45) > Chase 200(:77-79) > 游走/观望 0~10。

## 感知：没有"视线"，全是半径查询+概率

| 通道 | 实现 | 出处 |
|---|---|---|
| 视觉/索敌 | **没有 FindNearestCreature、没有射线 LOS**。统一范式：`SubsystemBodies.FindBodiesAroundPoint`（SpatialIndex 半径查询，SubsystemBodies.cs:18）拿到周围 body → 各行为自己的 `ScoreTarget` 打分（距离、Category 位掩码、随机概率、昼夜光强）取最高分 | Chase:424-477；AvoidPlayer:118-150；Stare:105-136；FindPlayer:126-158 |
| 昼夜光感 | `SubsystemSky.SkyLightIntensity`：<0.2 算夜（换用 NightChaseRange，Chase:283、AvoidPlayer:139）；<0.1 才算深夜（Howl 触发 :51、夜间追击转持久 :293-296） | |
| 听觉 | `SubsystemNoise.MakeNoise(sourceBody, loudness, range)`：半径内 FindBodiesAroundPoint → 实体上**所有 INoiseListener.HearNoise(sourceBody, pos, loudness)**（SubsystemNoise.cs:23-36）。监听者：RunAway(loudness≥1 记噪声源 :48-53)、FlyAway(≥0.25 直进 DangerDetected :65-71)、CattleDrive(≥0.5 累积驱赶向量 :29-38)。Chase 只发不收——追击时朝四周发 0.25/6m 噪声把猎物吓跑（:338），逃跑族听见即跑 = 原版"捕食链"的隐形一环 |
| 伤害感知（受击反击入口） | `ComponentHealth.Injured` 事件，四路订阅：Chase 反击（概率 ChaseWhenAttackedProbability，:246-267）、RunAway 记仇 10-20s（:63-66,:38-41）、SwimAway 同款（:48-51）、Herd 呼救（:120-123 调 CallNearbyCreaturesHelp） | |
| 领地/仇恨半径 | **没有领地系统**。仇恨半径=模板参数 Day/NightChaseRange；敌我判定=AutoChaseMask（CreatureCategory 位掩码，Chase:449）+ChaseNonPlayerProbability+GameMode>Harmless（:233）；亲近半径=StareRange/AvoidPlayer 的 Day/NightRange | |
| 命中校验（唯一真射线） | 攻击瞬间 `GetHitBody`：从自己中心向目标中心 Raycast，距离<`MaxAttackRange=1.75`（:81）且打到目标/其子 body/其脚下 body 才算命中（:552-568） | |

## 状态机范式：三个照抄模板

原版没有跨行为的状态机——"状态"= **组件组合 + importance 竞争 + 事件入口**。每行为内部用 `Game.StateMachine`（AddState(name, enter, update, leave)，TransitionTo 先 Leave 后 Enter、TransitionTo(null) 清空当前态允许重入，Survivalcraft\Game\StateMachine.cs:39-61）。最值得照抄的三套组合：

1. **温顺食草兽**（Gnu/Cow 底座，Database.xml:1103-1177）：LandAnimal 底座（Stare+MoveAway+AutoJump+LookAround+RunAway，Database.xml:645-654）+ HerdBehavior(HerdName/AutoHelp) + Category=LandOther。**继承链上无人挂 ChaseBehavior → 天然不打架**；受击跑 RunAway（100/300），被噪声吓（loudness≥1）。加什么性格就叠什么参数。
2. **群体捕食者**（Wolf 底座，Database.xml:258-332）：LandAnimal + ChaseBehavior(Day4/Night10/NightTime15/NonPlayerProbability 0.03——白天几乎不理你、夜里主动) + AvoidPlayer(Day20/Night0——白天怕人) + HerdBehavior(AutoHelp=True——被打全群围攻 20m/30s) + HowlBehavior + Miner.AttackPower=1 + EatPickable(Fish/Meat)。"游走+白天避人+夜猎+群呼"全靠参数表达。
3. **中立巨兽**（Bear 底座，Database.xml:194-257）：LandAnimal + ChaseBehavior(AutoChaseMask=LandOther,WaterOther,Bird——**掩码里没有 LandPredator，所以不主动惹狼**、但 AttacksPlayer 默认 true) + AttackPower=3.5，无 Herd 无 AvoidPlayer。掩码取舍=性格。

## mod 视角：给自定义生物挂 AI 的三层粒度

| 粒度 | 能改到什么程度 | 怎么做 |
|---|---|---|
| 1. 模板参数（纯数据） | 调"性格旋钮"：Chase 五参、AttackPower/HitInterval、FoodFactors、HerdName/AutoHelp、AvoidPlayer/Stare 半径、LowHealthToEscape、HowlSoundName、LayFrequency、AutoFeed——**不改逻辑只改数值/组合出的性格** | Database.xml 实体模板 `MemberComponentTemplate` 参数（或 Mod 覆盖/派生模板，InheritanceParent 继承展平，见 [24页](24-机制全链.md)链6）。注意 `SubsystemCreatureSpawn.CreatureType`（SubsystemCreatureSpawn.cs:7-35）是**生成规则**层（Name/SpawnLocationType/RandomSpawn/SpawnSuitabilityFunction），不管 AI |
| 2. 行为拼装（增删组件） | 换性格不改代码：在模板上增删 29 个现成行为组件自由组合。硬约束：①必须有 AICreature 底座（Selector+Pathfinding+Pilot 缺一就没人调度/走路）；②行为依赖兄弟组件——RandomPeck 要 BirdModel、DigInMud/FishOutOfWater 要 FishModel、Steed/DumpRider 要 ComponentMount、CattleDrive 要 HerdBehavior；③Category 必须单一 2 的幂，否则 Load 抛异常（ComponentCreature.cs:61-63） | 仿照上表 Gnu/Wolf 行抄一组 MemberComponentTemplate |
| 3. 代码层 | 无限：a) 写 `ComponentBehavior` 子类（继承 + `ImportanceLevel` 动态报价 + StateMachine，注册进实体模板 `Class` 字段）；b) 不写组件，用 ⚡钩子干预原版行为：`ChaseBehaviorScoreTarget`(改敌我评分 ModLoader.cs:1826)、`OnChaseBehaviorAttacked`(:1559)、`IsPredator`(:919 定义"谁吓鸟")、`CallNearbyCreaturesHelp`(:934)、`FindHerdCenter`(:951)、`ProcessAttackment`(:313 改伤害击退)、`SetHitInterval`(:100)、`OnEatPickable`(:275)、`OnCreatureAttackHit`(:2284) | a) 见 [03页](03-实体与组件体系.md)组件契约；b) 钩子全表见 [Mod钩子总表](../Mod钩子总表.md) |

## 快查路由

| 想做什么 | 去哪 |
|---|---|
| 生物发呆不动 | 查有没有 WalkAround/Peck/FlyAround/SwimAround 之一；再查 Pathfinding/Pilot 在不在（AICreature 底座） |
| 生物不攻击 | 查 ChaseBehavior 挂没挂 → Category/AutoChaseMask 掩码 → GameMode 是否 Harmless（:233）→ AttackPower>0 |
| 被打不反击 | ChaseWhenAttackedProbability<1（默认走 7m/7s 短追）；=1 才持久 30/60 |
| 调仇恨半径 | Day/NightChaseRange（昼/夜分档，SkyLightIntensity 0.2 为界 :283） |
