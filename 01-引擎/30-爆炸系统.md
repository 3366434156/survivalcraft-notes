# 爆炸系统

> 域: SC引擎 · 更新: 2026-11-01 · 状态: 全读(SubsystemExplosions/SubsystemExplosivesBlockBehavior/SubsystemImpactExplosivesBlockBehavior/SubsystemBombBlockBehavior/DetonatorElectricElement/GunpowderKegElectricElement/ExplosionParticleSystem/ComponentBody.UnderExplosion/Block爆炸字段/BlocksData.txt爆炸列)

## 一句话定位

`SubsystemExplosions` 把爆炸抽象成**一格压力源 + 六邻域 BFS 压力衰减波**：`AddExplosion` 只入队+先摇屏幕，`Update` 同帧合并 ±4 内的排队爆炸后同步跑 `SimulateExplosion`（毁格/链爆/碎块转弹），再 `PostprocessExplosions` 统一算粒子、点燃、全场实体冲量伤害和按总压力分档的音效——**伤害不进 Attackment 攻击管线**，走独立的 `ExplosionInjury`。

## AddExplosion 参数全解

签名：`AddExplosion(int x, int y, int z, float pressure, bool isIncendiary, bool noExplosionSound)` | `Survivalcraft\Subsystem\SubsystemExplosions.cs:237`

| 参数 | 含义 | 源码事实 |
|---|---|---|
| x,y,z | 爆心格坐标 | `pressure>0` 才收（:238）；入队 `ExplosionData`（结构 :140-159，含 `ValuesDictionaryForMods` :158 供 mod 夹带数据）并**立刻** `ApplyBodiesShaking`（:242→:764-768） |
| pressure | 爆源压力 | 全系统的唯一强度量：BFS 衰减、破坏判据、伤害公式、音效分档全由它派生。原版量级：雷击 39/19，小药桶 60，大药桶 2160 |
| isIncendiary | 燃烧型爆炸 | 影响三处：残余格起火概率 0.5（否则 0.2）与火焰强度 1.0（否则 0.3）（:803-809）；碎块烟迹变火色+寿命+10s（:732-744）；碎块 `IsIncendiary` 落地纵火（:746） |
| noExplosionSound | 静音爆 | 只控制**最终音效**（Update 里 `flag |= !NoExplosionSound` :272 → PostprocessExplosions 跳 PlaySound 但照发 Noise、照算粒子/伤害）。全仓唯一消费者=雷击（SubsystemSky.cs:260）；破坏、伤害、Noise 惊扰一律照常 |

- **两个入口的分工**：`AddExplosion`=从坐标起爆（不要求该格有方块）；`TryExplodeBlock(x,y,z,value)`=从方块起爆（:225-235，读该方块的 `GetExplosionPressure/GetExplosionIncendiary`，压力≤0 返回 false 不炸）——绝大多数触发链走后者，雷击独走前者。
- **批量合并**：`Update`（:246-327）取队首爆炸为锚点，与锚点每轴 |Δ|≤4 的全部排队爆炸**同帧一次模拟**（:266-272）；锚外的留到下帧。模拟是同步的（Task.Run 并行版本被注释 :270/:289-321）。
- **压力场容器**：`SparseSpatialArray<T>`（:7-138）= 以爆心为中心的 256³ 稀疏数组（origin=center-128 :34-36），4096 桶×4096 槽按位运算寻址，`m_activeBuckets` 跳空桶遍历（:28/:107-129）；场外读写落默认值——**离爆心超 128 格的格子不参与模拟**。

## 压力模型与破坏判据

`SimulateExplosion`（:343-639）流程：

1. **清爆心**：先 `ChangeCell(爆心, 0)`（:346），截止阈值 `num = max(0.13·√pressure, 1)`（:345）。
2. **逐波 BFS**（:372-638）：每波 `explosionPower += list.Count`（:374，累计**进入波次的格数**，空气+已毁+未毁通透格都算，被固挡的不进），波号 `num3++`；本波压力
   `num5 = pressure / (explosionPower^0.66 + 5·max(波号-7, 0))`（:376-377），低于阈值整波终止（:378）。
   - **轴向整形**：新点带 axis（0/1/2）。同轴邻居进 list3（下下波），垂直邻居进 list2（下一波）（:383-630）——垂直方向比轴向快一波，波前横向扩张。
3. **单点处理** `TryAddPoint`（:641-762）：
   - **韧性抖动**：`hash(x+913y+217546z)%100` → 抖动系数 `lerp(1,2)`，其中 1/8 格再 ×3（:655-659）——同种方块抗爆力参差，爆坑毛边来源。
   - **破坏判据**：6 邻压力和 `num4`（:661-666）÷ `max(抗性×抖动, 1)`（:667）得 `num6`；**`num6 > 1` 即毁**（:669）→ `DestroyCell(0, noDrop=true, noParticleSystem=true)`（:671-679；签名见 `Survivalcraft\Subsystem\SubsystemTerrain.cs:429-436`——不掉落不碎屑，掉落转弹见下）。
   - **即时链爆**：`num6>5 ? 0.95 : 0.75` 概率调 `TryExplodeBlock`（:681-684）——被毁格本身是爆炸物时接力（药桶堆几乎必连环）。
   - **碎块转弹**：未链爆时按掉落表把碎块注册成 Projectile 飞散（:686-750），初速来自 `CalculateImpulseAndDamage(中心, 质量60, 2·num4)`（:686）；限流三档：`m_projectilesCount<40` 全出 / <60 半出 / ≥80 只出 12.5%（:707-709）；`ExplosionKeepsPickables=true` 的方块（如烟花）落地必转掉落物（:719/:727-729）；半数碎块挂烟迹（<35 时，:730-745）。
   - **抗住则记账**：`num6≤1` 把 6 邻压力和记进 `m_surroundingPressureByPoint`（:754）；若方块 `IsCollidable_` 则 **BFS 在此挡住不再扩散**（:755-757）——实体方块才是波障，空气/草木直通。
4. **PostprocessExplosions**（:770-883）收账：
   - 残余格逐个发方块行为 `OnExplosion(value,x,y,z,邻压和)`（:794-802；虚函数 `Survivalcraft\Subsystem\BlockBehavior\SubsystemBlockBehavior.cs:51`）+ 起火判定（:803-809）。
   - 粒子：压力场逐格 `SetExplosionCell(格, 强度)`（:774-786），强度 `saturate(格压/15 − 0.001√总压)×random(0.2,1)>0.1` 才出。
   - ⚡`CalculateExplosionPower` 钩子可改总压（:787-793，影响音效档位）。
   - 音效七档按**总压**分（:839-882）：>200万→Explosion7(传53格) / >40万→E6(45) / >8万→E5(38) / >1.6万→E4(32) / >3500→E3(27) / >80→E2(23) / >0→E1(20)；每档同时 `MakeNoise` 惊扰 130~30 格生物（`Survivalcraft\Subsystem\SubsystemNoise.cs:11`）；音效延迟=距离/120s 上限 3s（音速模拟，`SubsystemAudio.cs:141`）。
- **方块抗爆数据链**：`Block.ExplosionResilience/DefaultExplosionPressure/DefaultExplosionIncendiary/ExplosionKeepsPickables`（`Survivalcraft\Block\Block.cs:161-167`，虚 getter :216-218/:491）← 由 BlocksData.txt 第 66~69 列反射灌入（加载器 `Survivalcraft\Managers\BlocksManager.cs:1037-1090`）。原版值：

| 方块 | 抗性 | 压力 | 燃烧 | 行 |
|---|---|---|---|---|
| 小/中/大火药桶 | 1 | 60 / 360 / 2160 | 否 | Content\Assets\BlocksData.txt:137-139 |
| 小/中/大燃烧桶 | 1 | 50 / 300 / 1800 | 是 | BlocksData.txt:140-142 |
| 引爆器 | 0 | 10 | 否 | BlocksData.txt:271 |
| 爆炸箭 | 1(默认) | 40 | 否 | ArrowBlock.cs:142-152（m_explosionPressures[7]，Table 驱动非 BlocksData） |

## 实体伤害链

`PostprocessExplosions` 对**全场** Bodies/Pickables/Projectiles 结算（不判距离场内场外，压力场外=0 压即无伤）：

- **公式** `CalculateImpulseAndDamage`（:895-921）：以实体所在格为中心扫 3×3×3，实格取"障碍压"（=实体格自身场压，:906-908），空格取场压；**方向**=27 邻压加权和的反向向量（:912，即远离爆心）；**冲量** `5.5555553·normalize(方向)·√|和| / max(√质量,1)`（:919）；**伤害** `2.59259248·√(27邻压总和) / max(√质量,1)`（:920）。伤害∝√压力、反比√质量——重型生物减伤。
- **ComponentBody.UnderExplosion**（`Survivalcraft\Component\ComponentBody.cs:323-355`）：
  1. 伤/冲量先除 `ComponentHealth.ExplosionResilience`（:326-328；实体爆炸抗性，默认 1，`ComponentHealth.cs:33`）。
  2. ⚡`OnComponentBodyExploded` 可改 injury/impulse/setOnFire/fluctuation（:330-338）。
  3. ±50% 随机浮动 → `ApplyImpulse` → `ComponentDamage.Damage`（结构伤害，:343）→ `Injure(ExplosionInjury)`（:345-347）。
  4. 伤害>0.1 时有 `min(伤-0.1, 0.5)` 概率身上起火 6~8s（:348-354）。
- **与攻击管线的关系**：`ExplosionInjury`（`Survivalcraft\Game\TypedInjury.cs:20-22`）**Attacker=null、不走 Attackment**——护甲（衣物减伤）不参与、击杀无归属记功；唯一通用减免钩子是 `Injury.Process` 里的 ⚡`CalculateCreatureInjuryAmount`（`Survivalcraft\Game\Injury.cs:51-57`）。原版给玩家减爆伤的正规途径只有调大实体 `ExplosionResilience`。
- **屏幕震动**：`AddExplosion` 当场对全场 Body `UnderExplosionStart(center,pressure)`（:764-768）——震幅 `5√p/(d/√p+1)`（`ComponentBody.cs:306-321`），可被 ⚡`OnComponentBodyExplodedStart` 改；实际表现为 Body 位置正弦抖动（ComponentBody.cs:431-435），玩家 Body 即视角抖动。
- **掉落物**（`Survivalcraft\Game\Pickable.cs:442-456`）：`IsExplosionProof` 免疫；`伤害/方块抗性>0.1` → 自爆转弹（爆炸物掉落物连环），否则被冲飞。
- **弹射物**（`Survivalcraft\Game\Projectile.cs:638-640`）：只加冲量不受伤；本批爆炸新生成的碎块弹跳过二次结算（SubsystemExplosions.cs:827-838）。

## mod 视角：自定义爆炸清单

- **最简照抄**：一次性当量 → `TryExplodeBlock`（要该格真有爆炸物）或直接 `FindSubsystem<SubsystemExplosions>().AddExplosion(x,y,z,压力,燃烧,静音)`；压力参考系：60≈小桶一枚坑，2160≈大桶掀层山，39≈雷击小坑。
- **"纯伤害不毁地形"没有原版开关**——`SimulateExplosion` 无条件 BFS 毁格（:669-679），也没有隔离参数。三条可行路：
  1. ⚡`TerrainChangeCell` 钩子在爆炸帧对目标区 Skip 原版写格（压力场照算、粒子/伤害/音效全保留）——最完整；
  2. 不发爆炸，手工对目标 Body 伪造成结算对：仿 SubsystemExplosions.cs:811-814 调 `CalculateImpulseAndDamage`+`body.UnderExplosion(impulse,damage)`，自己配粒子音效；
  3. 低压力贴脸多连爆近似（毁格判据是邻压和/抗性>1，压力大不到韧性就只推不毁）——不可控，不推荐。
- **水下/真空**：BFS 与伤害公式**无任何流体判据**——水下爆炸全效不衰减、isIncendiary 照样点水里的火 [源码未见差异，属引擎特性]；"入水即爆"是 Pickable/Projectile 各自的独立逻辑，与 SubsystemExplosions 无关。
- **可插钩子链**：`OnBlockExploded`（毁格时 :364/:690）、`CalculateExplosionPower`（改总压定音效 :787）、`OnComponentBodyExplodedStart`（改震幅）、`OnComponentBodyExploded`（改伤/冲量/着火）、`CalculateCreatureInjuryAmount`（最后减免）、`OnLightningStrike`（改雷击压力）。
- **性能红线**：`m_queuedExplosions` 是 public List，可自建 `ExplosionData` 入队（能用 `ValuesDictionaryForMods` 夹带数据）；巨型爆炸的两大开销=BFS 波次×每点 6 邻查 + 碎块弹限流（>40/60/80 阶梯 :707-709）；压力场 256³ 硬界，爆心挪了界也跟着挪但每场只一个原点。
