## 统计与读法

- 总 304 文件：方块类 298（根 Block 1 + 中间基类 41 + 其余 256）+ 接口 4 + struct 1（MovingBlocksRaycastResult）+ 无基类工具类 1（MovingBlock）。
- 被继承最多的中间基类（直接子类数，今日实读）：CubeBlock(23) > RotateableMountedElectricElementBlock(17) > MountedElectricElementBlock(14) = FoodBlock(14) > Stairs/Slab/PaintedCube/Flat/Chunk/Bucket(各9)。
- 表中"叶"= 无子类、构造函数填参即完成定制；工具/材质叶是标准做法：`public class X : 基类 { public static int Index = N; public X() : base(参数) { } }`（样例 CopperAxeBlock.cs:5）。
- 工具/近战武器基类七件同构（Axe/Hammer/Machete/Pickaxe/Rake/Shovel/Spear）：ctor(柄纹理槽,头纹理槽) + Models/X 的 Handle/Head 双骨烘焙 + UV 平移入 16×16 图集槽，`GenerateTerrainVertices` 恒空（地形不渲染）。
- 壁挂电器 data 约定：低 2-3 位=挂面（Rotateable 族 (data>>2)&7，Button/Detonator/MotionDetector/Photodiode data&7，SevenSegment/Target data&3）；电压档用反码 15-x（Battery 低4位、Button bit3-6）；连接方向由 GetConnectorType 按模型面+旋转查 SubsystemElectricity.GetConnectorDirection。
- IEE=IElectricElementBlock，IEWE=IElectricWireElementBlock，IPA=IPaintableBlock。
