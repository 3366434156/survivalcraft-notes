## 二、全族结构发现（最重要）

1. **生命周期三形态**（主页已立节）：
   - A 一次性自毁（`return !flag`）：BlockDebris、Kill、BurntDebris、WaterSplash、MagmaSplash、HitValue、Sound、GunSmoke（+时限 t≥0.5，GunSmokeParticleSystem.cs:89-91）、Fireworks、Leaves（12s 硬寿命）。
   - B 常驻共享池（`return false` 永不离场 + AddXxx 找空位）：RainSplash (RainSplashParticleSystem.cs:105)、SnowSplash (:71)、Explosion (:75)、PrecipitationShaft (:217)。注册点 SubsystemWeather.cs:252-253、SubsystemExplosions.cs:339。
   - C 跟随型 + IsStopped（宿主驱动，停止后等池清空再 true）：Fire、OnFire、SmokeTrail、FireworksTrail、Puke、Shapeshift(Stopped)、WhalePlume。
   - 特例 Fuse：恒 false 不自杀，宿主（SubsystemExplosivesBlockBehavior.cs:163-164）手动 RemoveParticleSystem——唯一"手动管理"样本。
2. **m_toGenerate 生成率累积器**是全族最通用微模式：`m_toGenerate += rate*dt` → 空位且 ≥1 发一粒 → 帧末 `MathUtils.Remainder`。速率可时变（GunSmoke 150→20、Shapeshift 15→35 ramp、Puke 由 SimplexNoise.Noise(3f*m_duration+GetHashCode()%100) 阵发 :53-55）。
3. **SmokeTrail 池寿命配平公式**：生成率 = clamp(50/size,10,40)/s，单粒 Duration = Particles.Length/rate (SmokeTrailParticleSystem.cs:49,81)——池大小、速率、寿命三者精确互锁，粒子无缝循环且总粒子数恒定。
4. **FireworksTrail 拖尾插值**：m_lastPosition → 当前 Position 随机 Lerp 取发射点 (FireworksTrailParticleSystem.cs:30,49)，高速发射体不出现虚线断点。
5. **Fireworks 池内自繁殖**：GenerationFrequency>0 的粒子按 freq×|v| 累积，>1 时从 m_nextParticle 顺延占池生成 HighDamping 子烟 (FireworksParticleSystem.cs:205-221)；池满自动停。初爆粒子多→拖尾少。
6. **Explosion 的 2000 大池键控复用**：Dictionary<Point3,Particle> 按 explosion 传播格复用粒子；池穷时随机抽 5 个抢 Strength 最弱者 (ExplosionParticleSystem.cs:26-54)；Strength -= dt/2.5s 驱动 slot 与上升。
7. **WaterSplash 单帧实例化限流**：静态 TryBeginInstantiation，100 次/帧（Time.FrameIndex 轮转，WaterSplashParticleSystem.cs:34-44）；三处调用方（ComponentBody.cs:591、Pickable.cs:354、Projectile.cs:576）先领配额再 new。
8. **Draw 门控反馈环**：Fire/OnFire/Fuse 在 Draw 里算视线点积+距离置 m_visible，Simulate 只在 visible 帧生成（Fire :79-87+:41、OnFire :79-86+:33、Fuse :68-76+:31）。Explosion 反向：空池跳过 Draw (:78-82)。
9. **交互三档**：
   - 无交互：Kill/HitValue/Shapeshift/烟花本体。
   - 液面漂浮：入 Water/Magma 判 GetLevelHeight，Y 钳 `液面+0.02*sin(2*距心距+10*m_time)` + 缩尺寸 + TTL 加速消耗（WaterSplash :115-125；MagmaSplash :91-101 几乎逐行克隆）。
   - 地形射线：SubsystemTerrain.Raycast(IsCollidable_) + CellFace.CalculatePlane() 按轴向速度反射（Puke 0.05 :75-83、BurntDebris 0.1 :72-81）；Paint 命中即粘附（速度清零 + HitPoint(0.03f) + 面≥4 关重力 + 1e-7 极强阻尼，PaintParticleSystem.cs:78-92）。
10. **Leaves 特殊**：BillboardingMode.None 手写 Right/Up 翻滚（双轴相位 :79-91）；每帧采样 chunk 光照但要求 chunk State≥InvalidVertices1 (LeavesParticleSystem.cs:96-100)；落地射线命中→转 Horizontal 贴地、延时 2s、首次触发 SubsystemDeciduousLeavesBlockBehavior.CreateFallenLeaves (:114-128)；入水立即终 (:111-113)。
11. **PrecipitationShaft**（唯一直接继承 ParticleSystemBase）：自管 TexturedBatch3D；雨画 QueueTriangle（3 顶点竖条）雪画 QueueQuad；雪 4x4 图集 16 槽；YLimit + 每粒子 RaycastParticle 下探 → 到点委托 RainSplash/SnowSplash；可见性 = 视线点积>0.5；GetBatchDemands 对 Rain/Snow 两纹理恒报 4 粒上界（纹理运行期切换的正解，PrecipitationShaftParticleSystem.cs:92-103，该文件带工程注释）。
12. **HitValue 是唯一文字粒子**：池容量 1，Draw 里 FontBatch3D（位图字体回退）/VectorFontSink3D（矢量链）双路排字，DepthStencilState.None、层 0；字号 0.006*√距离；0.2-20m 渐显渐隐；黑描边 (HitValueParticleSystem.cs:55-111)。有 ModLoader 钩子 SetHitValueParticleSystem（Attackment.cs:126-130、ComponentMiner.cs:691-700）。
13. **Paint 用方块图集当粒子纹理**：Texture = SubsystemBlocksTexture.BlocksTexture、TextureSlotsCount=16、slot15（PaintParticleSystem.cs:25,36,51）——粒子纹理不必是独立文件。
14. **光照取样三式**（见主页）：构造时六邻 max（最普遍）；Leaves 每帧采样+MultiplyColorOnlyNotSaturate；GunSmoke 光照折灰度。onFire/烟花本体等自发光系不采样。

## 四、坑清单（新发现部分）

1. 常驻池 AddXxx 满时静默丢粒子（无 else 排队）。
2. WaterSplash 绕过 TryBeginInstantiation 会造成水花风暴卡帧。
3. Puke/Paint/BurntDebris 每粒子每帧地形射线，容量×寿命即 CPU 账单。
4. Fuse 型不自杀：宿主漏 Remove → 永久泄漏（对照 OnFire 的 IsStopped 收尾正解）。
5. Fireworks 自繁殖抢池：初爆多则拖尾少。
6. 运行期换纹理（雨雪柱）必须 GetBatchDemands 恒报全部纹理上界——PrecipitationShaft 是活样本。
7. HitValue 的 3D 文字批 DepthStencilState.None 层 0，与其他粒子批次状态不同，不能混人共享批次预期。
