基类成员(ElectricElement.cs)：
- 3 属性: SubsystemElectricity(:5)/CellFaces(:7)/Connections(:8)；构造把 CellFaces 转只读列表(:11-20)。
- 9 虚方法 :22-38(GetOutputVoltage=0f/Simulate=false/OnAdded/OnRemoved/OnNeighborBlockChanged/OnInteract/OnCollide/OnHitByProjectile/OnConnectionsChanged)。
- `IsSignalHigh(v)=>v>=0.5f`(:40) 静态；`CalculateHighInputsCount()`(:42-52) 遍历 Connections 统计"非 Output 端口 + 邻居非 0 + 邻居输出高"的个数——**超过一半的具体元件的输入读取就是这一行**。

关键输入读取惯用法(全文统计)：
- `CalculateHighInputsCount()>0` 阈值型: GunpowderKeg/Detonator/Dispenser/Door/Trapdoor/FenceGate/SpikedPlank/ChristmasTree/Sign/Led(老式)。
- `Max(邻居输出)` 模拟量直通型: Piston/LightBulb/OneLed/FourLed/MulticoloredLed/SevenSegmentDisplay(均在 Simulate 里手写循环, 不经基类)。
- 语义方向型(`GetConnectorDirection(face,Rotation,connectorFace)` 分派): 旋转族全体(门电路/Counter/MemoryBank/RandomGenerator/RTC/SRLatch/TruthTable/ADC/DAC/SoundGenerator)。

## 二、逐元件事实(46 具体类 + 线域)

### 电平源(无 Simulate 或构造缓存)
- **BatteryElectricElement**：无 Simulate；GetOutputVoltage 直接 `BatteryBlock.GetVoltageLevel(data)/15f`(:7-13)。OnNeighborBlockChanged(:15-30)：正下方非碰撞/不可贴 → DestroyCell 自毁。输出永续、0 延迟，是唯一"静态源"。
- **SwitchElectricElement**：构造函数读 `SwitchBlock.GetLeverState/GetVoltageLevel` 缓存 m_voltage(:7-10)；OnInteract 翻 data 杆态 + ChangeCell(:14-21)→ 元件销毁重建，新元件带新电压；AddElectricElement 会自动排自 +1/邻居 +2。无 Simulate。
- **WireDomainElectricElement**(复核)：多输入按位或(:17-23)；洪泛成一个元件。

### 脉冲与人机输入
- **ButtonElectricElement**：Press()(:16-24) 仅当未按下且输出为 0 时置 m_wasPressed + 排 `CircuitStep+1`；Simulate(:28-39)：首拍 m_voltage= pressedVoltage 并排 `+10`(=100ms 脉宽)，次拍清 0。OnInteract 与 OnHitByProjectile 都触发 Press(:41-48)。恒定 1 步延迟 + 10 步脉冲。
- **PressurePlateElectricElement**：Press(pressure)(:13-28) 取 max 存 m_pressure + FrameIndex；触发源 OnCollide(压上, pressure=ComponentBody.Mass, :57-60, 顺带给微小下压冲量 2E-05)与 OnHitByProjectile(pressure=1f*density, :62-66)。Simulate(:32-55)：距上次 Press <2 帧视为"还在压"，输出 PressureToVoltage 并排 `+10` 轮询续期；否则清 0 并在原为高时播松开音。
- **PressureToVoltage**(:68-94) 8 档质量→电压：`<1kg→8/15, <2→9/15(0.6f), <5→10/15(2/3f), <25→11/15, <100→12/15(0.8f), <250→13/15, <500→14/15, ≥500→1f`。注意输出全 ≥8/15=0.533>0.5，**任何有质量的东西都产生"高"电平，档位只有经 ADC/DAC 才有意义**。
- **TargetElectricElement**：OnHitByProjectile(:24-41) 按 4/2 轴(X 面半径 0.707, Z 面半径 0.5)算离靶心距离 → score=Clamp(round(8*(1-d/r)),1,8)，排 +1；Simulate(:11-22) 输出 `(score+7)/15`、score 清 0、排 `+50`(0.5s 保持)。
- **DetonatorElectricElement**：Simulate 高输入计数>0 → Detonate()(:5-9)=`SubsystemExplosions.TryExplodeBlock(x,y,z, MakeBlockValue(147))`(以 147 号雷管方块值炸自己)；OnHitByProjectile 直接 Detonate(:18-20)。永 return false(自毁即元件销毁)。

### 传感器(轮询家族)
- **PhotodiodeElectricElement**：电压=Max(本格光照, 朝向格光照)/15(:19-29)；Simulate 后固定排 `+50`(0.5s) 自续(:15)。构造也算一次初值(:7-8)。
- **ThermometerElectricElement**：读 SubsystemMetersBlockBehavior.GetThermometerReading(:19)；周期 0.5s 带相位抖动 `0.5f*(0.9f+0.0002f*(GetHashCode()%1000))`(:20-21)。
- **HygrometerElectricElement**：电压=humidity(data)/15(:12-13)。**无自续排队**——湿度变化不会主动唤醒它，只有邻居方块变化才重跑。疑似原版惰性设计/缺陷。
- **MotionDetectorElectricElement**：常量 range=8m/speed=0.25m/s(平方 0.0625)/period=0.25s(:5-9)。构造算扇形中心与 2D 角框(:36-43)。Simulate(:47-57)：算出电压后按 `0.25f*(0.9f+0.0002f*(GetHashCode()%1000))` 抖动自续。检测源 4 类(:59-92)：SubsystemBodies.FindBodiesInArea(需速度≥0.25)、移动方块组(≤8m)、投掷物、掉落物。TestPoint(:94-116)：距离<8m 且与朝向点积>0.5 且射线无遮挡(遮挡判定无视编号 15/60/44/18 四种方块:107-109) → 强度 Saturate(1-d/8)；总输出 Lerp(0.51,1,Saturate(强度*1.1))——**下限 0.51 恰好过 IsSignalHigh 阈值**。电压从 0 变正播咔哒音(:50-53)。

### 显示家族(全部经 SubsystemGlow 的 GlowPoint, OnAdded 建/OnRemoved 删)
- **LedElectricElement**(小圆点)：Simulate(:38-45) `CalculateHighInputsCount()>0` 开关 m_glowPoint.Color(数据色/透明)；恒 return false。
- **OneLedElectricElement**：Max 输入×15 取整 num；`num>=8 → LedColors[Clamp(num-8,0,7)]` 否则透明(:50-53)。即电压 8..15 是 8 色选色盘，0..7 灭。
- **FourLedElectricElement**：4 个 GlowPoint(2x2 布局:21-38)；`num&(1<<i)` 逐位点亮(:56-62) —— 4-bit 二进制直读。
- **MulticoloredLedElectricElement**：与 OneLed 同规则(:45-49)，单点彩色。
- **SevenSegmentDisplayElectricElement**：7 个 GlowPoint，第 7 个居中为 g 段；段心/段尺寸两表(:13-31)，类型横条/竖条矩形(:77)。16 项字模表(:33-50) `63,6,91,79,102,109,125,7,127,111,119,124,57,94,121,113` = 0-F 十六进制标准段码，bit i=段 i(:96-101)。
- **LightBulbElectricElement**：intensity=Clamp(round((v-0.5)*30),0,15)(:28)(阈值 0.5 全灭, 1.0 全亮)；**10 步防抖**：距上次变档 <10 步则排 `CircuitStep+10-num` 补齐, 满 10 步才 ChangeCell 写 data 亮度位(:32-41)。恒 return false。
- **ChristmasTreeElectricElement**：布尔灯；与灯泡同一套 10 步防抖 + ChangeCell 写 SetLightState(:15-33)。

### 门电路族(全部 Rotateable；4-bit 整数域位运算)
- 通用读入：`(int)MathF.Round(邻居电压*15f)`，按连接聚合后 `/15f` 写回 m_voltage；只有值变才 return true。
- **AndGate**：累积按位与，但**恰好 2 个有效输入才输出, 否则 0**(:20)。
- **NandGate**：同上再取 `(~n)&0xF`(:20)。
- **OrGate**：按位或(:18)。**NorGate**：取反(:18)。
- **NotGate**：只取**第一个**输入(break)(:15-19)——多连线时其余被忽略。
- **XorGate**：累积异或, 0 输入输出 0(:16-19)。
- **BaseDelayGateElectricElement**：m_voltagesHistory 字典按步号存未来电压(≤300 条, :33)；输入变化时记 `history[step+DelaySteps]=v` 并排 `+DelaySteps` 自续(:31-37)；到点从字典取值(:27-30)。DelaySteps==0 直通。
- **DelayGateElectricElement**：延迟 3 档 `{20,80,400}` 步(:7)；档位=递归数"输入侧串联的延时门个数"(CountDelayPredecessors, 封顶 2, :26-38)；**档位缓存 50 步**(:11-13)——改拓扑后最多 0.5s 才生效。
- **AdjustableDelayGateElectricElement**：`AdjustableDelayGateBlock.GetDelay(data)`(:9-11)，存档在方块 data。

### 存储/时序族
- **CounterElectricElement**：端口语义 Right=+1, Left=-1, In=清零(:50-58)；Top 输出 count/15, Bottom 输出溢出位(:21-32)。边沿触发靠 m_plusAllowed/m_minusAllowed/m_resetAllowed 三旗(输入回低才重新武装, :62-96)。**持久化技巧**：`WritePersistentVoltage(point, count/15f * (overflow?-1:1))`——用电压符号位偷存溢出标志(:97-100)；构造时逆向还原(:13-19)。
- **SRLatchElectricElement**：Left=Set, Right=Reset；若 Bottom 接了东西进入时钟模式：时钟沿时 S&R 双高=翻转(T 触发器), 单高置/清(:49-61)；无时钟=电平直控(:63-70)。状态 WritePersistentVoltage(:80-84)。
- **MemoryBankElectricElement**：地址=Right(nib 低 4 位)+Left<<4(:58)=8bit/256 字；Bottom 复用：≥8=时钟沿(读), 1..7=写允许, 0=空闲(:45-50)；In=写数据(:51-53)。无 Bottom 连线=组合读(地址直通输出)(:73-75)。数据本体在 SubsystemMemoryBankBlockBehavior.GetBlockData 的 MemoryBankData(行为侧存档)；LastOutput 缓存(:82-84)。边沿武装 m_clockAllowed/m_writeAllowed(:60-81)。
- **TruthTableCircuitElectricElement**：Top/Right/Bottom/Left 四输入拼 4-bit 下标(1/2/4/8)(:26-44)；`blockData.Data[下标]` 查 16 项表(:48-49)。真值表数据在 SubsystemTruthTableCircuitBlockBehavior(188) 行为侧。
- **RandomGeneratorElectricElement**：有连接=时钟沿出随机(武装旗 :23-37)；**无连接=自由运行**, 以 `random.Float(0.25,0.75)s` 随机周期自续出随机电压(:43-48)。WritePersistentVoltage 存当前值(:50-53)。
- **RealTimeClockElectricElement**：一天 4096 份(:9)；GetClockValue=20bit `Day*4096`(:49)；**五个方向各输出一个 nibble**：Top=bit0-3, Right=4-7, Bottom=8-11, Left=12-15, In=16-19(:14-34)。Simulate(:36-47) 用 `FrameStartCircuitStep+距下一跳步数` 把下次唤醒精确排在日界，再比较 20bit 变化才 return true。

### 数模转换
- **ADC**：In 读入→取整 4bit(:43)；Top=bit0(LSB), Right=bit1, Bottom=bit2, Left=bit3(:10-27)。
- **DAC**：各方向高电平加权累加(:26-37)：Top=71/(339π)=**1/15**, Right=142/(339π)=**2/15**, Bottom=**4/15**, Left=**8/15** —— 1-2-4-8 二进制权重(即权重常数只是 1/15 的花哨写法)。

### 机构执行族(电→行为子系统)
- **PistonElectricElement**(复核)：6 面 CellFace；长度=Max((int)(Max输入*15.999f)-7, 0)(:22-24)——**模拟量控制伸出长度 0..8 格**，v<0.5 伸 0；长度变化才调 SubsystemPistonBlockBehavior.AdjustPiston(:27)。
- **DoorElectricElement**(复核)：阈值型 + 10 步节流 + m_needsReset 三段状态机(Simulate :14-45)；高→调 SubsystemDoorBlockBehavior.OpenCloseDoor(toggle !GetOpen)。
- **TrapDoorElectricElement / FenceGateElectricElement / SpikedPlankElectricElement**：与 Door 完全同构(仅替换行为调用 OpenCloseTrapdoor/OpenCloseGate/RetractExtendSpikes)。三份代码逐行复制。
- **DispenserElectricElement**：构造给 6 面 CellFaces(:11-21)——六面都是连接端；高输入 + 0.1s 冷却 → BlockEntity→ComponentDispenser.Dispense()(:23-37)。
- **GunpowderKegElectricElement**：高输入 → SubsystemExplosivesBlockBehavior.IgniteFuse(:5-12)。全元件最短实现(11 行), **自定义"高电平触发动作"的最小样板**。
- **SignElectricElement**：高输入 + 0.5s 冷却 → 读 SignData 文本 → 给**所有在线玩家** DisplaySmallMessage 广播(:11-35)；颜色取首行色归一化亮度(:24-25)。

### 家具族(FurnitureElectricElement 抽象基)
- 基类(:10-27)：按 design.MountingFacesMask 生成挂载 CellFace 集合(mask 按家具旋转换算本地朝向 :20)。
- **ButtonFurnitureElectricElement**：与 Button 同构但电压固定 1(:23-34)。
- **SwitchFurnitureElectricElement**：电压=design.Index>=LinkedDesign.Index?1:0(:7-14)——开关态由家具"链式设计对"顺序决定；OnInteract 调 SwitchToNextState(:18-23)。
- **MultistateFurnitureElectricElement**：高输入 + 0.1s 冷却 → SwitchToNextState(:11-25)。

## 三、横切机制(新页素材)

### 3.1 机构执行类标准状态机(4 处复制粘贴)
门/活板门/栅栏门/刺板共用：`m_lastChangeCircuitStep + m_needsReset`。
1. 构造时 m_needsReset=true —— **上电/加载瞬间不触发**, 防止存档加载时全门齐开; 必须先见低电平才武装(:21-23)。
2. 电平沿变化记时间戳(:17-19)。
3. 距上次沿 ≥10 步(0.1s)才执行动作, 否则补排 `+10-num`(:24-37) —— 执行类最小间隔 100ms, 防手电抖动。

### 3.2 旋转与语义方向协议
- RotateableElectricElement：Rotation 存 data(`RotateableMountedElectricElementBlock.Get/SetRotation`), set 走 ChangeCell+Click 音(:5-22)；OnInteract=++Rotation(:26-29)。
- 元件内用 `SubsystemElectricity.GetConnectorDirection(CellFaces[0].Face, Rotation, face)` 把物理连接面换算成 Top/Bottom/Left/Right/In 语义方向 —— 同一个类支持 4 朝向, 端口语义(数据/时钟/清零)写在方向上。
- 20 个类用此协议：6 门(不含 Delay 两门? Delay 门不用方向)+Counter/SRLatch/MemoryBank/TruthTable/ADC/DAC/RTC/SoundGenerator。实际上 DelayGate 读输入只问"非 Output 的第一条", 不分方向。
- MountedElectricElement.OnNeighborBlockChanged(:7-29)：支架方块 IsFaceNonAttachable → 自毁挂件; 特例 face==4 且支架是栅栏(FenceBlock)不毁(:17)。

### 3.3 显示类统一出口 = SubsystemGlow
LED 5 种 + 7 段码全部 OnAdded 里 AddGlowPoint、OnRemoved RemoveGlowPoint；GlowPoint.Type 决定渲染形状(Square/HorizontalRectangle/VerticalRectangle)。发光不进光照系统(不走 SubsystemLighting), 是纯视效点。

### 3.4 存档归宿三分法(逐类核对)
| 归宿 | 使用者 |
|---|---|
| 方块 data 位 | Switch/Button/电池/灯泡亮度/圣诞树/可调延迟门/线色/Rotation/门开合 |
| WritePersistentVoltage | Counter(带符号偷存溢出)/SRLatch/RandomGenerator —— 恰好是"无方块位可用"的 3 类 |
| 自己的 BlockBehavior 数据 | MemoryBank(186)/TruthTable(188)/Sign/家具设计/存储方块 |

### 3.5 事件转发补遗(SubsystemElectricBlockBehavior 全文复核)
- OnBlockStartMoving/OnBlockStopMoving 也塞 m_pointsToUpdate(:88-94) —— **活塞每次推/停都重建涉及的电路元件**。
- OnNeighborBlockChanged 转发给该点 6 面全部元件(:100-105)。
- OnInteract/OnCollide/OnHitByProjectile 只找 6 面中**第一个**元件转发(:107-158)。

## 五、坑与新发现清单

1. 活塞伸出长度是模拟量：0.5 以下收 0, 每档电压多伸 1 格(PistonElectricElement.cs:23)——想当数字开关用必须给 ≥8/15。
2. 铁活板门(84)接电后不能手开, 木活板门(83)永远能手开(SubsystemTrapdoorBlockBehavior.cs:46)；栅栏门 166 特殊(SubsystemFenceGateBlockBehavior.cs:46)。
3. 移动方块启停会销毁重建其电路元件(SubsystemElectricBlockBehavior.cs:88-94)——活塞推电路上非 data/持久电压状态全丢。
4. DelayGate 延迟档缓存 50 步(DelayGateElectricElement.cs:11-13), 改拓扑后有 0.5s 旧档窗口。
5. Hygrometer 不自续轮询(HygrometerElectricElement.cs:9-15), 湿度变了不会自己上报, 是全传感器唯一惰性的。
6. NotGate 只认第一条输入(NotGateElectricElement.cs:15-16 break), AndGate 严格要 2 输入否则输出 0(AndGateElectricElement.cs:20)。
7. 压力板 8 档全部 ≥8/15>0.5: 只要压上就是高, 分档需 ADC(PressurePlateElectricElement.cs:68-94)。
8. OneLED/多彩 LED 电压语义是 8..15 选色 0..7 灭(OneLedElectricElement.cs:52)——直连 4 档信号源会全程灭灯。
9. Counter 持久电压符号位=溢出标志(CounterElectricElement.cs:99), 直接读持久电压做别的会被污染。
10. MemoryBank 的 Bottom 端口三义: 0=空闲 1-7=写 8-15=时钟读(MemoryBankElectricElement.cs:45-50)。
11. RTC 5 个端口语义按旋转不重排?——否, GetConnectorDirection 已含 Rotation, 语义方向随旋转走(RealTimeClockElectricElement.cs:14-34)。
12. 熔炉火焰粒子被注释禁用(SubsystemFurnaceBlockBehavior.cs:70-87), 熔炼在 ComponentFurnace。
13. DAC 权重常数 71/(339π) 等就是 1/15、2/15 的浮点花写(DigitalToAnalogConverterElectricElement.cs:27-30), 别被吓到。
14. 原版刺板行为编号动态取 GetBlockIndex<T>(SubsystemSpikesBlockBehavior.cs:17), mod 仿写可学这个免硬编码。
15. 老式 LED(LedElectricElement) 是唯一"阈值开关型"显示, 其余 LED 全是模拟量直接驱动。
