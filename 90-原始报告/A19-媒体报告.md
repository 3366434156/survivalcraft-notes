## 1. Engine.Media 发现

### 1.1 图片
- Image 是 SixLabors.ImageSharp `Image<Rgba32>` 的薄包装（Image.cs:63），注册 9 个解码模块 Bmp/Gif/Jpeg/Pbm/Png/Qoi/Tga/Tiff/Webp（:17-27），默认 `PreferContiguousImageBuffers=true`（:29）。
- `Load(Stream)` 自动嗅探（:144）；带格式重载校验嗅探结果一致否则 FormatException（:132-136）。Save 支持同 9 格式，默认异步（SaveAsXxxAsync），`sync=true` 才同步（:152-250）。
- `Pixels` 惰性缓存 Color[]，写入像素后 `m_shouldUpdatePixelsCache=true` 失效（:38-61）。
- **疑似 bug**：`Image(LegacyImage)` 构造器 Image.cs:84 `pixels.Slice(y * image.Width, image.Height)` —— Slice 长度用了 Height（应为 Width）。宽 > 2×高 的图 CopyTo 源不足会抛异常；正方形/高图正常。
- LegacyImage：Color[] 缓冲图，`GenerateMipmaps` 手写 box filter（2×2/2×1/1×2 平均 +1/+2 舍入，LegacyImage.cs:52-153）；任一维收窄到奇数即 break→throw（:66-69、150-152）。
- Rgba32Extensions：PremultiplyAlpha（R*A/255）、IsMagenta（255,0,255,255）、IsCompletelyTransparent。
- PeekStream（:31-108）：构造即预读 N 字节，Read 先缓冲后透传；SoundData 用 64、ModelData 用 256。

### 1.2 音频装载
- SoundData：16bit PCM，声道 1-2、采样率 8k-192k（SoundData.cs:9-25）；Save 仅 WAV（:106-112）；StereoToMono=(L+R)/2（:120-130）。
- 嗅探顺序 Flac→Wav→Ogg→Mp3（:39-48）。**命名坑**：第 47 行调 `Mp3.IsFlacStream`，该方法实测 ID3v2 标签存在性（Mp3.cs:83-90 `Id3v2Tag.ReadTag != null`）——裸 MP3（无 ID3v2）判不出、带 ID3v2 的 FLAC 会先落到这里被当 Mp3。
- Wav.ReadHeaders（Wav.cs:195-237）：跳未知 chunk（按 size 前进），硬校验 Type==1/声道 1-2/8k-48kHz/16bit。**Position setter bug**（Wav.cs:34）：`m_stream.Position = SizeOf<WavHeader>(12) + num`，未含 fmt/data 头（标准 44 字节），seek 偏早 32 字节。
- 四个 StreamingSource 构造函数都把整份流拷进 MemoryStream（Wav.cs:42-48、Mp3.cs:36-41、Ogg.cs:23-29、Flac.cs:184-188 / IOS Flac.cs:33-53）："流式"=内存分块解码。Duplicate() 再全拷。
- Mp3：NLayer Mp3FrameDecompressor 解出 float，Read 逐样本 ×short.MaxValue 转 int16（Mp3.cs:49-68）；BytesCount=reader.Length/2。
- Ogg：NVorbis VorbisReader，float×32767→int16（Ogg.cs:53）；BytesCount=TotalSamples×2。
- Flac：IOS 分支用 BASS（BASS_FLAC_StreamCreateFileUser，构造即全解到 MemoryStream，:33-53）；其余 NAudio.Flac。非 IOS 的 IsFlacStream 先 ID3v2.SkipTag 再查 "fLaC"（:221-232）。

### 2.6 IK
- IKSolver：链延迟构建（pending→BuildPendingChains in Solve）；骨世界位置整树递归重算（每 Solve 一次+CCD 每次迭代内 UpdateWorldPositions）。
- 默认算法按链长：2→SingleBoneIK、3→TwoBoneIK、>3→CCD；≤1 或未注册→放弃。FABRIK 仅显式。
- 目标平滑：SmoothDamp（PositionSmoothTime 默认 0.1s / Aim 0.15s），平滑状态存在 target 上跨帧延续（:370-432）。
- Aim-only：算法不支持 Aim 时生成合成位置=bindRoot+aimDir×链长（:235-258）；TwoBoneIK 的 Aim 约束在末端骨上按 AimAxis 旋转（:176-206）。
- 不可达：链级策略 ExtendTowardTarget（仍解，算法内伸展）/KeepCurrentPose/UseLastValidResult（保存最近成功结果，:466-498）。
- JointLimit：欧拉分解→Clamp→按顺序重建（默认 YXZ）。所有算法解后统一 ApplyJointLimits。
- IKUtils.ApplyModelRotation：模型空间旋转增量→重算世界矩阵（保位置）→父世界仿射逆回局部。ComputeBoneWorldTransform 用 [ThreadStatic] 路径缓冲。
- 已知注意点：CCD/FABRIK 实例持有缓存数组（m_worldPosCache/m_positionsCache），IKSolver 内是全局单例算法——同帧多模型顺序复用无碍，跨线程不行 [推测]。

### 2.7 RootMotion 域
- TranslationConfig：Blend（SmoothDamp 0.3s/WeightedAverage 0.5/SpringDamper 100/10）/AddImpulse（Average/Peak/Weighted；ImpulsePhase=-1 自动；ImpulseOverride/ImpulseSpeedOverride body-local；MaxImpulse 50）/Override；VelocityMask 按轴；MaxSpeed 20。
- ScaleConfig：Fixed/Animation 源；CollisionBoxApplier 指数衰减 Lerp（decay=exp(-dt/blend)）。
- PhysicsConfig：7 开关（重力/地形碰撞/输入移动/空气阻力/水阻力/地面阻力/退出清速）+disableAll 聚合属性；**JSON 混用 disableAll 与单项时按文档出现顺序 set，单项须排在 disableAll 之后**（RootMotionConfig.cs:265-268 注释）。
- RootMotionCache：位置采样表+循环回绕跨帧测速（end→start 拼接）；SamplePosition 增量线性搜索+二分回退（m_lastSampleIndex）。
- RootMotionStrip：从 SourceBone（或自动根）走到模型根，translation:=rest，保留 R/S；幂等。
- RootStripInfo：None/AddImpulse 不剥。

## 3. VR 发现

- 架构：`IVrBackend` 接口（生命周期/HMD/帧/眼/手柄/RenderTarget）+ `OpenXrVrBackend` 抽象类（平台子类提供 GL 绑定：WINDOWS=XR_KHR_opengl_enable，ANDROID=opengl_es_enable）。编译门 `#if WINDOWS || ANDROID`。
- 初始化：Windows 下丢后台 Task（xrCreateInstance 在注册了 runtime 但无 HMD 时可阻塞数秒，:150-172 注释）；实例/系统/视图查询线程安全，session/GL 绑定仍在 StartVr（渲染线程）。Android 先 xrInitializeLoaderKHR（JVM+Activity，:187-210）。
- 参考空间三级回退 LOCAL_FLOOR→Stage→Local（:1517-1553）；ReferenceSpaceChangePending（recenter）时重建 space 并做 **Y 累积补偿**（trackingEstablished 之后才记账，防启动误补，:1239-1257、1471-1480）。
- Swapchain：格式优先 Srgb8Alpha8（注释：Rgba8 会被 Meta runtime 二次伽马→发灰，:463-473）；每眼 swapchain+FBO+Depth24 RB；Acquire/Wait/Release 每帧轮换，FBO 重新 attach 当前图像（:1088-1128）。
- 投影矩阵自 FOV tan 构造（OpenGL 惯例 clipZ [-1,1]，:1570-1592）；GetEyeToHeadTransform 只返回 IPD 平移（旋转由 HmdMatrix 承担，防双转 roll 反转，:1429-1447）。
- 输入：13 动作×2 手（trigger/grip float+click/menu/stick x+y/pose/stickClick/primary/secondary/thumbrest/trackpad x+y）；8 个 interaction_profile 建议绑定（Quest Touch/Touch Pro/Touch Plus/WMR/Vive/Index/PICO Neo3/PICO 4/Vive Focus3——PICO 4 右手无 menu，:894-920）；类型检测延迟到首次 SyncActions 后、30 次尝试（:1074-1080）。
- Grip=浮点≥0.5 或 click；Trigger 按钮化同样 ≥0.5；TrackpadCenter=stickClick 且 |x|,|y|<0.3；IsButtonDownOnce 用 m_lastControllers 差分。WalkingVelocity 恒 Zero（OpenXR 不提供，:1596）。
- EndFrame：ShouldRender=0 时提交空层（EndFrameEmpty）。

1. Mp3.IsFlacStream 名不副实（实测 ID3v2）→ 裸 MP3 判不出、带 ID3v2 的 FLAC 误判（Mp3.cs:83-90、SoundData.cs:47）。
