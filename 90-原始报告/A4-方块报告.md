## 二、最重要机制发现(带 file:line)

1. **形状家族=data 位编码家族**。每个异形基类自带一组静态位工具函数，data 在"朝向/开合/染色/液位"间复用：液体 bit0-3 液位+bit4 isTop(FluidBlock.cs:196-207)、门 bit0-1 朝向+bit2 开+bit3 右手(DoorBlock.cs:208-228)、楼梯 bit0-1 朝向+bit2 倒装+bit3-4 转角+bit5-9 颜色(StairsBlock.cs:439-470)、板 bit0 isTop+bit1-5 颜色(SlabBlock.cs:283-299)、栅栏 bit0-3 连接+bit4-8 颜色(FenceBlock.cs:419-435)、电线低 6 位=6 面位掩码+bit6-10 颜色(WireBlock.cs:220-248)、家具 13 位 designIndex 分裂在 bit2-11 与 bit15-17(FurnitureBlock.cs:604-618)、服装衣索引 10 位分裂 bit0-7 与 bit17-18(ClothingBlock.cs:271-280)。
2. **Initialize 期预烘变体表**是异形方块的统一渲染架构：门 16 变体(DoorBlock.cs:21-62)、楼梯 24 变体×2+24 套碰撞盒(StairsBlock.cs:26-104/:129-232)、活塞 48 变体(PistonBlock.cs:12-70)、栅栏 16(FenceBlock.cs:42-192)。运行期 GenerateTerrainVertices/GetCustomCollisionBoxes 只做下标查表。
3. **液体平滑顶面与同族判定**：FluidBlock.Initialize 反射"继承 FluidBlock 的直接子类"建同族布尔表(FluidBlock.cs:23-43)；顶面高度=8 邻域最大值(同液顶=本液位高/同液非顶=1/空气=0.01/实心=0，:179-192)；顶面纹理槽随流向偏移 `-MathF.Sign(x2)-16*Sign(x3)`(:86)。
4. **拓扑回写不在方块类**：栅栏连接位由 SubsystemFenceBlockBehavior.cs:22-31 调 `FenceBlock.ShouldConnectTo`(:410) 回写；楼梯转角由 SubsystemStairsBlockBehavior.cs:91/:190 调 `SetCornerType` 写入——方块类只给谓词和位工具。
5. **两板合一**：SlabBlock ctor 带 fullBlockIndex，同板上下相贴→直接替换为整块并把染色经 `IPaintableBlock.Paint` 转移(SlabBlock.cs:139-152)；挖整块不掉板(:167-183)。
6. **本 API 项目扩展点(实读确认非原版)**：`GetDrawDemand`/`BlockDrawDemand`(Managers\BlockDrawDemand.cs:8，物品方块报 `FromBlockMesh`，平面报 `Flat`)；活塞 data 增加 maxExtension/pullCount/speed 三字段(PistonBlock.cs:201-211)；MovingBlocksRaycastResult.ValuesDictionaryForMods 模组扩展位(:24)；FurnitureBlock.cs:148-162/:164-189 带 API 项目中文注释。
7. **物品损伤即变体切换**：FoodBlock.GetDamageDestructionValue 返回 ctor 传入的腐烂值(FoodBlock.cs:60)；桶类坏掉掉空桶(MilkBucketBlock.cs:53、PaintBucketBlock.cs:128)；蛋损坏值=246 孵化(EggBlock.cs:143)。AdHoc 程序化合成有 5 个实例：服装染色(ClothingBlock.cs:189)、地毯(CarpetBlock.cs:103)、家具组合(FurnitureBlock.cs:436-542)、烟花(FireworksBlock.cs:195)、LED 染色(LedBlock.cs:92)。
8. **特殊直系**：AirBlock 用 111 号方块+洋红渲染"有 contents 的空气"作为坏数据报警(AirBlock.cs:16-42)；ShadowBlock data=阴影强度+128(ShadowBlock.cs:15-22)；火 data=6 面位掩码且 0=全脸(FireBlock.cs:306-314)；TorchBlock 底面(5)不可放置(TorchBlock.cs:179-181)。

## 三、新坑列表(未入总表，主会话统一维护)

1. StoneAxeBlock 直接继承 Block 而非 AxeBlock(StoneAxeBlock.cs:5)——按材质族补工具时会漏。
2. LitFurnaceBlock : FurnaceBlock 且 `new static Index=65`(LitFurnaceBlock.cs:3)——"同模型双 ID"实体，复制该模式要重走注册。
3. Kelp/Seagrass/SeaUrchin/Starfish/LitFurnace 五处用 `new const/new static Index` 隐藏基类成员(KelpBlock.cs:6 等)——反射搜 `public static int Index` 会命中到基类。
4. DirtSlabBlock/DirtStairsBlock 显式禁染(Paint=>value, DirtSlabBlock.cs:7-9)——"板都可染"不成立，做染色功能要查 GetPaintColor。
5. 楼梯转角不在 StairsBlock 计算——把转角逻辑写进方块类会与 SubsystemStairsBlockBehavior 冲突。
6. 异形方块若在顶点阶段现算矩阵(而非预烘变体表)会显著掉帧——原版全部预烘。
7. FenceGateBlock 的 GetVariant=data&0xF 与颜色位(bit4)重叠位面：variant 实为 rot+open+hand 组合(FenceGateBlock.cs:405)，照抄时别把颜色塞进低 4 位。
