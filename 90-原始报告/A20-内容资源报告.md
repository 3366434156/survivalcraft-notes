## 二、最重要机制发现（带 file:line）

1. **游戏本体就是一个"根 mod"**：`SurvivalCraftModEntity` 构造函数注册全部 19 个原版读取器（ModsManager\SurvivalCraftModEntity.cs:14-40），打开 `app:/Content.zip`（外置优先，否则内嵌程序集资源 `Game.Content.zip`，:50-58）。原版资产与 mod 资产走完全同一条 `Assets/` 剥前缀→`ContentManager.Add`（AddOrUpdate，后载赢，Managers\ContentManager.cs:134；ModsManager\ModEntity.cs:279-298；LoadingScreen.cs:242-247 逐 mod CombineContent）。
2. **Get 装载链三表结构**：Resources(路径→ContentInfo)/ReaderList(Type 字符串→读取器)/Caches(键→对象列表)（ContentManager.cs:51-54）。`Get` 先查 Caches，再按 reader.DefaultSuffix 顺序探测后缀（:92-109），找不到抛 `Not Found Res [key][type]`（:118）。`Subtexture` 在 Get 里特判直转 TextureAtlasManager（:80-82）。引擎 Storage/GltfLoader 的外部流回调挂到 `GetStream`（:60-62）。
3. **ContentInfo.Duplicate() 不是复制**：共享同一 MemoryStream 只复位 Position（ContentManager.cs:35-43）。多线程并发解析同一图片的解法是 ContentInfo.InUse 锁+自旋+回缓存取（IContentReader\ImageReader.cs:12-22）。
4. **scmod 三层结构**：弱加密前缀（HeadingCode 倒序/HeadingCode2 交织，复用 ModsManager.GetDecipherStream，幂等）→ 杂质前缀（扫 PK\x03\x04 截断，64KB 上限）→ zip（Managers\ScmodArchiveReader.cs:57-92,176-214）。根条目读取有 4MB 解压上限+逐块复核防压缩炸弹（:99-133）。**密文落盘、加载期自解密**（:41-43 注释）；错误分类已类型化（InvalidScmodArchiveException :19-36）。
5. **导入决策树**（Managers\ExternalContentManager.Import.cs:15-62）：mod 更新→ModUpdateImporter（tmp+TransactionalFileReplacement+RescanModsAsync，ModUpdateImporter.cs:42-69）；内置物（$ 皮肤/空名材质）禁覆盖（:41）；文件型覆盖走 OverwriteWithRollback（:95-119）；World 永不覆盖（导入总建 World/World1… 新目录）。准备阶段冲突检测统一 Dispatcher.Dispatch(waitUntilCompleted) 封送主线程（Analyze.cs:133-154,221-251），原因是 Update*List 与 ModListAll 在主线程 Clear()+Add。
6. **材料族格式**：.scskin=裸图片（pow2、≤65536²，CharacterSkinsManager.cs:225-235，内置名 $ 前缀 :27，加载回退链至 HumanMale1 :79-107）；.scbtex=容器后缀（真格式看剩余扩展名，可内 astc，BlocksTexturesManager.cs:52-85，**内置=空字符串名** :24）；.scfpack=必须恰好 1 条目 FurnitureDesigns.xml 的 zip（FurniturePacksManager.cs:110-115，重名自动 " (n)" 最多 9 次 :43-51）；字体 ttf/otf/ttc/woff/woff2 入 doc/Fonts，导入校验=解析 0 面拒+全面轮廓可渲染（CFF2 拒）+Latin 62 字符必备（FontManager.cs:912-961）。
7. **世界打包重排**：PackWorld 把 Region* 文件在 zip 内挪到 `Regions/` 前缀下（WorldsManager.cs:400-401）；非内置材质/皮肤嵌入 `EmbeddedContent/<名>.scbtex|.scskin`（:404-439），UnpackWorld 按扩展名重导入（:453-461）。种子字符串哈希=逐字符 `sum+=c*(29^i)` int 截断（:228-234）。`MaxAllowedWorlds=30` 常量全库无强制点（:15 唯一命中）。
8. **SettingsManager 反射持久化**：Save 枚举全部 public static get+set 属性写 `DocPath/Settings.xml`（SettingsManager.cs:1096-1147，非阻塞 TryEnter 锁防重入 :1097）；Load 同名反射赋值、ValuesDictionary 属性 ApplyOverrides 合并（:1051-1067）；旧版 `<Configs>` 结构转 ModsManager.LoadConfigsFromXml（:1046-1049）。
9. **社区协议单端点**：全部走 `{CommunityServerManager.CurrentApiBaseUrl}/com/list`，`Action=list|publish|delete|feedback`（CommunityContentManager.cs:60,246,274,386）；内容哈希 SHA384 Base64（:674）；评价缓存 TryAdd 失败=重复提交→1.5s 延迟 failure（:408-418）；本地缓存 CommunityContentCache.xml 于 Window.Deactivated 落盘（:30,680-731）。
10. **提供者家族**：Initialize 注册 Disk(非 Android)/AndroidSdCard/ChineseCommunity/Dropbox（ExternalContentManager.cs:16-27）；ChineseCommunity 列举改跳专用屏（ScreenNameForListing="CommunityMyPublished" :29），Upload=又拍云直传+登记（凭证/登记 30s 超时 :107-123）；Dropbox OAuth token 走 URI 回调 HandleUri（DropboxExternalContentProvider.cs:257-287）+桌面贴 code 兜底（:212-255）；Schub 是 [Obsolete] 尸体类（SchubExternalContentProvider.cs:9-13）。

## 三、新坑列表（页面"坑与对策"已收编的部分此处合并罗列）

- Duplicate() 共享流：多线程读同一 ContentInfo 会互相踩 Position → 照抄 ImageReader.InUse 模式。
- 资产键区分大小写；无后缀 Get 按 DefaultSuffix 顺序首个命中（astc 排在 webp/png 前）。
- ContentManager.Add 是 AddOrUpdate：同名资产后载 mod 覆盖先载（含覆盖原版）。
- Caches 无逐出：一次性大资产须手动 ContentManager.Dispose(name)（原版 BlocksData/Database/Clothes 先例 SurvivalCraftModEntity.cs:74-137）。
- 后台线程直接枚举 Update*List()/ModListAll 会 InvalidOperationException → Dispatch(waitUntilCompleted:true) 封送。
- SettingsManager 的 public static 可写属性会被反射整包写进 Settings.xml——临时状态别挂上去。
- SetGamepadMapping/SetCameraManageSetting 只能改已存在键，新键必须走 ModLoader.Get*Mappings。
- scmod 直接 ZipArchive.Open 会撞弱加密前缀+英文异常 → 必须 ScmodArchiveReader.OpenArchive。
- 覆盖导入不备份会丢用户原内容 → TransactionalFileReplacement.OverwriteWithRollback。
- 字体导入：CFF2-only 变量字体解析能过但渲染必炸（FontManager.cs:942-948 全面拒收）；纯 CJK 字体缺拉丁必备字符被拒（:950-961）；同名覆盖导入后必须失效 `user:<文件名>` 探测缓存（:968-970）。
- 皮肤/纹理非 2 次幂或超 65536² 导入期抛。
- .scbtex 里 astcsrgb 必须走 CompressedTexture2D.Load(...,false) 才有正确 sRGB。
- CommunityContentManager.Feedback 缓存 TryAdd 失败后延迟 1.5s 才报错——UI 看起来"卡 1.5 秒才报重复"。
- 世界名合法校验只挡 \、\n、空、>128 字符（WorldsManager.cs:146-154），不挡特殊字符。
- 尝试导入世界在试用模式（IsTrialMode 静态布尔）被拒——该布尔纯内存，无持久化。
